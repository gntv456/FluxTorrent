1项目背景与设计目标

好学 HxPT（hxpt.org）是采用 NexusPHP 系统搭建的 PT 站点，专注学前教育、小学、初中、职高、高中学习资源分享，辅以教育影音与纪录片。本次为其重新设计整套主题，目标是让站点的视觉语言与「幼小初高学习资源」的定位、与「好学」的站名气质完全对齐。

设计目标落地方式
符合站点特色紧扣幼小初高学习资源定位：学科封面、课本专区、名师精讲、官种古籍等真实内容贯穿全站设计
青春活泼有活力8 色明亮童趣色板 + 圆润字体 + 大面积留白与色块分区，拒绝沉闷的深色 PT 模板风
有朝气有创意「种子 ⇄ 成长」双关叙事线：下载做种 ⇄ 播下知识，全站统一世界观，与「好学农场」「火花银行」玩法联动
童趣可爱猫头鹰学士 Q 版吉祥物、贴纸徽章、彩带渐变条、蜡笔字标题、成长豆荚等级体系
全端覆盖网页端 / 移动端 / 平板端 / 双折叠屏 / 三折叠屏，含折叠屏外屏、半展开、折叠态、分屏全形态

全部 2383 个设计画板均基于真实站点结构、真实导航、真实分类与真实站点数据（种子数、用户数、火花货币、银行利率、商店价格、勋章、课本、排行榜等）逐一绘制，开发部可直接对照画板实现。

2设计概念：种子 ⇄ 成长

核心双关

PT 的「种子」（torrent）与幼小初高教育的「种子」（seed）天然双关——下载做种、保种分享，就是播下知识、陪伴成长。整套主题以「种下知识 → 发芽生长 → 开花结果」为叙事线；站点已有的「好学农场」「火花银行」等玩法顺理成章纳入世界观，童趣而不幼稚。

站宠：猫头鹰学士

延续站点猫头鹰基因，升级为青春卡通：学士帽 + 圆框眼镜 + 抱书与星光。全站各端反复出现，作为登录页主角、空态陪伴、加载占位与品牌签名元素。

签名元素：贴纸徽章与彩带

「免费 / 2x / 新手 / 部编版 / 精品 / 学科标签」做成彩色贴纸徽章；活动横幅、进度条、等级条用彩虹渐变彩带，是全站记忆点。

成长豆荚等级体系

用户等级按「种子→新芽→幼苗→小树→大树→开花→硕果」命名，与好学农场联动：等级越高农场解锁越丰富，把保种文化做成养成玩法。
