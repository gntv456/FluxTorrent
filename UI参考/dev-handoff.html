0交接摘要

项说明
设计资产主题设计方案（2383 画板）已交付为两个可交互画板文件：主册 1754 块（品牌规范 3 + 桌面 255 + 移动 270 + 平板 235 + 折叠屏常规 991）与折叠屏对齐扩充专册 629 块（外屏/半展开/折叠态），均为单文件 HTML，浏览器打开即可缩放查看每个页面
实现目标为 hxpt.org（NexusPHP）前端实现新主题：青春活泼、童趣可爱、种子⇄成长世界观；覆盖桌面/移动/平板/双折叠/三折叠全端
依据真实站点结构（31 个真实页面抓取缓存）+ 真实数据口径（见 §6）；不可臆造字段
开发顺序建议① 设计 Token 与全局样式 → ② 登录/注册 → ③ 首页与种子列表 → ④ 种子详情/发布 → ⑤ 内容区（课本/官种/保种/排行/勋章/站免池）→ ⑥ 经济系统（银行/商店/签到/任务/绩效/火花）→ ⑦ 社区（论坛/PM/消息）→ ⑧ 娱乐（农场/市场/游戏/装饰）→ ⑨ 个人中心与设置 → ⑩ 管理后台 → ⑪ 移动/平板/折叠屏适配 → ⑫ 验收

1技术栈与架构约束

项约定
系统基础NexusPHP（PHP 模板系统）。主题改造优先走模板/样式层替换：新增 CSS 变量体系 + 覆写页面模板类名，不改动核心业务逻辑
技术栈原生 HTML5 / CSS3 / 少量 JS；无框架依赖；移动端与折叠屏优先 CSS（媒体查询 + 容器查询）
字体标题 ZCOOL KuaiLe（站酷快乐体）、正文 Noto Sans SC；自托管镜像 miaoda.feishu.cn/fonts/css2；每处 font-family 必须带系统 fallback
图标内联 SVG（viewBox 0 0 24 24），建立统一图标语言；学科标签/勋章等可沿用站点现有图标
图片资源一律 CDN URL（aka.doubaocdn.com）直引，禁止本地路径；素材见 §7
响应式策略移动优先（mobile-first）书写，按 §4 断点逐级增强；折叠屏用视口尺寸 + 形态（折叠铰链）判定
无障碍键盘焦点可见、对比度 ≥ 4.5:1（正文）、触控目标 ≥ 44px、尊重 prefers-reduced-motion

3组件规范

3.1 种子列表（本站核心页面，重点）

用户多次强调「种子列表显示方式要好看合理」。三端三形态，按设备切换，同一份种子数据渲染三种密度。
形态结构字段与顺序样式要点
桌面表格行表头 + 行（默认视图，可切卡片）分类色条 + 标题（主）+ 贴纸徽章（免费/2x/官种）+ 大小 + 种子/做种/下载数 + 发布人 + 时间 + 操作（下载）标题 14px/700 两行截断；分类色条 4px 左侧竖条；数字列 tabular-nums；行 hover 底色 #F0F8FF；行高 56px
桌面卡片网格 3-4 列卡片封面图（学科封面）+ 标题 + 徽章行 + 数据条（大小·做种·下载）+ 发布人封面 4:3，圆角 12px；hover 上浮 2px 加深投影
移动卡片单列流式卡片封面左置 88×66px + 右侧标题/徽章/数据行；触控目标 ≥ 44px整卡可点；分类色条融入封面左侧边；底部数据行 11.5px 灰蓝

4布局与响应式规范

4.1 断点定义

桌面 ≥1280px多栏工作台布局，导航横向展开，种子列表表格行式 + 卡片视图切换
平板 768-1280px双栏自适应（内容 + 侧栏），卡片 2-3 列；导航收窄为图标+文字
移动 ≤768px单栏 + 底部 5 Tab；种子卡片列表；抽屉式筛选
折叠屏展开 ~673px约等于小平板宽度；双栏或单栏自适应，避开铰链中缝
折叠屏折叠 ~280px超窄单栏；底部 Tab + 顶部汉堡；内容上下堆叠

4.2 折叠屏三形态布局规则（对应画板 1620 块）

形态视口参考布局规则
双折叠 全展开约 673×720单栏居中内容（max-width 640px），顶部横向导航可显示 4-5 项，其余入「更多」
双折叠 外屏约 340×720超窄单栏：仅核心信息，隐藏次级列与元数据；标题 2 行截断；底部 Tab 保留 5 项
双折叠 分屏展开 + 分屏 720×900左 65% 内容 + 右 35% 快捷面板（筛选/详情/操作），中间 1px 分隔 + 可拖拽手柄
三折叠 全展开约 900×620三栏自然展开：内容（中）+ 辅助（右），左留导航
三折叠 半展开约 900×620 折 1/3两屏可视：主内容 + 次面板；第三屏内容收进抽屉
三折叠 折叠态约 600×400单屏：内容优先；导航收为底部 Tab / 汉堡；表格转卡片
三折叠 分屏1200×520 三栏分屏左内容 / 中数据 / 右操作，三栏信息分层
铰链与安全区：所有折叠屏布局必须避开铰链中缝（屏幕中线预留 ≥48px 不可交互区）；底部导航预留 safe-area（env(safe-area-inset-bottom)）；外屏 340px 宽度下点击目标仍 ≥44px。

4.3 栅格

12 列栅格，间距 16px（移动 12px）；内容最大宽 1280px 居中；页面留白用 8px 步进（16/24/32/40）。卡片网格：桌面 3-4 列、平板 2-3 列、移动 1 列、折叠展开 2 列、折叠折叠 1 列。

9验收标准

  • 全站颜色、字体、圆角、阴影全部取自 Token 体系，无硬编码色值；货币文案为「火花」
  • 桌面 255 / 移动 270 / 平板 235 / 折叠屏 1620 页面对应画板逐页可对照，无缺页、无错位
  • 种子列表三端三形态（桌面表格/卡片、移动单列卡、平板双列、折叠分屏左右布局）显示正确且字段顺序与画板一致
  • 五大端真实设备实测：桌面 ≥1280、平板 768-1280、手机 ≤768、双折叠（展开/外屏/分屏）、三折叠（展开/半开/折叠/分屏）
  • 折叠屏铰链区无交互元素；底部导航 safe-area 正确
  • 登录/注册、发布、下载、签到、农场、银行、商店、站免池、邀请等核心流程可用，错误提示符合新视觉
  • 触控目标 ≥44px；正文对比度 ≥4.5:1；键盘可完整操作；reduced-motion 生效
  • 管理后台 66 个页面完成视觉迁移（桌面优先）
  • 真实数据字段（统计数字、利率、价格、勋章数、课本 29 科、论坛帖子数、排行榜）显示正确
  • 吉祥物、7 张学科封面在对应位置正常加载（CDN 可用性）

10已知限制与开发建议

画布渲染上限：design-canvas 单画布约 1800 块为渲染上限，2383 块会白屏，故设计交付拆为主册 1754 + 扩充册 629 两个文件。开发时不受此限制——直接按 §5 清单实现即可。
折叠屏真机验证必要：折叠屏形态画板按主流尺寸（双折叠展开 673 / 外屏 340 / 三折叠展开 900 / 半开 620 / 折叠 600）设计，各厂商铰链位置与比例有差异，上线前必须真机矩阵验证。
建议：① 先做 Token 与全局样式基线，评审后再铺页面；② 种子列表作为核心页面优先实现并评审；③ 折叠屏适配用「内容不变、布局重排」原则，勿做阉割版；④ 管理后台视觉迁移量大（66 页），可排二期；⑤ 站点数据全部为设计基准，开发联调时替换为真实接口值但保持格式一致。
