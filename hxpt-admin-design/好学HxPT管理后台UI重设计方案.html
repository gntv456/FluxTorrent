01现状诊断：后台长什么样、问题在哪

基于代码库盘点（app/Filament、app/Providers/Filament/AppPanelProvider.php、routes）与本地 Docker 生产副本实测（http://localhost/nexusphp，admin 账号），以下是后台的真实技术构成与界面现状。

🧩
技术栈已定型
Filament 3（PHP 渲染）+ Laravel 12 + NexusPHP 1.6。后台不是普通 Blade 模板，重设计必须走 Filament 主题链，不能逐页改 HTML。
🗂️
规模：约 70 个导航入口
8 大导航分组（User/Torrent/Section/Oauth/System/Prop/StudyBuddy/Other）+ 4 个外链后台（九宫格/绩效考核/装饰品/红包雨）+ Horizon。仪表板挂 9 个 widget。
🎨
品牌几乎为零
侧边栏标题仍是「NexusPHP」，主色为 Filament 默认 Amber，与前台 CuteTop 粉色主题、v44 新品牌完全脱节。
🌪️
碎片化严重
英文残留（创建user / Auto Approval Settings / TelegramBot…）、4 个外链后台风格各异、仪表板部分 widget 空白、System 组 22 项平铺。

1.1 当前界面实录（本地生产副本实测截图）

仪表板 —— 欢迎语 + 最新种子表格 + 用户统计；部分 widget 渲染空白，无 KPI 卡、无趋势可视化风格。
用户列表 —— 筛选区置顶（FiltersLayout::AboveContent）、12 列宽表；「等级」显示 User(幼儿园) 混排、状态为英文原文 confirmed/no。
设置页 —— 顶栏 4 个工具按钮 + 12 个 tab + 大表单，缺少分组卡片与保存反馈；系统概念（SeedBox/Meilisearch）未中文化。
种子列表 —— 15+ 筛选字段平铺、占满两屏，搜索按钮与英文 label（label.search）残留；表格列无固定、无密度控制。

02设计目标与四条原则

延续 v44 设计稿的风格分层：A 品牌/营销层（登录、首页 hero）放心童趣；B 数据/工具层（前台列表、详情）活泼但克制；C 后台层（本方案）清爽专业、品牌色点缀、弱化童趣装饰。

2.1 三个目标

🎯
目标 1 · 一站看清
仪表板成为真正的「运营驾驶舱」：KPI 卡 + 趋势图 + 待办清单 + 快捷入口，10 秒掌握站点健康度。
⚡
目标 2 · 快速到达
70 个入口按角色收敛为 7 组 + 集群折叠 + 全站搜索；高频操作（审核种子、考核、发消息）路径 ≤ 2 次点击。
🌈
目标 3 · 一眼好学
「好学」品牌渗透后台：靛蓝主色 + 糖果粉/天蓝点缀、等级徽章「种子→硕果」成长体系、猫头鹰空态插画，管理者有归属感。

2.2 四条原则

原则说明
1 · 专业优先，童趣点缀后台底色、表格、表单一律中性专业；品牌彩色只出现在主色按钮、等级徽章、状态标签、空态插画。禁止大面积糖果色块与蜡笔体。ZCOOL KuaiLe 不进后台，标题用 Noto Sans SC。
2 · 密度可调，扫读优先表格提供 宽松/紧凑 两档密度；数字用 tabular-nums 等宽；等级、状态、真伪（yes/no）全部换成语义徽章，一屏内完成扫读。
3 · 与前台同 Token8 色品牌板、圆角、阴影与前台 v44 设计稿同一来源；后台只做「引用同一变量」的收窄版（前台全量、后台收敛）。后续前台换肤不破坏后台。
4 · 渐进改造，不推倒重来全部通过 Filament 主题链 + CSS 变量 + 少量 Provider 改动落地，66+ 资源页不逐页重绘；新主题注册、旧主题可回退，灰度上线。

对比度红线（承继 v44 M5 校验清单）：糖果粉 #FF8FC7 与明黄 #FFC93C 上放白字不达 4.5:1，禁止作为白字按钮底/白字徽章底。方案：
  • 糖果粉徽章 → 文字用墨蓝 #1F2A44（深字浅底），或只作描边/装饰；
  • 明黄 → 只作高亮、星星、彩带起点；
  • 警告色在后台统一用加深的 #E8A23D（非 #FFC93C），保证白字徽章可读；
  • 正文灰蓝 #93A1BC 只用于 11px 以上的次要说明，小字号用 #4A5878。

08灰度发布与回滚策略

承继 ui-refactor-prep 已定原则：分支开发、本地验证、原子发布、先备份后覆盖、新主题灰度、php -l 门禁。后台走 Filament 主题链，天然支持「新主题 + 旧主题」双轨回退。

1
分支开发
在 feature/ui-v2 分支进行；main 保持与线上基线一致。
2
本地验证
Docker 全栈（http://localhost，admin 账号，库 hxpt_prod_copy）逐页走查 + 截图比对；改配置后 redis-cli FLUSHALL。
3
语法门禁
任何 PHP 上传前 ssh hxpt "php -l …"；CSS/配置只走 git 发布。
4
原子发布
生产改为 releases/2026xxxx + 软链 ln -sfn 切换；切回即回滚。
5
灰度切换
后台主题配置项「经典 / 好学」二选一，先内测后全量；问题秒回滚经典主题。
6
稳定后收尾
观察 1~2 周无回归后废弃旧主题；清理 tmp_* 调试产物与安全债。
