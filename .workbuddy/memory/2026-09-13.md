新抓到的一手事实（替换 v1 的推测部分）：

- **TBSource 是 NexusPHP 的直接前身**（NP 官方自述 fork，2005 起，2010-03-11 停更，扁平 80 个根级 .php）；作者用 CodeIgniter 重写的 `BrokenWings` 半途而废。
- **XBTIT** 源自 phpBTTracker/TorrentBits/TBDev，bTemplate 分离模板；**双 tracker**（PHP tracker ≤10k peer，否则外挂 xbtt C++）；致命伤是 **hack 补丁式生态**（鼓励 fork 核心 → 无法升级）。
- **JS 系集体失败**：meanTorrent 自 v1.8 停止开源且有高危信息暴露漏洞，PTDream+ 2019-07 回迁 NexusPHP。教训是 MongoDB 弱事务 vs PT 计费强一致冲突 + 单维护者单点故障。
- **YemaPT** 有完整公开开放 API（wiki.yemapt.org/developer/open-api）：6 端点，含 `fetchTorrentIdWithPiecesHash`（批量 ≤100 按 piecesHash 反查 id）、临时下载凭证（30min，与 Authorization 解耦）、上传幂等建议；API AuthKey 180 天有效、每人 ≤3 个。
- **NexusPHP 有 31 条 CVE**，其中 CVSS 9.8 SQL 注入 ≥6 条（takeconfirm / linksmanage / nowarn / cheaterbox / staffbox / forummanage / modrules / reports），根因是逐文件拼 SQL + 无统一鉴权中间件。

## 本次最重要的发现（对本站风险最高）

**第三方工具生态的入场券是一张架构方言表**。ptool 的 `[[sites]] type` 可选值只有 `nexusphp | gazellepw | unit3d | tnode | discuz | mtorrent` 六种，仓库 adapter 目录与此一一对应。**TNode 证明了自研站只要 API 形状对，就能拿到与 nexusphp 平级的 adapter**——这是本仓库最该抄的作业。我们目前**零适配**。

## 由此定位到两个具体代码级缺口

1. **`torrents` 表缺 `pieces_hash` 字段**（核查 `apps/api/migrations/0001_init.sql:88` 只有 `info_hash CHAR(40)`）。piecesHash 是跨站重打包 / source 不同场景下比 info_hash 更鲁棒的二级指纹，是辅种识别的关键。补字段成本 = 一次迁移 + 上传时算一次 SHA-1。
2. **下载凭证未与长期 API key 解耦**（`apps/api/src/openapi_http.rs` 的 Token 是长期令牌且通吃下载）。

连同既有结论，**P0 排序**：pieces_hash 字段 → IPv6 compact（BEP-7，`apps/tracker/src/peers.rs` 当前 v6 peer 不进响应）→ 工具兼容层 + 公开 API 文档 → agent_rules 执行闭环。

## 结论要点

我们真正的护城河是「教育垂直域模型 + 流水式计费 + 类型安全 + 极简运维组件」；真正的风险**不是功能不够**（113 表 / 360 路由 / 53 页），而是**生态不兼容**与**教育网纯 IPv6 用户拿不到 peer**。两者都不需要重架构。

## 2026-09-13 深夜：审计修复全量入库 + jgg 测试稳定化

十板块审计五批修复（经济/种子/账号社区/基建/大项）全部提交入库。入库前复验发现一个**随机偶发失败**：

- `jgg_weights_cover_all` 断言"抽 2000 次覆盖全部 8 档"，该常数是 EV 修复**前**按最低权重 5/1000 标定的；批 1 把 50x 降到 1/1000 后没同步它，2000 次漏抽 50x 的概率 ≈13.5%，约每 7-8 次全量跑测随机红一次（本次复验恰好命中）。
- 修复：抽样次数改为 `25 * total / min_weight` 动态推算（漏检 ≈ e^-25），并加 min_weight=0 守卫断言。**规则：调整 JGG 赔率表必须三处同步——权重表、EV 断言、cover_all 抽样次数（后者现已自动适应）。**
- 教训：与权重/概率耦合的测试不要写死采样次数，应从表内最小权重推导；"连续 N 次全绿"不等于稳定，概率性测试要按失败率核算轮数。
