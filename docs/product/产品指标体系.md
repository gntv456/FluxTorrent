# 产品指标体系（2026-11-18）

> 目的：把「改版有没有用」从主观判断变成可复算的数字。工程门禁证明「没变坏」，本体系回答「是否更好」。

## 一、北极星指标

**月度活跃做种用户（MASU）**：自然月内至少产生 1 次有效做种计费事件的去重用户数。

选择理由：PT 站的健康取决于持续做种供给，而非注册数或页面浏览量；MASU 同时覆盖留存（还在）与贡献（还在做种）。

> 2026-11-19：MASU 已在管理后台总览可见（含 MAU 与做种渗透率），取数见
> `apps/api/src/repo/admin_metrics.rs`，展示见 `admin-overview-panel.tsx`。

## 二、五层指标

| 层 | 指标 | 定义 | 当前目标 |
|---|---|---|---|
| 获客 | 注册完成率 | 进入 /register → 注册成功 | ≥ 60% |
| 激活 | 首种激活率 | 注册后 7 日内打开首个种子详情 | ≥ 45% |
| 激活 | 首次做种率 | 注册后 7 日内产生有效做种 | ≥ 30% |
| 留存 | 次日签到率 | 新增用户次日完成签到 | ≥ 35% |
| 留存 | D7 回访率 | 注册后第 7 日仍有访问 | ≥ 25% |
| 供给 | 首月发布率 | 注册后 30 日内发布过种子 | ≥ 8% |
| 增长 | 邀请转化率 | 发出的邀请码中已使用占比 | ≥ 40% |
| 效率 | 首次搜到种耗时 | 首页 → 打开目标种子的中位时长 | < 90s |
| 体验 | 空态退出率 | 进入空态后 10s 内离开 | 下降 30% |
| 信任 | 规则页到达率 | 新增用户访问 /help#survival 或 /rules | ≥ 50% |

## 三、事件字典

事件落 localStorage 的 flux-ux-metrics（上限 60 条），并暴露 window.__fluxUxMetrics 供 E2E 读取；不新增后端端点、零网络开销。

| 事件 | 触发点 | label 约定 |
|---|---|---|
| signup_complete | 注册成功（登录票写入前） | — |
| app_ready | 根布局水合完成 | — |
| lcp | 最大内容绘制 | — |
| empty_state | 空态渲染 | home-latest / filter / search / dead / allEmpty |
| first_torrent_open | 点击种子链接 | cockpit-search / home-latest-category / torrents-row |
| guide_open | 帮助/新手引导入口 | survival / cockpit |
| checkin | 点击签到 | cockpit / strip |
| publish_start | 点击发布入口 | cockpit |
| invite_issue | 点击生成邀请 | — |
| filter_save | 保存筛选 | — |
| search_submit | 提交资源库搜索 | — |
| coldstart_task_open | 后台冷启动任务直达 | 任务键 |
| report_open | 从资源详情直达举报表单 | torrent-detail |

## 四、使用方式

- 客户端任意元素加 data-ux-event="事件名"（可加 data-ux-label），全局 UxMetricsProbe 事件委托自动采集，服务端组件也能埋点。
- 客户端逻辑中可直接 import uxMark(name, label, value)。
- 需要汇总到服务端时，只需替换 uxMark 的写入实现，调用点不动。



## 五、数据回流闭环（2026-11-19 补齐）

指标体系此前只有「定义」，事件只写 localStorage 且 60 条滚动，无法回答 D1/D7 回访与漏斗——本轮把闭环补齐：

| 层 | 落点 | 说明 |
|---|---|---|
| 采集 | `lib/ux-metrics.ts` | 事件上限 60→300；新增 `flux-ux-first-seen`（首访）与 `flux-ux-active-days`（活跃日，上限 90）；`uxMark` 自动记活跃日；注册成功补 `signup_complete` |
| 聚合 | `lib/ux-metrics-report.ts` | 纯函数 `computeUxReport(profile, now)`，输出 ageDays / activeDays / d1Return / d7Return / 7 步漏斗 / ttfvMs / 空态分布 / 搜索次数 |
| 可见 | `components/ux-footprint-card.tsx` | 挂 `/account-health`：用户看到自己的活跃天数、漏斗、首次找到种子用时；可导出 JSON、两段式确认清除 |
| 自测 | `scripts/ux_metrics_selftest.mjs` | `node --experimental-strip-types scripts/ux_metrics_selftest.mjs`，构造带 D1/D7 的假画像断言聚合口径；本环境已通过 |
| E2E | 浏览器读取 `window.__fluxUxMetrics` 与两个 localStorage 键，喂给同一份 `computeUxReport` 复算 | 与 UI 展示同一算法，避免「看板和报表两套口径」 |

**隐私边界**：只存时间戳与事件类型，不含用户名、邮箱、路径或种子内容；用户可一键清除（含首访与活跃日）。生产若要汇总，只替换 `uxMark` 的写入实现，聚合器与 UI 不动。

**下一步（需真实环境）**：在可跑 Playwright 的 CI 跑一遍新用户旅程（注册→首页→搜种→签到），导出 `window.__fluxUxMetrics`，用聚合器算出首种激活率与 TTFV，回填本文件并对比目标值。
