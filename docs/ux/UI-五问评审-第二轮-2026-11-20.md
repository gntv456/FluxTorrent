## P0（5 条，建议立即处理）

### P0-1　猜大小「赔率表」写的规则与实际玩法完全不是一套
- **证据**：`apps/web/app/(main)/games/bigsmall/_inner.tsx:331-352`（表体 337-351）；同页选卡 304-317；后端 `apps/api/src/games/bigsmall.rs:1-10`；词表 `i18n/zh-CN.ts:3492-3507`。
- **现状**：侧栏赔率表硬编码「1-100 数域：小 1-49 / 大 52-100 / 50·51 平局返本」。实际机制是三骰：**小 3-10 / 大 11-18 / 三同豹子判负**。同页选卡按钮已经正确写「3-10」「11-18」——一页之内自相矛盾。
- **五问**：问 1（玩家最需要知道的是真实规则）+ 问 5（错误信息无提示）。
- **后果**：玩家照表下注，以为开出 50/51 会返本；实际后端只掷 3 颗骰，押中豹子是**判负输掉全部注额**。直接误导真金白银。

### P0-2　站内信「全员」广播无二次确认、无影响面预演
- **证据**：`apps/web/components/admin-ops-broadcast.tsx:211-228`，发送逻辑 `:64-78`，人群下拉 `:24-32`。
- **现状**：人群可选 `all/全员`，点「发送广播」直接 `api.post('/pm-broadcast')`。实际送达人数只在**发送成功后**才出现在 msg 里。
- **五问**：问 5（不可逆操作无拦截与补救）。
- **后果**：群发全站不可逆，选错人群或正文写错一个字即全站可见，无撤回。

### P0-3　举报裁决「接受」直接淘汰种子，无确认、无理由、无撤销
- **证据**：`apps/web/components/admin-trumps.tsx:41-53` + 按钮 `:91-106`。
- **现状**：接受按钮 `onClick={() => act(r.id, true)}` 直接 POST `/trumps/{id}/resolve`。文件头注释 `:21` 明写「接受即淘汰被举报种（后端置 approval_status=2 + deny_note）」。拒绝侧同样无理由输入槽。
- **五问**：问 5；玩家侧也没有任何被淘汰的补救提示。
- **后果**：误点一下架一条种子，无确认、无理由留痕、无撤销。

### P0-4　审核队列取数失败被静默演成「队列为空」
- **证据**：`apps/web/app/(main)/admin/_parts/use-review-queue.ts:52-59`，`reload().catch(() => {})` 在 `:66`；渲染 `admin-queue-panels.tsx:191-195`；徽标 `admin/page.tsx:365`。
- **现状**：fetch 失败被吞，`items` 保持 `[]`，界面显示「暂无待审种子」，徽标为 0。对照同项目 `report-box.tsx:29,137`、`cheater-box.tsx:60,140` 已有 failed 态——此处是同类问题漏改。
- **五问**：问 1（不知道真实状态）+ 问 5（无错误无重试）。
- **后果**：后端抖动时审核员看到「没有待审」就停工，积压无人发现。

### P0-5　网络错误后重试 = 重复扣款（6 条路径同构）
- **证据**：
  - 下注：`games/scratch/_inner.tsx:120-147`、`capsule/_inner.tsx:182-198`、`jgg/_inner.tsx:122-138`、`bigsmall/_inner.tsx:138-192`
  - 抽卡：`components/gacha-draw.tsx:73-93`（键在 76-78，catch 在 89-92）
  - 卡册三动作：`components/gacha-album.tsx:77-94,156-179`
  - 对照正确实现：`games/wheel/_inner.tsx:72-73,129-138,256-265` **保留了同键重试按钮**。
- **现状**：每次点击都在发请求前生成**新的** `idempotency_key`；catch 只 `setErr` + 复位 busy，没有「结果未知」态。后端 `/gacha/draw` 本身支持同键重放（该文件头 `:15` 自己写明），前端浪费了这个能力。
- **五问**：问 3（做完能否确认结果）+ 问 5（补救路径）。
- **后果**：请求已到后端扣了钱、响应在 30s 超时或网关 502 丢失时，玩家看到「网络错误」再点一次 → 新键即新一局，钱扣两次且第一局结果永远看不到；bigsmall 还连带多消耗一件道具；抽卡首充体验价那 1 券也被吃掉。
