### 容错设计
- **搜索防抖**：短讯/求种/字幕三处统一 `useDebounced(400ms)`。
- **短讯打开**：本地更新已读态，不再 `setRows(null)` 让整表塌成骨架、勾选丢失。
- **详情取数失败**：就地 `ErrorPanel` + 重试链接，不再 rethrow 丢站内上下文；`getDict` 前移以在错误分支可用。
- **下载记录失败**：与空态分离 + 重试按钮。
- **磁力复制**：取磁力与写剪贴板拆两段，非安全上下文给可手抄兜底（不再误报「获取失败」）。
- **登录**：`?expired=1` 提示 + 回跳路径；剩余/耗尽尝试次数明确展示。
- **注册二次登录失败**：独立 try/catch，账号已建时引导重登并预填用户名，不再误报字段错误。
- **FieldErrors**：`form` 键友好展示、未知字段退化为不可点文本。
- **路由级 error.tsx**：`/my`、`/account-health`、`/admin` 三处，局段异常保留站点壳。
