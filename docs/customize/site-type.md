# 4. 站型与术语

> 入口：安装向导第 ① 步 / 后台「站型」。

## 站型包

11 种预置：综合 / 教育 / 影视 / 音乐 / 动漫 / 电子书 / 体育 / 游戏 / 软件 / 纪录片 / 无损。每个包携带一套：

| 快照段 | 内容 |
| :--- | :--- |
| sections | 分类树 + 维度定义 |
| tags | 受控标签词表 |
| classes | 等级门槛预设 |
| economy | 经济参数预设 |
| metadata | 元数据口径 |

- **切换即应用**（replace 模式）：不叠加、不残留——派生值走「纯覆盖」架构，改站型后前台筛选/详情即刻一致；
- **另存快照**：把当前配置存成 custom 包（五段齐全），之后可随时应用回来；
- **应用台账**（0223 起）：每次 apply 记录 diff 快照，后台可回看与回滚；
- v0.2.0 起站型应用后可再选「新手运营模板」（考核淘汰制/缓冲宽进制），与站型正交。

## 术语改名

后台「术语」可把系统词汇改成站点行话——例如把「字幕」改成「歌词本」、「火花」改成「魔力」。改名影响前台全部文案（含三语），复合词有保护（不会把「字幕组」改出半个词）。

## 主题令牌

16 个品牌色/形态键（`theme_token_*`），后台取色器即改即见；`--brand-glow` 等注入全站 CSS 变量。深改布局属二次开发范畴，改色改品牌完全无代码。
