# 3. 自定义页面与菜单

> 入口：后台 `?tool=pages`（自定义页面）与 `?tool=menu`（菜单管理）。

## 自定义页面

- 建规则页、FAQ、关于我们、活动落地页等，地址 `/p/{slug}`；
- 正文支持富文本（经消毒白名单，视频内嵌白名单同公告）；
- 可挂 `module_key`：模块关闭时页面下线，指向它的菜单项也一并消失（不留 404 死入口）；
- 典型用法：把「新手运营双模板」附带的规则页模板粘贴进来改几个字即成站规。

## 菜单管理

- 主菜单/用户菜单的条目可增删排序，支持外链与带参条目；
- 选中态匹配规则已统一（带参条目 URL 精确匹配、裸路径让位），不会出现两个菜单同时高亮；
- `module_key` 挂钩条目随模块开关显隐（如「字幕」入口在字幕模块关闭时消失）。

## 内置可挂页面

`/classes`（等级要求公开页）、`/rules`（如启用）、`/getrss` 等系统页也可通过菜单管理挂入导航——先用后挂，无需改代码。
