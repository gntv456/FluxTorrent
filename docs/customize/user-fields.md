# 1. 用户字段（自定义用户资料项）

> 入口：后台 `?tool=userfields`（「用户字段」）。

给注册表单 / usercp / 公开用户档案加自定义资料项——例如「常用 BT 客户端」「所在地区」「接收求种私信」。

## 六种字段类型

| 类型 | 值形状 | 说明 |
| :--- | :--- | :--- |
| text | 字符串 ≤500 | 单行文本 |
| number | 数字 | 含上下限 |
| select | 单选项 | 选项在 options 里维护 |
| multiselect | 多选项 ≤20 | 同上 |
| date | 日期 | YYYY-MM-DD |
| bool | 是/否 | 开关 |

> 同一套类型语义与内容侧「维度」共用一个校验器（`apps/api/src/fields.rs`），两边行为一致。

## 每个字段可配

- **required**：注册时必填与否；
- **show_on_register**：是否出现在注册表单；
- **visibility**：公开（他人档案可见）/ 私密（仅本人与管理）；
- **module_key**：挂到某模块——模块一关，字段从前台三处（注册页/usercp/档案）一并下线；
- **sort / enabled**：排序与启停。

## 行为要点

- 字段值存 JSONB（`user_field_values`），改类型不影响已存值读取，但重校验在新值写入时执行；
- 删除字段前列表会显示「已填用户数」，心中有数再删；
- 字段随全量配置导出/导入走（见升级手册），换机不丢。
