# 2. 内容维度（分类树与种子字段）

> 入口：后台 `?tool=cats`（分类）与 `?tool=sections`（维度）。

「维度」是内容侧的自定义字段系统：分类（如「电影」）之下挂维度字段（如「媒介/编码/分辨率」），用户发布与筛选时按维度选择。

## 分类层级

- 分类支持父子层级（`parent_id`），前台级联筛选；防环校验内置；
- 站型包会带一套预置分类（影视站与教育站的分类树完全不同），可在此增删改排序。

## 维度字段

与用户字段**同一套六类型引擎**（text/number/select/multiselect/date/bool，`section_kinds.field_type` + `torrent_sections.value` JSONB）：

- 每个维度定义挂在某个分类下（`mode_kinds` 关联），发布该分类种子时表单自动出现；
- 前台筛选 Chip 与 RSS/种子包等出口走同一谓词，改维度即全链生效；
- 后台「维度」列支持批量改值（运营侧 G5 收口）。

## 典型用法

| 站型 | 分类示例 | 维度示例 |
| :--- | :--- | :--- |
| 影视 | 电影/剧集/纪录片 | 媒介、编码、分辨率、制作组 |
| 教育 | 小学/初中/高中 | 科目、教材版本、年级、学期 |
| 音乐 | 无损/有损/现场 | 格式、比特率、发行年份 |

## 要点

- 维度值参与「同组版本」聚合与辅种指纹之外的资源组织；
- 改维度定义不会丢历史值（JSONB 容忍形状变化），但选项删除后旧值在筛选中不再出现——先盘点再删。
