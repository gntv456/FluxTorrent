# 7. 适配器（wasmtime 沙箱）

> 入口：后台 `?tool=plugins`（适配器管理）。

## 是什么

用 WebAssembly 组件模型接入外部数据源（如豆瓣元数据），在**沙箱**里运行，不触碰站点数据：

| 边界 | 规则 |
| :--- | :--- |
| 能做 | `fetch(url)` 拉 HTTP、读写宿主缓存、打日志 |
| 不能做 | SQL、文件系统、环境变量、改写 HTTP 响应 |
| 限额 | epoch 10s / 挂钟 25s；缓存 LRU 512 |
| 熔断 | 连续失败 ≥3 次自动熔断，后台可重试/卸载 |

## 用法

1. 后台「适配器 → 安装」上传 `.wasm`（或从内置示例启用——仓库自带 douban 示例与 SDK）；
2. 「试运行」验证输出；
3. 启用后对应元数据抓取走适配器（如发布页的豆瓣信息填充）。

## 开发自己的适配器

SDK 在 `apps/api/adapters/sdk.rs`（no_std 绑定，`sdk::entry!` 宏导出）：Rust 写逻辑 → `cargo build --target wasm32-wasip2` → 后台安装。参考实现看 `apps/api/adapters/douban/`。

## 与内容包的关系

内容包是「配置数据」的货架，适配器是「代码能力」的插件——两者独立安装，互不依赖。

## 私有反作弊挂载点（官方支持的闭源层）

本引擎 MIT 开源，检测算法与出厂默认值随源码公开（威胁模型见
[安全姿态](../ops/security.md)）。**站私有检测层**是官方支持的用法，
不是灰色地带——MIT 允许你把自己的反作弊逻辑闭源部署，只欠一份
LICENSE 声明。三条路径按投入从低到高：

1. **私有调参**（零代码）：后台「反作弊」卡片全部键改非出厂值即可。
   出厂默认人人可查，改过的值只有你知道。
2. **私有规则包**（低代码）：规则包体系支持站内自建规则——在本地
   写、私有部署、不回流上游。`agent_rules`（客户端名单）就是最常用
   的私有层：自建 UA/peer_id 特征规则只在你的站生效。
3. **私有适配器**（代码级）：用上面的 SDK 写自己的检测/数据源适配器，
   wasm 沙箱内运行。适合接外部风控数据源（如 IP 信誉、代理检测服务）。

注意：适配器沙箱**不能跑 SQL**（边界表），所以它承载不了「查流水判
作弊」这类需要全量数据的检测——那类需求提 issue 走引擎层共建；沙箱
定位是外部数据源接入与轻量计算。
