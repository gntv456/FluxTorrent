# 做种契约：把贡献变成奖励

「做种契约」是本站的一项自愿激励机制：每个月你可以给自己定一个目标
（做种体积或发种数量），达标拿大额奖励，未达标才扣罚——它把「随手挂
着」变成「有目标的贡献」，也是站点供给端最重要的稳定性来源。

## 谁能参加

注册满 30 天的账号即可参与（在「成长荣誉 → 做种契约」页签约）。

## 两种契约

- **做种契约**：按月内**日均做种体积**计量（每小时采样，月末取日均）。
  适合保种型用户——把收藏做满就是成绩。
- **发布契约**：按月内**过审发种数**计量。适合供给型用户——每月集中
  发布一批好资源。

## 奖与罚

- 达标：发档位对应奖励（例如做种 1TB 档奖励 5000 魔力）。
- 未达标：扣档位对应罚金（通常为奖励的一半以下）。罚金余额不足时
  挂账由管理组处理，不会影响账号状态。
- 签约时可勾选「自动续约」：达标自动续下月；未达标保留一次续约机会，
  连续两次未达标才停止自动续约。

## 进度随时可看

「做种契约」页会实时显示当月进度条（做种=日均体积，发布=过审数）。
计量口径也在页面上公示——不会有「算不明白被扣罚」的情况。

## 建议

新手先别急：第 1 个月先把客户端配置好、把收藏做满，观察自己的日均
做种体积再选档位。**宁可选低档达标，不要选高档被罚。**
