# 1. 获得账号

PT 站不对外开放注册。三种入站方式（站长开启哪种用哪种）：

## 邀请制（最常见）

- 拿到邀请码后在 `/register` 注册；**一码一用**，且邀请码可能与指定邮箱绑定（绑定后只能用该邮箱注册）。
- 邀请人通常是 LV3+ 等级用户（站内 `/invites` 自助生成，有周配额）或管理员直发。
- 珍惜邀请：邀请人对被邀请人有连带责任（管理侧可见邀请树）。

## 开放注册

站长阶段性开放 `/register` 直接注册（常伴随周年庆等活动）。注册时有图形验证码；一次性邮箱可能被拒。

## 申请制（部分站点）

提交其他站点的账号截图/链接作为举证，管理员人工审核通过后发放入场资格。

## 注册之后

- 首次登录按提示完成必填项（站长可配置自定义字段，如常用客户端、所在地区）。
- 建议立刻：绑定邮箱（找回密码依赖它）→ 开启 2FA（见第 7 篇）→ 阅读站内规则页。
- 新账号通常处于最低成长等级，部分站点会自动派发**新人考核**（见第 2 篇）。
