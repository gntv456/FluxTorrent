# 2. 新手生存：分享率、H&R、考核

PT 的三条生存红线。站长会选择不同的强度模板（从严的「考核淘汰制」到宽的「缓冲宽进制」），机制如下。

## 分享率（ratio）

`分享率 = 上传量 / 下载量`。提高办法：做种（上传量随做种累积）、下载免费/促销种子（不计或减计下载量）、用魔力兑换上传量。跌破下限可能被降级（低保户档）并限制下载——具体阈值见站内规则页。

## H&R（Hit & Run，保种义务）

下载完成的种子若在考察期内做种时长不足，记一条 H&R。后果阶梯（站长配置）：预警私信 → 警告累积 → 停下载权。消除途径：补足做种时长、分享率达标豁免、高等级/捐赠豁免、花魔力消除（如有开放）。**下完别急着删种**是 PT 第一守则；「我的 H&R」页可查每条记录的状态与剩余时长。

## 新人考核

部分站点对注册 N 天内的新人自动派发考核（如「做种满 120 小时转正」）。在「我的考核」页看进度条与截止时间；考核可能有奖励（火花/上传量），从严站点不过关会禁号。这是筛选真实用户的主要机制。

## 新手期建议动作

1. 先下载**免费（Free）**或做种人数多的种子——免费种通常不计下载量；
2. 保持客户端 24 小时挂机做种；
3. 每天签到领火花；
4. 看不懂的概念（辅种/魔力公式/候选）→ 第 3、6 篇。
