# 5. 消费与个性化

## 商店

魔力可兑换的货架（站长可增删改）：上传量阶梯包、邀请码、补签卡、道具、勋章、装扮（头像框/彩虹 ID/自定义头衔）。部分商品限量/限时；重复购买护栏会拦下已拥有的不可叠加品。

## 券

- **免费券**：对单个种子启用免费下载；
- **中性券**：单种上下行均不计——适合「只想保活不想刷数据」的场景。

## 勋章与装扮

- 勋章图鉴：获得条件公开（成就型/任务型/评选型/购买型），可佩戴展示、可赠送他人；
- 头像框：多款式 SKU，佩戴即时生效（个人主页/评论区等展示位）；
- 自定义头衔/彩虹 ID：展示型消费，usercp 内修改。

## 银行与捐赠

- 定期存款五档利率（7/30/90/180/365 天），到期自动结息，提前支取只还本金；
- 捐赠入「站免池」：池满触发全站免费时段，捐赠榜公开留名（部分站点给捐赠组特权如 H&R 豁免）。

## 经济小常识

魔力是持续增发的（做种就有），长期看会通胀——理性消费顺序建议：先换生存所需（上传量/消除 H&R），再换炫耀品。
