# 7. 账号安全与退出

## 登录与二步验证

- 密码登录（登录限流内置）；**2FA（TOTP）**：usercp「安全设置」扫码绑定验证器 App，登录时追加动态码；
- passkey 是你的下载身份凭证（不是登录密码）：怀疑泄露时 usercp 内**重置 passkey**，旧 key 立即失效（所有旧种子需重新下载注入）。

## API Token（给工具用）

「个人设置 → API Token」可签发最多 3 枚（180 天时效、可随时吊销、独立限流）。浏览器插件（PT-Plugin-Plus 类）、flexget、自写脚本都用它，比交出 cookie 安全。下载还有 30 分钟临时凭证机制（`downloads/keys`），适合一次性分享。

## 隐私

管理侧 IP 可见性按权限分级（仅高级 staff 可见完整 IP）；用户名/邮箱不回传第三方端点。RSS 地址含身份凭证，勿外传。

## 不活跃与找回

- 长期不登录且零做种的账号会被标记休眠（登录时提示联系管理组恢复）——保持挂机或定期登录即可避免；
- 被处罚（警告/H&R 停权）后：申诉信箱可提交申诉；部分站点开放**自助解封**（首次宽恕，冷却期内一次）；
- 注销账号：目前需联系管理组（管理侧走匿名化软删，账本与风控记录依法保留）。
