# 用户指南（user）

> 写给站点终端用户；站长可把本册连同自定义页面一起作为站内帮助内容。按一个账号的完整生命周期组织。

1. [获得账号](01-join.md)：邀请码 / 开放注册 / 申请制
2. [新手生存](02-survival.md)：分享率、H&R、考核——三种规则如何影响你
3. [日常使用](03-daily.md)：搜索下载、做种、魔力（火花）、签到
4. [成长升级](04-growth.md)：等级体系与升级条件，去哪里看进度
5. [消费与个性化](05-spend.md)：商店、勋章、头衔、兑换
6. [进阶参与](06-advanced.md)：发布种子、求种、字幕、论坛、组队
7. [账号安全与退出](07-account.md)：2FA、API Token、隐私、不活跃与找回

> 注：各站点规则不同（考核强度、H&R 时长、等级门槛均由站长配置），本指南讲的是通用机制；具体数值以站内「规则」「等级要求」（`/classes`）页为准。
