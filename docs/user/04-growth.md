# 4. 成长升级：等级体系

## 等级怎么升

等级由四个维度的门槛共同决定（数值站长配置，公开透明）：

| 维度 | 含义 |
| :--- | :--- |
| 上传量 | 累计上传 |
| 完成数 | 完成下载的种子个数 |
| 做种时长 | 累计做种小时数 |
| 账龄 | 注册天数 |

全部达标自动晋升（分钟级生效，无需申请）；标注「可降级」的等级在跌破门槛时自动降回。

## 去哪看

- **我的进度**：个人中心「下一等级」卡片显示四维当前值/要求值与完成百分比；
- **等级要求公开页**：`/classes` 列出全站等级的门槛与特权（也可从导航菜单进）。

## 高等级有什么用

邀请名额配额提升、H&R 豁免线、专属版块/权限（按站点权限矩阵）、下载并行数等——具体每级特权见 `/classes` 页。

## 顶级之后

顶级成长等级之上是职能体系（发布员/字幕组/版主/管理员，站长任命），以及荣誉向内容：勋章图鉴集齐、排行榜留名、成就达成。晋升会有站内私信通知。
