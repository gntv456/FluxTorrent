# 3. 日常使用：搜索、下载、做种、魔力

## 找种子

- 资源库支持分类/媒介/标签/促销状态多维筛选与全文搜索（标题/简介/文件名，中文友好）；
- 促销标记：Free（免费）、2xFree、50%、2x 上传等——免费种是新手积累上传量的主要途径；
- RSS 订阅：`getrss` 页生成个性化地址（含你的身份凭证），导入下载器或阅读器自动追新；
- 浏览器插件/聚合工具用户：站点提供 PT-Plugin-Plus 兼容端点与开放 API（见第 7 篇）。

## 下载与做种

1. 种子页点下载得到 .torrent（已注入你的 passkey 与本站 announce）；
2. 加入 BT 客户端（qBittorrent/Transmission/Deluge 等；部分站点维护客户端白名单，伪造版本会被拒）；
3. **保持做种**：做种时长、做种体积、做种人数都是站点统计与收益的来源；
4. 辅种：同一资源在其他站的种子若 info_hash/pieces 一致可跨站辅种（种子页有「同组版本」与辅种指纹支持）。

## 魔力（站点货币，名称以站内术语为准，如「火花」）

- **获得**：做种收益（按时结算，与做种体积/稀有度相关）、签到（连签里程碑加成）、发帖/发布/字幕等贡献奖励、考核与任务奖励；
- **明细**：「我的魔力明细」页可查每一笔收支；
- **消费**：商店兑换上传量/邀请/道具、免费券/中性券（对单个种子生效）、银行定期、捐赠入站免池等。

## 每日钩子

签到（首签/连签/里程碑）、每日任务、「更多」里的娱乐玩法（站长开启才有）。消息中心接收系统通知（审核结果/升级/预警私信）。
