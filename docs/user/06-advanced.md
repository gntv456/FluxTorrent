# 6. 进阶参与：发布、求种、字幕、社区

## 发布种子

1. 「发布」页上传 .torrent（服务端会重解析校验；重复种会被拒）；
2. 填写描述/媒介/维度/标签（按站型不同维度不同），可关联同组版本；
3. 等待审核（staff 审核通过后对外可见；拒绝会附理由私信）；
4. 发布者有绩效统计（jixiao），优秀发布者可获任命为发布员。

## 求种与候选

- 「求种」发起需求或为已有需求投票/追加悬赏（悬赏火花会冻结，被满足后转移给发布者）；
- 「候选」区投票决定哪些资源转正为官种（官方种常有魔力加成）。

## 字幕

字幕库支持上传/关联种子/版本管理；认证字幕人的产出有专属标识与奖励；部分站点开放字幕评选活动。

## 社区

- 论坛：版块发帖/回帖/投票/视频内嵌/打赏/关注；
- 短讯与好友：点对点私信、好友列表；
- 组队玩法/娱乐屋（刮刮乐/猜大小等，站长开启才有）——下注有上限与限次风控，理性参与。

## 荣誉体系

成就与勋章在个人主页展示；排行榜（上传/做种/发布/魔力各榜）是站点头部用户的竞技场；绩效考核榜对发布/字幕等职能角色公开。
