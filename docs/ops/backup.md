# 备份恢复

## 脚本三件套

| 脚本 | 用途 |
| :--- | :--- |
| `scripts/backup.sh` | pg_dump -Fc + 附件卷 tar + 14 天轮转（建议 cron：`0 4 * * *`） |
| `scripts/restore.sh --drill` | 演练模式：校验归档完整性与可恢复性，不动数据 |
| `scripts/backup_drill.py` | 定期演练自动化 |

## 后台面板

「运营 → 备份」面板可看历史归档、手动触发一次备份（容器内 pg_dump）。**恢复故意不提供网页按钮**——恢复是高危动作，只走脚本两段式（先 drill 后 force）。

## 纪律

1. 升级前必备份（回滚依赖旧代码 + 旧备份的组合）；
2. 每月至少一次 `--drill` 演练（备份不演练等于没有备份）；
3. 归档异地存放（对象存储/另一台机器）——S3 后端（`storage_backend=s3`）可直接把附件放云端；
4. 敏感项：备份含用户哈希与 IP 数据，按站点隐私政策保管与销毁。
