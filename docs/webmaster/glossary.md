# 站长常用术语小词典

看文档时遇到不懂的词，先来这翻一眼。不用死记，用到哪查到哪。

## 基础概念

- **Docker / 容器**：一种打包软件的盒子。我们这套站点是 6 个互相配合的“盒子”（数据库、网站、后台接口等），用 Docker 一把拉起来，不用你一个个手动装。
- **compose**：上面那串“盒子”的启动清单文件（`docker/docker-compose.yml`）。一句 `docker compose up -d` 就把全部盒子按正确顺序起好。
- **.env 文件**：装站用的“配置纸条”。里面写数据库密码、密钥等机密。复制 `docker/.env.example` 改成 `.env` 后填写，**不要提交进 git**。
- **迁移（migration）**：数据库结构的自动升级脚本。起服务时自动跑，你不用管。

## 跟“做种”有关的词（PT 站核心）

- **种子（.torrent 文件）/ 做种**：用户下载的 `.torrent` 文件就是“种子”；把下载完的文件继续上传分享给别人，叫“做种”。一个 PT 站能不能用，首先看用户能不能正常做种。
- **tracker（追踪服务器）**：站点的“调度中心”，负责记录谁在下载、谁在做种。它决定了用户之间能不能连上。
- **announce 地址**：tracker 的“对外门牌号”，写进每一个种子里。如果填的是内网地址（`127.0.0.1`），站外用户下载后连不上 tracker，就**没法做种**——这是新站最常见的事故。
- **passkey（密钥）**：每个用户独有的身份串，拼在 announce 地址后面（形如 `/announce/<你的passkey>`）。系统自动拼，你不用手填。

## 装站相关的词

- **站型**：11 种预置的站点定位（综合/教育/影视/音乐/动漫/电子书/体育/游戏/软件/纪录片/无损）。它决定默认的分类、维度、功能模块。拿不准就选「综合」，之后随时能换。
- **装机封锁**：向导没跑完之前，除登录/改密/健康检查外的所有业务接口都被锁住——这是**正常设计**，不是坏了。跑完向导自动解锁。
- **邀请制 / 开放注册**：邀请制（`invite_only`，默认）只有拿到邀请码才能注册；开放注册（`open`）谁都能注册。
- **幂等**：同一个操作做多次，结果跟做一次一样。安装向导可以反复打开，不会把站搞乱。

## 后台与运维

- **SMTP（邮件服务）**：发邮件的服务器配置。找回密码、邀请信、群发通知都靠它。
- **worker（工作进程）**：后台定时跑任务的盒子（发奖励、算考核、清过期数据等）。它挂了，站点数据就“不更新”了。好消息：**你不用配 crontab**，worker 盒子自己就是调度器。
- **后台**：指站点管理面板（通常 `/admin` 或后台入口），不是你电脑的桌面。
