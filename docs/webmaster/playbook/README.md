# 运营 playbook：怎么把站办好

> 前面几篇回答「怎么装、怎么配」；本册回答「**怎么运营**」——促销怎么排、考核怎么定、作弊怎么查、内容怎么从零攒起来。每篇都给能直接抄作业的参数示例。
> 数值默认对齐默认安装；你自己改过站点设定的，按自己口径重算。不懂的词查 [术语小词典](../glossary.md)。

| 篇 | 解决什么问题 | 你读完能动手做 |
