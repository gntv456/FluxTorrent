# 促销玩法编排

> 后台「促销」工具支持 6 类 × 4 范围 × 定时起止。本篇给组合打法与节奏案例。

## 能力矩阵

| 类型 | 效果 | 典型场景 |
|---|---|---|
| free | 下载不计流量 | 拉新、活动周 |
| x2 | 上传双倍 | 冲做种量、周年庆 |
| x2free | 双倍+免费 | 开站首月、重大节日 |
| half | 下载减半 | 日常温和促销 |
| x2half | 双倍+减半 | 平衡型活动 |
| p30 | 下载记 30% | 长线促销位 |

范围四档：`global`（全站）/ `official`（官方种）/ `non_official`（用户种）/
`category`（按分类）。定时：开始时间缺省立即，结束缺省按小时数（1-720h），
最长 90 天。

## 节奏案例（可直接抄）

### 开站首月（目标：留下新用户）

```
第 1 周   global x2free 168h     —— 生存压力最小化
第 2-4 周 global x2   720h       —— 有代价但方向友好
第 2 月起 official free 每周末   —— 官方种定向引流（周五设、周一撤）
```

### 周年庆（目标：唤醒沉默用户）

```
提前 1 周  global half   168h    —— 预热（配合公告）
正日 3 天  global x2free 72h
同步       复活任务加码（做种死种双倍计）+ 邮件召回
```

### 内容冷启动期定向（目标：填分类）

对空分类用 `category` 范围挂 `free`，配合「候选/求种」引导；满 50 种后撤掉，
避免"免费位"长期化让该分类失去分享率意义。

## 三条纪律

1. **全站免费不要超过连续 7 天**：下载端长期免费会摧毁分享率体系的意义，
   用户失去做种动力（上传量是唯一硬通货场景下尤其如此）。
2. **促销不增发魔力**：促销只作用于流量计费侧，不动 spark 经济
   （收支平衡另见[考核篇](03-exam-hr.md)附录）；付费种税收照常入池。
3. **每次促销配公告**：后台「群发/公告」同步说明起止，结束前不续期就不
   要吊胃口——促销信任是运营信用的一部分。

## 与其他运营件的联动

- **复活任务**：死种区促销 + 复活任务双管齐下，是清理死种的标准组合；
- **考核期**：新手考核进行中的用户遇到全站 x2free，做种时长照常累计——
  促销不豁免考核（口径见[考核篇](03-exam-hr.md)）；
- **经济仪表**：大促后看一眼下载侧流量变化，确认无异常套利
  （多账号领免费额度在限流与 IP 检查覆盖范围内）。
