# 4. 邀请与注册策略

> 三种注册模式 + 邮箱绑定 + 黑名单的组合选型。开站前想清楚「用户从哪来、坏用户怎么挡」，比事后封号便宜得多。不懂的词查 [术语小词典](../glossary.md)。

## TL;DR

- **三种模式**：开放注册（谁都能注）、邀请制（默认，凭码）、申请制（人审）。后台随时能切换。
- **邀请制三条铁律**：配额跟着等级走、邀请人连坐可配、邀请码可绑邮箱防转卖。
- **反滥用能力全内置**（验证码/邮箱黑名单/限流/IP 检查），运营上要真的去用，别开了当摆设。

---

## 三模式选型

| 模式 | 入口 | 适合 | 风险 |
| :--- | :--- | :--- | :--- |
| 开放注册 | 谁都能注册 | 冷启动拉量、内容型站 | 滥用注册/马甲；必须配验证码 + 邮箱验证 |
| 邀请制（默认） | 邀请码 | 几乎所有 PT | 邀请链条 = 信任链条，但发码过滥会失效 |
| 申请制 | 提交申请 → 人审 | 精品站/定向社区 | 人工成本高；审核标准要公示 |

三种模式后台「站点设定 → 注册模式」随时切换；`email_verify` 模式（注册后邮件激活才能登录）是第四档混合形态，可与开放注册叠加。

---

## 邀请制的三条铁律

1. **邀请配额跟着等级走**：低等级不发或发少量（等级设定里按档配），高等级多发——让邀请权成为成长奖励的一部分；
2. **邀请人连坐可配置**：被邀请人作弊，邀请人的信用要受影响（口碑上），管理组处理时在「用户管理」看邀请链（userlogs 有记录）；
3. **邮箱绑定**：定向邀请支持给邀请码绑定邮箱（消费时大小写不敏感校验），防止码被转卖/泄露后被陌生人捡用。

---

## 反滥用基线（内置能力清单）

以下都是开箱即用的，运营上要**真的去用**：

- 验证码四驱动（Turnstile/reCAPTCHA/hCaptcha/无）——生产不建议选 none；
- 一次性邮箱域名黑名单（后台「邮箱黑名单」维护，自带预置表）；
- 登录/注册限流（5 次/分）+ 账户级失败锁定（5 次/15 分钟）；
- 注册后邮件激活（email_verify 模式）拦截一次性邮箱与机器人；
- IP 封禁 + 「IP 检查」工具查同 IP 多账号（见[巡检篇](05-anticheat.md)）。

---

## 冷启动的数量建议

- 首批邀请 10–20 人，全是会做种的老手（熟人圈/可信社区）；
- 第二批按首批存活率（做种 7 天以上的占比）决定：存活 > 80% 可以翻倍放量；
- 开放注册只在大促/活动期开窗（比如周年庆 48 小时），平时关门——「开窗式开放注册」既是拉新手段也是稀缺感运营。
