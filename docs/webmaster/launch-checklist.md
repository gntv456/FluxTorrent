# 开站 checklist（放用户进来之前）

向导完成后、放开注册之前，按序过一遍。前两项是硬性的（不做用户无法做种/找回密码），其余按站点策略。

## 必做（硬性）

- [ ] **announce 地址**：后台「站点设定」`announce_url` 改为公网域名（默认 `http://127.0.0.1:7070` 是 tracker 根地址，只对本机可用；系统按 `/announce/<passkey>` 自动拼接，勿手写 `/announce` 尾缀——历史上 0034 迁移曾因此产生双重路径，0080 已纠偏并加了代码侧双保险）。若 tracker 走独立域名并终结 TLS，同时配 `https_announce_url`（种子将按 BEP12 双 tier 下发 https 首选 + http 回退）。
- [ ] **SMTP 邮件**：后台「站点设定 → 邮件」填服务器/端口/发件人。可用后台的「测试发信」给自己发一封验证。未配置时找回密码的 token 只进日志（不影响开发，但生产必须有）。
- [ ] **改 root 密码**：首次登录已强制修改；再确认后台「用户管理」里无其他演示账号（向导完成时已自动清 0，复核一眼）。

## 强烈建议

- [ ] **注册模式**：默认邀请制（`invite_only`）。开放注册前想好反滥用：验证码已内置；一次性邮箱黑名单在后台「邮箱黑名单」维护；登录/注册限流已内置（5 次/分）。
- [ ] **新手运营模板**（v0.2.0 起）：后台「运营 → 新手模板」二选一——**考核淘汰制**（入职考核 + H&R 从严 + 低保户降级）或**缓冲宽进制**（初始上传缓冲 + H&R 宽限 + 无考核）。装站时没选的话之后随时可切，切换只影响新配置项，不动已有用户数据。
- [ ] **等级门槛**：后台「等级设定」核对 12 级成长线的四维门槛（上传量/完成数/做种时长/账龄），按站点规模调；勾选「可降级」的等级跌破门槛会自动降。
- [ ] **经济阀门**：后台「经济仪表」看一眼每周产出/消耗是否平衡；`economy_max_buffer_gb`（购买上限）可防大户无限买上传量。
- [ ] **备份**：`scripts/backup.sh` 挂 cron（pg_dump + 附件卷 + 14 天轮转）；恢复演练走 `scripts/restore.sh --drill`。
- [ ] **监控**（可选）：`docker compose --profile monitoring up -d` 起 Prometheus + Grafana，五条告警规则已预置（DLQ 积压/5xx/tracker Redis 降级/Stream 积压/连接池）。

## 按需

- [ ] 站型/分类/标签词表复核（自定义手册有专篇）。
- [ ] 公开页（规则/FAQ/等级要求）：后台「自定义页面」建规则页并挂菜单；`/classes` 等级要求页开箱即用，可在「菜单管理」挂入导航。
- [ ] 关掉用不到的模块（30 个模块开关，后台「模块开关」），前台入口与后台面板会一并消失。
- [ ] 若有公网 IP 白名单/反代，参考仓库 `_doc/生产部署指南.md` 的 nginx 样例与 tracker 边缘限流参数。
