# 开站 checklist：放用户进来之前

> 服务起好、向导跑完之后，开门放人之前，按这篇过一遍。前面三项是**不做就会出事故**的硬指标，后面的是按你站点策略选做。不懂的词查 [术语小词典](glossary.md)。

## TL;DR（赶时间看这版）

| 优先级 | 项目 | 不做会怎样 |
| :--- | :--- | :--- |
| 🔴 必做 | announce 地址改成公网域名 | 用户下载后**没法做种**，站等于废的 |
| 🔴 必做 | 填好邮件 SMTP | 用户**找回不了密码**、收不到邀请 |
| 🔴 必做 | 改掉 root 默认密码、清演示账号 | 被人用初始密码登进后台 |
| 🟡 建议 | 定好注册方式 / 选运营模板 | 开放注册易被垃圾号刷屏 |
| 🟡 建议 | 核对等级门槛、经济阀门 | 数值失衡，大户失控 |
| 🟡 建议 | 挂上自动备份 | 硬盘坏/误删，数据全没 |
| ⚪ 按需 | 规则页、关模块、公网反代 | 看站点定位 |

## 🔴 必做（硬性，不做用户就崩）

- [ ] **announce 地址改成公网域名**
  - **在哪改**：后台「站点设定」里的 `announce_url`。
  - **改成什么**：默认是 `http://127.0.0.1:7070`（这是“本机专用”地址，只有服务器自己能访问）。换成你的**公网域名**。
  - **为什么**：这个地址会被写进每一个种子里。填内网地址，站外用户下载后连不上 tracker，就做不了种——这是新站头号事故。
  - **注意**：只填 tracker 的**根地址**（不带 `/announce` 尾缀），系统会自动拼成 `/announce/<用户passkey>`。手写上 `/announce` 反而会生成双重路径。
  - **进阶**：如果 tracker 用了独立域名且走了 HTTPS，同时把 `https_announce_url` 也配上，种子会同时下发 https（首选）和 http（兜底）两个地址。

- [ ] **SMTP 邮件配置**
  - **在哪改**：后台「站点设定 → 邮件」，填服务器地址/端口/发件人。
  - **怎么验证**：后台有「测试发信」按钮，给自己发一封确认能收到。
  - **为什么**：找回密码、邀请信、群发通知全靠它。没配时找回密码的链接只进日志、用户收不到——开发期无所谓，生产必须有。

- [ ] **改 root 密码 + 清演示账号**
  - 首次登录已强制你改过 `root` 密码；再确认后台「用户管理」里没有遗留的演示账号（向导完成时会自动清空，复核一眼即可）。

---

## 🟡 强烈建议（按站点策略）

- [ ] **注册方式**：默认是邀请制（`invite_only`）。想开放注册前先想好反滥用——验证码和登录/注册限流（5 次/分）已内置；一次性邮箱黑名单在后台「邮箱黑名单」维护。
- [ ] **新手运营模板**（v0.2.0 起）：后台「运营 → 新手模板」二选一——
  - **考核淘汰制**：入职考核 + H&R 从严 + 低保户降级（适合想保持活跃质量的站）；
  - **缓冲宽进制**：初始上传缓冲 + H&R 宽限 + 无考核（适合想快速积攒人气的站）。
  - 装站时没选，之后随时能切；切换只影响新配置，不动已有用户数据。
- [ ] **等级门槛**：后台「等级设定」核对 12 级成长线的四维门槛（上传量/完成数/做种时长/账龄），按你站点规模调。勾了「可降级」的等级，用户跌破门槛会自动降。
- [ ] **经济阀门**：后台「经济仪表」扫一眼每周产出/消耗是否平衡；`economy_max_buffer_gb`（购买上限）能防止大户无限买上传量。
- [ ] **自动备份**：把 `scripts/backup.sh` 挂上定时任务（pg_dump + 附件卷 + 14 天轮转）；恢复演练走 `scripts/restore.sh --drill`。**别等出事才想起来没备份**。
- [ ] **监控**（可选）：`docker compose --profile monitoring up -d` 起 Prometheus + Grafana，五条告警规则已预置（积压/5xx/tracker 降级/流积压/连接池）。

## ⚪ 按需

- [ ] 站型 / 分类 / 标签词表复核（自定义手册有专篇）。
- [ ] 公开页（规则/FAQ/等级要求）：后台「自定义页面」建规则页并挂菜单；`/classes` 等级要求页开箱即用，可在「菜单管理」挂进导航。
- [ ] 关掉用不到的模块（共 30 个模块开关，后台「模块开关」），关掉后前台入口和后台面板会一起消失。
- [ ] 有公网 IP 白名单或反代需求的，参考 [域名部署](domain-deploy.md)（含 nginx 样例 + tracker 边缘限流参数）。
