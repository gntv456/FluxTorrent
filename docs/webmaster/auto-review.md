# 自动审种（机器人审核员）使用指南

面向站长。自动审种 = 给审核队列配一个机器人助手：稳的种自动通过、明显违规的自动拒绝并邮件告知理由，拿不准的留给人。**它的每一次裁决都走人工审核的同一条管线**——信用分、促销、通知与人审完全一致。

## 三分钟开起来（推荐节奏）

1. 打开 **管理台 → 系统设置 → 自动审种**，把「启用自动审种」打开。出厂即「影子模式」：机器人只记录意见、不动任何种子——**这一步零风险**。
2. 让它跑 7 天左右（或攒够 200 个样本）。每天会收到一封站内信摘要：一致率、误杀、漏放、减负。
3. 打开 **管理台 → 自动审种**（台账页）看四指标：
   - 一致率 ≥85% 且样本 ≥200 → 可以切「半自动」（只自动通过）；
   - 半自动再观察 3 天没异常 → 切「全自动」（通过+拒绝）。
4. 每一步都可逆：模式随时改回，台账页可「按规则批量恢复」误杀的种子。

## 读懂四指标

| 指标 | 意思 | 多少算好 |
|---|---|---|
| 一致率 | 机器与人工判得一样的比例 | ≥85% 才切执法 |
| 误杀 | 机器拒了、人工却过的 | ≤2%；高了就把对应规则改「仅暂缓」 |
| 漏放 | 机器过了、人工却拒的 | ≤5%；逐例看台账里命中了什么，调阈值 |
| 减负 | 机器人替你处理的占比 | 40-70% 都正常 |

指标不好怎么办：误杀高 → 台账页找到误杀最多的规则，在设置页把它改成「只标记暂缓给我看」；减负低 → 可小幅下调「描述最少字数」或切换预设到「高效」。

## 我要改规则

全部在 **系统设置 → 自动审种**，改完保存即生效（不用重启）：

- **换预设**：「一键预设」下拉——谨慎（几乎不自动拒）/ 均衡（出厂）/ 高效（激进）/ 关闭。
- **改一条规则**：每条规则三个字段——「启用」开关、「发现后怎么办」（自动拒绝 / 只标记暂缓 / 仅记录）、「触发门槛」（数字，如相似度百分比、最少字数）。
- **加广告词**：「广告词库」多行文本，一行一个词，命中即算广告。
- **命名规范**：站型预设一键带入该站型的标题模板（影视 `{中文名}.{年份}.{来源}.{分辨率}-{组名}`、音乐 `{艺人} - {专辑} ({年份}) [{音质}]` 等）；也可以自己在「标题命名模板」里拼。命名问题默认**只提醒不自动拒**，并在意见里附「建议标题」供作者复制。
- **信任某人/盯某人**：白名单 UID 跳过自动拒绝；观察名单 UID 只暂缓不自动通过。变更都会进审计日志。

## 站型差异

不同站型审的东西不一样：音乐站强制无损文件校验、剧集站校验「标题写 12 话就该有 12 个视频」、体育站关闭重复检测（同赛事多机位属常态）。在「站型预设」里选你的站型一键套用；出厂包升级时**你改过的键不会被覆盖**，只会在页面上提示「有新预设可套用」。

## 出事了怎么办

- **误杀了好人**：设置页把该规则改「仅暂缓」→ 台账页按该规则筛选 → 点「按规则批量恢复」一键回待审。全程不用停机器人。
- **机器人失控**：单日人工推翻 ≥5 例会**自动熔断**降级为半自动并给管理组发告警；单条规则被推翻累计 ≥10 次会自动降级为「仅暂缓」。
- **彻底关掉**：预设选「关闭」。历史台账保留（审计需要），不影响人工审核。
- **被拒用户收到什么**：站内信 + 邮件（若已配 SMTP），含拒绝原因、修改建议、重新提交指引与申诉入口；同一用户每小时最多 3 封自动拒邮件，超限只发站内信。

## 常见问答

- **机器会不会误杀好人？** 会有一小部分，这正是影子模式先行的原因：影子期的每一次误杀都会在你切执法之前暴露出来。执法期还有熔断与批量恢复两道保险。
- **管理员需要一直盯着吗？** 每天看一眼摘要即可；异常（熔断/规则降级/队列积压）会主动站内信告警。
- **影子模式要一直开吗？** 不用，切执法后它自动变成「对照监督」继续积累数据。
- **和「免审」有什么区别？** 免审（连续过审、信用分、等级）是发布时就跳过审核；自动审种审的是**本来要排人工队列**的种，两者互不干扰。
- **worker 挂了会怎样？** 人工审核完全不受影响；机器人恢复后自动补评积压的待审种。
