第三章

决策五要素：L0 首屏的信息分级

把首屏信息归为五个要素，按「先判断后行动」排序。五要素全部由 已有字段 驱动， 零新增数据接口：

要素真实字段 / 来源展示形态
① 是什么t.name + t.small_descr + subtitleChain标题（h1）+ 副题链（sections 前 3 维度名拼接）+ 简介首行
② 值不值得t.size t.seeders t.leechers t.times_completed ext.views t.rating右栏 td-vitals 2×2（做种/下载/完成/感谢）+ 健康度横幅 + 规格条大小/评分

第四章

桌面端 · 双栏骨架（≥768px）

对齐 base.css 的 .td-layout 网格：head 通栏 + 左主栏 + 右信息栏（随页面滚动）。 右栏宽度 320px（≥1024）/260px（768–1023）。

├─ td-crumbs 资源库 › 高中 · #1201
└─ td-layout grid: minmax(0,1fr) 320px areas: "head side" "main side" "main rel"
  ├─ td-head grid-area:head · 200px 2:3 海报 + 主信息 + 操作区
  ├─ td-main grid-area:main · flex column gap 14
  │  ├─ td-specs 规格 chip 条（折行）
  │  ├─ td-fold × n 简介/MediaInfo/NFO/日志/在线/组版本/合集/文件/字幕/断种
  │  └─ tail 感谢者 / InfoHash / 评论
  ├─ td-side grid-area:side · 随页面滚动（不 sticky）
  │  ├─ td-vitals 2×2 大数字 + 健康度 + 查看
  │  ├─ td-files-mini 前 5 行文件 + 查看全部 →#td-files
  │  └─ td-meta 资源信息聚合卡
  └─ td-side-rel grid-area:rel · 相关种子

桌面规则

  • 右栏随滚动：.td-side 不吸附，三卡（状态/文件/元信息）与下段「相关种子」同口径随页面滚动。2026-10-16 撤销原 position:sticky; top:80px 实测依据：三卡与 td-side-rel 同处一个 grid 列，sticky 项绘制层级高于同列普通项，主栏滚到 ~700px 时 rel 顶边 218 已进卡组 80..599 区间，相关种子被压在卡背后。
  • 头部 meta 行收敛：桌面 .td-head__meta { display:none }（信息在右栏 td-meta 卡展示），<768 时重新显示。
  • 规格条折行：chip 数不定时自动换行；<640 转单行横滑（nowrap + overflow-x:auto，隐藏滚动条）。
  • 平板档（≤1024）：右栏 260px、海报 100px、文件 mini 只显前 3 行（M4 细侧栏口径）。
第五章

移动端 · 单栏 + 锚点 + 底部操作条（<768px）

不删模块，靠三层手段收敛：锚点条吸顶跳转、折叠卡按需展开、操作让位吸底条。

td-layout 单列 grid-template-columns: 1fr areas: "head" "side" "main" "rel"
├─ td-head 80px 海报 + 信息（操作区隐藏）
├─ td-anchor sticky top:72 · 简介/文件/字幕/评论 + 计数 · 横向滚动
├─ td-vitals 2×2 状态卡（文件 mini 与 meta 卡隐藏——头部 meta 行承载）
├─ td-main 折叠块默认收起，锚点点击展开 + 平滑滚动（scroll-margin-top:124）
└─ td-side-rel 相关种子回落页面底部
td-actionbar fixed 底部 · 44px 高 · ☆收藏 / ⧉复制 / ⬇下载（flex:2 主按钮）

移动规则

  • 锚点条：仅 <768 渲染（useIsCompact），sticky top 72px（顶栏下方）；IntersectionObserver 高亮当前区块；点击先展开折叠卡再平滑滚动。
  • 底部操作条：<767 显示，评论输入聚焦 / 键盘弹出（visualViewport 收缩 >25%）时自动隐藏让位。
  • 操作让位：.td-head__actions { display:none }（<768），下载/收藏/复制全部收进吸底条。
  • 规格横滑：<640 时 td-specs 单行横滑，chip 不折行（M6.3 一屏看完）。
  • 评论单栏：<640 评论左作者侧栏折叠为顶行（avatar + 用户名横排）。
第六章

组件规范（8 个核心组件 + 状态机）

全部沿用站点 Aurora 令牌（base.css :root），不新增色值；状态机补齐 hover / focus-visible / active / disabled / loading 五态。

① td-head 海报头

  • 结构：grid: 200px 1fr；海报 2:3 + 分类角标（bg_color 左上悬出）+ 主信息列。
  • 名称：h1 22px font-display，word-break: break-all。
  • 副题链：.td-head__chain 品牌蓝加粗 + small_descr 灰字。
  • 徽章行：置顶(sun) / 促销 / 剩余(red) / 官种(indigo) / 抓轨分 / 匿名(muted) 混合排布。
  • H&R 横幅：sun 底 warning 字，14 天 / 48 小时默认；关闭态 mint 底。
  • 操作区：主操作「下载」+ 心愿单 → 更多操作（互动/抢种/复活/管理）。

② td-specs 规格徽章条

  • 结构：flex wrap gap 8；chip = 值 + 灰字标签。
  • 内容：大小 / 文件数 / 分类 / sections 各维度（label + name）→ 评分。
  • 状态：hover 背景 --surface-hover；<640 横滑。

③ td-anchor 移动锚点

  • 结构：sticky 横排 Tab（sky-soft 底），当前项 sky-deep 实底白字。
  • 计数：文件数 / 评论数 小数字徽标。
  • 交互：点击 → 展开折叠卡 → 平滑滚动（scroll-margin 124px 避让）。

④ td-fold 折叠分区

  • 结构：<details> + summary（h2 + 计数 + chev 箭头）。
  • 视觉：16px 圆角白卡，summary 渐变底（--head-a → card）。
  • 打开态：shadow-hover；chev 旋转 225°。

⑤ td-vitals 状态卡

  • 结构：2×2 大数字：做种(success) / 下载(coral) / 完成(sky-deep) / 感谢(warning)。
  • 健康度横幅：is-alive 绿点光环（success-soft 底）/ is-dead 红点（danger-soft 底）。
  • 查看行：views 数值 + 「查看」标签。

⑥ td-files-mini / td-meta

  • files-mini：前 5 行斑马纹 + 扩展名徽标（sky-soft 34px）+ 大小 + 「查看全部 n」锚点。
  • meta：发布人 / 发布时间 / 最近活动 / 分类 / 合集；label 左 value 右虚线分隔。

⑦ td-actionbar 底部操作条

  • 结构：fixed bottom；三按钮 ☆ / ⧉ / ⬇（主按钮 flex:2 sky-deep 实底）。
  • 隐藏：键盘弹出（visualViewport 收缩）translateY(120%) 让位。
  • 安全区：padding-bottom 加 env(safe-area-inset-bottom)。

⑧ td-comment 评论区

  • 结构：桌面左作者侧栏 170px + 右正文；<640 单栏。
  • 嵌套回复：回复挂根楼层、组内缩进一层平铺 + 「回复 @xxx」标注。
  • 动作：点赞 / 回复 /（staff）删除，无权限后端 403 兜底。
