二、设计规范（甜梦蓝 · 奇迹暖暖风）

2.1 色板（CSS 变量已在 arcade-sweet.css 定义）
变量色值用途
--sweet-cream#f4f8fd页面底色（奶油蓝白）
--sweet-mist#c5dff0浅雾蓝（卡片渐变起始）
--sweet-sky#8ab4dd主蓝（按钮/选中态）
--sweet-sky-deep#4a7ab0深海蓝（标题/强调文字）
--sweet-lilac#b8c8e8淡蓝紫（辅助渐变）
--sweet-gold#d4af7a香槟金（点缀/角标/头奖）
--sweet-gold-deep#b08a4a深金（按钮文字/描边）
--sweet-ink#2c3e5c深海军蓝（正文）
--sweet-ink-soft#5a6b8c次要文字
--sweet-line#d8e4f2分隔线/边框
2.2 字体与材质
  • 标题字体：Noto Serif SC（衬线冕，900字重）
  • 正文字体：Noto Sans SC（无衬线，400/700字重）
  • 圆角体系：28px（大卡片）/ 22px（中卡片）/ 16px（小卡片）/ 999px（胶囊按钮）
  • 阴影：柔和蓝雾投影（rgba(74,122,176,.25)），金色阴影（rgba(212,175,122,.4)）
  • 材质母题：缎带细线、烫金描边、珍珠柔光、衬线冕
2.3 多端断点与布局策略
断点宽度布局当前 GameShell 对应
折叠屏外屏280-360px单列，紧凑默认单列
直板手机360-680px单列，stage+controls 堆叠grid-cols-1
折叠屏展开680-880px单列加宽，side 可浮层lg 以下仍是单列
三折叠全展开880-1024px双栏（stage+side）需加 md 断点
iPad 平板768-1024px双栏，side 240px需加 md 断点
桌面1024-1440px双栏，side 280pxlg:grid-cols-[1fr_280px]
宽屏桌面1440px+三栏（stage+controls+side 加宽）需加 xl 断点

关键改造点：GameShell 当前 lg:grid-cols-[minmax(0,1fr)_280px] 只在 1024px+ 才出侧栏。需要加 md: 断点让 768px+ 就出侧栏（缩窄到 220px）。

五、开发步骤（按优先级）

Phase 1：CSS 补全（纯样式，不改 TSX）
  1. 在 arcade-sweet.css 末尾追加 ⑩-⑭ 块（约 200 行）
  2. 覆盖 BalanceBar / HistoryStrip / GameShell 返回栏
  3. 覆盖各游戏舞台组件（jgrid / cap-machine / lw-disc / fp-pond / plot-bed）
  4. 加多端断点（md:768px 出侧栏）
  5. Dev server 热更新验证视觉效果
Phase 2：UI 模块增强（改 TSX，纯展示层）
  1. 刮刮乐：在 controls 区加票种选择 Tab（10/100/1000）
  2. 猜大小：在 side 栏加赔率表面板
  3. 转盘：在 controls 区加奖池切换 Tab
  4. 农场：确认三栏布局在桌面端正常显示
  5. 所有游戏：确认 side 栏在 md 断点正常出现
Phase 3：多端适配验证
  1. DevTools 切 280px（折叠屏外屏）— 确认不溢出
  2. 切 680px（折叠屏展开）— 确认双栏合理
  3. 切 880px（三折叠）— 确认三栏不挤
  4. 切 768px（iPad）— 确认侧栏出现
  5. 切 1440px（宽屏）— 确认三栏舒展

六、注意事项

6.1 不要改的东西
  • 不改后端 API 调用：所有 POST/GET 路径和参数保持原样
  • 不改游戏逻辑：下注、开奖、结算逻辑一行不动
  • 不改 i18n 字典：文案由 dict.games 提供，不硬编码
  • 不改 GameShell 组件签名：只通过 CSS 覆盖视觉，不改 TSX props
6.2 CSS 覆盖纪律
  • 所有选择器必须以 [data-arcade="sweet"] 开头，作用域隔离
  • 不改全局 TIDE 令牌，只在本作用域内覆盖
  • 用 !important 压过 Tailwind 工具类（如 bg-sun / bg-mint）
  • 不新增 npm 依赖，纯 CSS 覆盖
6.3 已知风险
  • 登录凭据 root/password123 验证失败，无法实际验证游戏页效果
  • 部分游戏舞台底图是位图（/games/stage-*.jpg），CSS 覆盖可能压不住
  • GameShell 的 grid-cols 是 Tailwind 工具类，CSS 覆盖需要转义方括号
