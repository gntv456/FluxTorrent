壹 · PHILOSOPHY
01

设计理念：从「潮汐蓝」到「甜梦奇境」

现有 TIDE 主题是冷静的工程感蓝白，适合 PT 站的种子/论坛主域；但娱乐屋是用户「卸下压力、抽卡碰运气」的情绪场， 需要一套与之互补、甚至略有反差的童话语言。奇迹暖暖之所以迷人，不在粉色本身，而在 「缎带 + 水晶 + 烫金 + 衬线字」四种材质叠出的精致感。本方案把这种材质语言抽象为可复用的设计令牌。

🎀 情绪定位

像走进一座藏在花园里的糖果宫殿。每一次刮奖、每一次转盘停下，都应该像拆开一份包装精致的礼物—— 仪式感大于刺激感，陪伴感大于赌博感。

💎 材质关键词

乳白玻璃、丝绸缎带、香槟烫金、珍珠柔光、蕾丝花边、水晶切面。 所有组件都要有「被精心包装过」的边缘细节，拒绝扁平色块。

✨ 交互承诺

每次下注/开奖都配「缎带展开 + 星屑飘散 + 水晶高光」三段式动效， 让 1 秒的等待变成值得期待的小仪式。

贰 · COLOR TOKENS
02

色彩系统：雾蓝 × 香槟金 × 淡蓝紫

主色从现有 --sky / --gold / --lilac 三个语义位派生，全部走柔雾冰蓝明度（L≥75）， 避免高饱和宝蓝。每个颜色都同时给出 hex / 用途 / 与 TIDE 令牌的映射，方便落地。

落地提示： 在 theme-tide.css 旁新增 arcade-sweet.css，仅在 /games/* 路由下 @import，用 [data-arcade="sweet"] 作用域覆盖令牌——主站其余页面保持 TIDE 蓝白不变，零回归风险。

03

字体与排版：衬线为冕，圆体为礼

06

娱乐屋大厅：一座藏在花园里的糖果宫殿

大厅是用户进入娱乐屋的第一印象，也是现有 /games 页面的重构目标。 保留现有信息架构（Hero → 分组卡片 → 纹章/周常/赛季/背包），但把每一层都「包装」成礼盒。

📐 大厅分区与视觉层级

① Hero 迎宾台粉金渐变云雾底 + 飘落樱花瓣（CSS 动画） 大标题「甜梦奇境」用衬线金色渐变；右侧悬浮一座水晶旋转木马插画（生成图）；下方三颗数字宝石：今日已开启 12 款游戏 / 本周累计奖励 8,420 火花 / 连续好运 5 天。
② 分组标题缎带横幅 「即时开奖 · Instant」与「养成经营 · Session」两个分组标题，用粉色缎带横贯，两侧配卷草金纹，替代原来的「分组线+数字」。
③ 游戏卡片网格3 列 × 2 行（桌面） 9 张游戏卡，每张顶部圆形宝石图标（取代 emoji 直出），角标「3.8x」用金色缎带胶囊，「HOT」用红色小皇冠。卡片 hover 时浮起 + 轻微倾斜 2° + 星屑闪现。

07

九款玩法逐页设计：各有各的童话布景

共用同一套组件库，但每款游戏有自己的场景色调与核心交互仪式。 下面按现有路由顺序逐一给出界面方案。

🎯
猜大小 · Big/Small
INSTANT · 雾蓝水晶骰桌

7.1 猜大小 —— 水晶骰局

  • 场景：一张铺着蓝丝绒的赌桌，中央悬浮两颗透明水晶骰子，骰面数字是烫金衬线。
  • 交互：下注金额用「珍珠滑块」调节（拖动乳白珍珠，刻度是小水晶）；选择「大 / 小 / 围骰」三个缎带按钮。
  • 开奖：点击「摇骰」后骰子在水晶杯中滚动 1.2s，伴随叮铃声，停下时金光爆闪 + 数字翻转。
  • 赔率角标：现有 1.9x 倍率写在玫瑰金缎带上，贴在赌桌右上角。
  • 禁忌：不用红色/绿色赌桌——保持雾蓝冷调，避免与赌场风混淆，符合 PT 站教育气质。

INSTANT · 冰蓝信封礼盒涂层

7.2 刮刮乐 —— 信封里的星尘

  • 交互：支持鼠标/手指拖动刮开，刮开区域用 canvas 实现；刮开 60% 自动判定。
  • 中奖：刮出三个相同宝石（💎👑🌹）时，信封自动裂开，花瓣从卡片里飘出 2 秒。
  • 奖池：现有 scratchPoolText 放到信封封口的火漆印里，hover 展开。
  • 多连刮：底部一排未刮信封缩略图，像一副牌，点哪张刮哪张。

7.3 九宫格 —— 命运宝石盘

  • 场景：3×3 圆形宝石阵，每格是一颗切面紫水晶，背面写着奖品名。
  • 交互：点击一颗宝石 → 它先悬浮、发光、裂开，露出奖品；其余宝石变灰。
  • 未中奖：宝石碎裂成星屑缓缓落下，配一句温柔文案「下次一定更好」，不做嘲讽。
  • 奖池预览：底部一排迷你宝石图标，hover 显示奖品名与概率（沿用现有 prizes 数据）。
  • 十连抽：加一个金色「连开十次」按钮，十颗宝石按顺序依次裂开，节奏感 0.3s/颗。

捌 · MOTION
08

动效规范：三拍式开奖仪式

奇迹暖暖的精致感一半在动效。我们为所有「开奖/获得」统一一套三拍节奏，避免每个游戏各做各的。

第一拍 · 期待（0–0.6s）

按钮按下 → 缎带从中心展开 → 水晶高光汇聚 → 背景压暗 15%。 这一拍让玩家进入「屏息」状态。

第二拍 · 揭晓（0.6–1.4s）

结果物（卡片/宝石/胶囊）放大弹出，带 3D 旋转 15°； SSR/大奖时全屏撒金色星屑，普通奖只在卡片周围飘 5 颗小星。

第三拍 · 余韵（1.4–2.2s）

奖励数字翻滚计数 → 缎带缓缓收回 → 「收入背包」按钮淡入。 全程 ≤ 2.2s，不拖泥带水。

克制原则： 非开奖场景（浏览大厅、查看规则）不主动动效； 尊重 prefers-reduced-motion，系统开了减弱动效就只保留淡入淡出。 背景飘落花瓣/羽毛全局只在 Hero 区出现，不铺满整站。
玖 · ROLLOUT
09

落地策略：与 TIDE 主题共存，零主站回归

不推翻现有 TIDE 主题，而是给娱乐屋单独开一个「皮肤」。

样式隔离新建 apps/web/app/styles/arcade-sweet.css，仅在 /(main)/games/** 布局里 import； 所有规则挂在 [data-arcade="sweet"] 作用域下，不污染全站。
令牌覆盖把 --sky / --coral / --sun / --mint 在该作用域下重映射为雾蓝/冰蓝/金/薄荷雾； 组件类名（.gc-card / .arc-*）不变，只换皮肤。
图标替换现有 emoji 图标（🎯🎫🎰🥚🎡🌾🃏🐾🎣）保留为兜底； 第一期用内联 SVG 宝石图标替换，二期再补 Lottie 动效。
图片素材Hero 水晶旋转木马、各游戏场景插画用 image_gen 生成 16:9， 风格关键词：Soft watercolor, pink cream, gilded details, Nikki miracle style, lace ribbon, transparent background。
分期P0（2 周）：令牌 + 大厅 + 按钮/卡片组件换肤； P1（3 周）：5 款即时游戏（猜大小/刮刮乐/九宫格/扭蛋/转盘）逐页改造； P2（2 周）：4 款养成游戏 + 动效 + 宠物/装扮联动。
验收桌面 1440 / 移动 390 两档截图对照； 夜间主题 baozi-night 下娱乐屋自动切「深紫星空版」（奶白底 → 深紫底，金描边保留）。
