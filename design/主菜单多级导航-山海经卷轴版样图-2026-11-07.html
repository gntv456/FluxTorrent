第一套是「横向逐级列 + 四档换皮」；这一套是主题驱动布局：山海经两档（岩彩 / 宣纸）改用纵向卷轴结构 —— 层级从上往下展卷，已展开层收成题签，当前层用册页宫格。数据树、path 状态、点击逐级展开的口径与第一套完全一致，变的只是信息架构与视觉语言。

一级展卷 → 二级 → 三级 → 四级 → 五级 已展开层 = 卷首题签，当前层 = 册页宫格 岩彩 / 宣纸 双档实时切换 状态：样图阶段，未改业务代码
01

为什么要第二套结构

换皮解决不了「卷轴感」；竖排、题签、册页是结构层，不是令牌层
维度第一套 · 标准横向列第二套 · 山海经卷轴
层级方向由左向右追加列，已展开列并列可见由上向下展卷，已展开层收成窄题签，只有当前层铺开
当前层形态竖排链接列表（每行一项）册页宫格卡片（编号 / 名称 / 子级数 / 箭头）
路径呈现顶部横向面包屑卷首印章式路径 + 逐层朱文题签（壹贰叁肆伍）
溢出策略第 5 列起列窗横向滚动卷身纵向滚动并自动滚到最新卷；窄屏天然单列，无需第三套
动效新列 160ms 横向滑入新卷 180ms 自上而下展开（unroll）
不变的部分同一棵 NavNode 树、同一个 path、点击逐级展开、叶子才导航、跨层级搜索、面包屑可回退
取舍：横向列擅长「同时比较多级」，卷轴擅长「层层深入、有仪式感」，代价是跨层比较要回滚。所以按主题分流：brand / brand-night 用第一套（效率优先），shanhaijing / shanhaijing-light 用本套（沉浸优先）。两套共用数据与状态，只替换渲染壳。

04

交互与视觉规格

布局 / 尺寸

面板min(760px, 100vw - 36px)，居中，圆角 3–4px（方册页），金箔/纸纹外描边
题签已展开层级收成 40px 高窄条，朱文方印标层级（壹贰叁肆伍），点击回退到该层
当前卷册页宫格 repeat(auto-fill, minmax(146px,1fr))，卡片 78px 起，窄屏降到 120px
高度min(62vh, 470px)，卷身独立纵向滚动 + 自动滚到最新卷
动效新卷 180ms 自上而下展开；prefers-reduced-motion 下关闭

状态 / 无障碍

触发点击展卷，不用 hover；点叶子卡片才导航，点带子级的卡片展开下一卷
路径卷首印章式面包屑 + 逐层题签双通道，任一段可点回退
字体卷题 / 册页名用宋体系（--serif），编号与元数据用等宽；两档同
键盘Esc 关闭 / ← 回退一卷 / 斜杠聚焦搜索；焦点陷阱、关闭后归还触发按钮
对比度岩彩深底正文用石绿亮档 #8fdcbd、金色 #e6c87a，避免原色在暗底不达标（沿用现有主题校准口径）
