第一步 · 参考拆解：成熟内站为什么一眼能认

实证来源：仓内研究快照 .np-research/np/public/pic/category/chd/scenetorrents/（CHD 分类精灵图 catsprites.png + css，45×46px 每格）、NexusPHP 经典 pic/cat*.gif 贴图体系、M-Team / TTG 等现代扁平站点的公开界面截图。

  1. 固定主色 = 分类身份：CHD 精灵图每格一个饱和底色（蓝=电影、绿=动漫、紫=MV、橙=体育），用户靠颜色就能预筛，形状只是确认。
  2. 满底色块 + 白色强剪影：CHD 每格是「色块 + 白色剪影 + 分类汉字」三段式，剪影只占格内约 50%，45px 下依然利落。
  3. 道具化具象，不用抽象符号：电影用胶片盘、体育用 ESPN 牌、音轨用八分音符——道具自带语义，不需要学习。
  4. 文字/品牌梗当图形锚点：BBC（纪录片）、MTV（MV）、禅（动漫）——把字/logo 直接当图标用，辨识度极高。
  5. 小尺寸只留 2–3 个视觉锚点：CHD 剪影没有内部细节，细节全在色块和文案上。
  6. 选中/归属态 = 整格上色反白：色块本身承担「选中」语义，白图形永远落在他自己的主色上，对比天然成立。

取舍：学①②③⑤⑥（固定主色、双色面性、道具化、少锚点、满底反白选中）；不学老式 NexusPHP 插画级 GIF（细节在 22px 全糊）、不搬第三方品牌 logo（版权风险 + 与山海经气质冲突）、不学多彩虹渐变（暗底下脏、与玄墨/石青体系打架）。文字梗只学思路不照搬——本站分类名已在色块旁有文字列，图标保持纯图形。

V2 个性化设计口径

  • 双色体系：主色（剪影）+ 单强调色（细节/高光），16px 下每图锚点 ≤3 个。
  • 道具清单：电影=爆米花桶（取代 V1 场记板，与「看片」场景绑定更可爱）、电视剧=圆角电视+天线+播放键、短剧=竖屏手机+爱心、综艺=派对礼花筒+星星、纪录片=摄像机+地球纹镜头、动漫=圆脸+星星眼+呆毛、音乐=双音符+CD 孔、有声书=耳机+耳罩高光、游戏=手柄+十字键、软件=窗口+光标箭头、电子书=摊开书+行线、教育=学士帽+流苏、体育=篮球+高光、兜底=收纳箱。
  • 近义分类区分不靠颜色：电影（桶+爆米花轮廓）/ 剧集（横屏+天线）/ 短剧（竖屏+心）/ 综艺（礼花+星）/ 纪录片（摄像机+镜头）——剪影形状两两不同，色盲与反白态仍成立。
  • 选中态 = 满底主色块反白：20×20 圆角色块（贴齐 CHD 手法），白色图形 + 主色镂空细节，22px 下镂空不丢。
  • 颜色全部令牌化：SVG 内 style="fill:var(--cat-general-movie-primary,#D94444)"，亮/暗底两套取值由消费处 CSS 变量覆盖，SVG 单文件可直接 <img> 渲染（回落亮底色值）。

实现说明

1. 命名约定

  • V2 全部位于 design/icons/v2/，文件名沿用 V1：分类 key（kebab-case）+ -active 选中态；V1 原样保留在上级目录，不删不改。
  • 兜底：cat-other.svg / cat-other-active.svg（收纳箱）。

2. 主色令牌定义（接入时放主题层，本任务未动生产样式）

/* 每类三个令牌：primary 主色 / accent 强调色 / on 反白图形色（一般恒 #fff） */
:root {
  --cat-general-movie-primary: #D94444;   --cat-general-movie-accent: #FFE9C2;
  /* …其余 13 类同构，暗底作用域覆盖 primary 为提亮值（见上表）… */
}
[data-theme="brand-night"], [data-theme="shanhaijing"] {
  --cat-general-movie-primary: #F26A60;   /* 暗底提亮版 */
}

3. 如何接入

  • 并入 icons.tsx：V2 是多色图形，与 PATHS 的单色 currentColor 口径不同，建议新增 CatIcon 组件（或 <img src> / inline 注入），按 categories.key 选文件；icon_key 词表可扩展为分类 key 本身。
  • 列表 40×40 色块：现状是 bg_color 块 + 白色 glyph。V2 选中态（*-active.svg）天然就是「主色块 + 白 glyph」，可直接替换 CatBlock 内层；默认态双色版适合无底色块的场景（筛选 chips、侧栏、详情页头）。
  • 尺寸建议：类型列 22px、筛选 chips 16px、导航/分区头 20–24px、详情页头 32–48px。
  • fallback：未配图的分类（其他站型包专有类）→ cat-other；icon_key 空 → 维持现有首字色块。

4. 与 V1 的量化对比（见文末结论区，渲染核对后填写）

  • 可辨识锚点数：V1 单锚点（剪影轮廓）→ V2 2–3 锚点（剪影 + 主色 + 强调细节）。
  • 撞车分类：V1 中 电影/剧集/短剧/综艺 四类共用两种几何（film/tv）；V2 五类几何两两不同。
  • 选中态：V1 实心剪影（细节丢失）→ V2 满底反白 + 镂空细节保留。
