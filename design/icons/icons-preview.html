实现说明

1. 命名约定

  • 文件名 = 分类 key（categories.key，kebab-case）：general-movie.svg；选中态追加 -active：general-movie-active.svg。
  • 未配套图的分类统一兜底：cat-other.svg / cat-other-active.svg。
  • 为什么用 key 不用数字 id：数字 id 随物化顺序漂移（0455 迁移用 max(id)+seq 分配），key 才是跨环境稳定标识。

2. 网格与视觉口径

  • 24×24 viewBox，2px 安全区（坐标 2~22），描边 1.5px、round cap/join —— 与 components/icons.tsx 头注释中的既有规格一致，可直接并入 PATHS 表。
  • 默认态：线性 fill="none" stroke="currentColor"；选中态：面性 fill="currentColor"（必要细节用 fill-rule="evenodd" 挖洞）。两态同几何剪影，切换不跳位。
  • SVG 不内置色值，颜色一律 currentColor：亮/暗品牌主题与山海经主题只需给容器设 color。

3. 如何接入（生产侧，本任务未改动）

现状：分类图标走 categories.icon_key（站长后台可改），前端 components/icons.tsx 的 PATHS 表按键名渲染，种子列表「类型」列 CatBlock 为 40×40 色块内 22px 图标；筛选器与导航目前不用分类图标。空键 / 未注册键回落「首字色块」。

  • 最小接入：把本套 SVG 的 path 数据并入 icons.tsx PATHS（新增 key：shortdrama、audiobook、variety、movie 等），后台 icon_key 改填新键即可，无需改组件结构。
  • 两态接入（可选）：筛选 chips / 侧栏等需要选中态的位置，给容器一个 .is-active 类切换引用 *-active 路径，颜色用主题令牌：color: var(--compat-cinnabar, #b23a2e)（山海经暗底建议用提亮朱砂或金箔令牌）。
  • 尺寸建议：列表类型列维持 22px / 40px 色块；筛选 chips 用 16px；导航/分区头用 20~24px；详情页头可用 32~48px。本套图标按 16px 最小档做了笔画取舍，四档渲染均经核对。

4. 未覆盖分类的 fallback 规则

  • 其他站型包（movie/music/anime/ebook/education/game/software/sports/documentary/lossless）的分类与 general 语义重叠（如 movie_tv=电视剧、ebook_audio=有声书），直接复用同语义图标：映射建议——电影/电视剧/综艺/纪录片/音乐/有声书/电子书/教育/游戏/软件/体育各自共用本套同名词条。
  • 无语义对应的扩展分类（如 edu 包的 K12 学段、sports 包的球种）：用 cat-other，或由站长在后台改 icon_key 选已有近义图标；后续按本规格补画专属图标（24 网格 / 1.5 描边 / currentColor / 两态成对）。
  • icon_key 为空或未注册：维持现有「首字色块」回落（CatBlock 已内置该逻辑），不要在前端硬编码 if-else 补图。

5. 颜色与主题

/* 生产映射示例（不写进 SVG，由消费处控制 color） */
.cat-icon            { color: var(--text-primary); }              /* 默认态随正文 */
.cat-icon.is-active  { color: var(--compat-cinnabar, #b23a2e); }   /* 选中态：朱砂 */
[data-theme="shanhaijing"] .cat-icon.is-active { color: var(--compat-gold, #d4a24e); } /* 暗底可换金箔 */
