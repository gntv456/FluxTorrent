规格

结构底图层（潮汐美术）→ 品牌带 126px → 磨砂抽屉（position:sticky 升起）。桌面 ≥1024px 仍走现有双栏 .bz-login-canvas，新结构只在 @media (max-width:640px) 生效。
抽屉圆角 18px 18px 0 0 = --r-xl；内边距 22px 20px calc(20px + env(safe-area-inset-bottom))；底色 --surface-card，玻璃开时自动半透（glass.css 的 color-mix 族，不写 hex）。
字段高 52px（保持现状）、圆角 --r-md 10、左图标 20px、右眼睛热区 30 → 44；焦点环 0 0 0 3px --focus-ring。
按钮主按钮 52px 全宽 --grad-aurora；次按钮 44px 两列 gap --sp-2 8。全站触控下限 --tap-min:44px 在本页首次全部达标。
字号h1 25/800、正文 15、辅助 13、说明 11.5。原辅助链接 11.5px 提到 13px（--fs-sm）。
动效抽屉升起 --motion-slow 320ms + --tide-ease；PoW 进度条 --motion-slow 循环；prefers-reduced-motion 下全部换成瞬时切换。
降级glass_alpha=100 或 prefers-reduced-transparency → 抽屉实心、美术只露品牌带；@supports not (backdrop-filter) 同上。不手写 -webkit-backdrop-filter。
断点只用 640 / 768 / 1024 / 1280（ui_design_guard 口径），窄屏规则写进 @media (max-width:640px)。
验收node apps/web/_chk_auth_mobile.mjs（390×844 无横滚 + 主按钮 ≥44）新增一条判据：主按钮 top < 视口高，把「首屏可见」钉成硬门。

要你拍板

  • 「记住登录」是装饰。现状 <input type="checkbox" defaultChecked /> 无 state、不进请求体，后端 LoginReq 也没有该字段。要么接真语义（延长会话有效期，需要后端加字段），要么从界面撤掉——样张先按「保留并接真语义」画。
  • 手机端底图默认开不开。潮汐美术现在靠站长配 login_page_bg_url（0446/0447）；本方案要它手机端默认走内置场景、配了就用配置的。这动的是「默认观感」，得你定。
  • 帮助折叠的代价。收进抽屉省 ~140px，代价是封禁/申诉四条少一次可见性。折中方案（只折叠非高频三条）已按此画；要全常显就得接受主按钮下移。
  • 成功后的去向文案。登录跳转是 next 参数、默认 /torrents（资源库），不是「首页」——样张里没写「下一步」这类词，落地时也别引入。
