交互与可达性规则
1hover 浏览 + 点击直达并存：悬停带子级的一级条正下弹第一层；点击一级条本身仍进该频道首页，两者不互斥。
2纯 CSS 驱动：展开全由 :hover / :focus-within 控制，无 JS 状态机；键盘 Tab 走 focus-within 同样能逐级展开，可达性不降级。
3叶子 = 链接直达；带子级行 = 悬停右飞（›）；分组名（空 href）= 只展开不跳转，三类行形态严格区分。
4选中点亮口径：带参条目仅当 URL 参数集合完全一致才点亮；带参条目命中时，裸路径的父级让位。当前页（如「三年级」）以 is-lit 高亮并上溯点亮父链。
