落地说明 · 与现有主题机制的接法
◈ 三步接入（现有机制原生支持，组件零改动）
  1. lib/themes.ts 注册表追加 shanhaijing: { chrome: "#0a0f0d", scheme: "dark" }；scheme 已落注册表，auto 深色档经 themeIdByScheme("dark") 命中，无双真源。
  2. 新建 app/styles/theme-shanhaijing.css，只写 [data-theme="shanhaijing"] 变量块（与 theme-tide.css 同法），挂到 globals.css @import 链末端。
  3. i18n 三语补 themeShanhaijing（中：山海经 / 英：Mythica / 繁：山海經）；键名由 themeNameKey(id) 推导，tests/theme-registry.test.ts 门禁三语齐全。

五档：≤1180px 图鉴收图标轨 · ≤1024px 紧凑边距 · ≤768px 移动帧（抽屉 + 底部 TabBar，顶栏修为收起）· ≤640px 单栏收敛（区块头换行、落地表可横滑）· ≤400px 收尾（用户只留头像）。竹简表固定轨宽不再顶破页面：整表 overflow-x:auto 横滑（卷轴心智），表头与数据行同一滚动容器天然同步；Hero 题字 clamp(40px,9vw,76px) 随宽缩放。

◈ 兼容与降级

• 系统若开启「减弱动态效果」，自动关闭视差与入场动画（已实现）。• 异兽配图以水印方式呈现，加载失败自动隐藏，不影响页面。• 移动端（≤768px）：侧栏收进抽屉（点 ☰ 打开，点空白处或 Esc 关闭），底部保留 TabBar（首页/搜索/献宝/传讯/我的），与正式版结构一致——换主题不改操作习惯。• 双视图切换钮支持键盘操作，键盘聚焦时显示金色光环。• 全站聚焦光环统一为金色，口径与正式版 base.css 一致，不会出现有的组件有光环、有的没有。• 「百器演武」节的按钮、输入框、开关、弹窗、提示气泡、空态均可真实点按：弹窗支持 Esc 与点空白处关闭，关闭后焦点回到打开它的按钮，打开期间 Tab 键只在弹窗内循环；提示气泡 3.5 秒自动消失，读屏软件也能听到内容。• 「换肤」与「结构改造」两份范围/工作量清单见《山海经 UI 设计系统》伍章。
