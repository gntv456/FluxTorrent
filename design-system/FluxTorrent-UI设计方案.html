01设计哲学与品牌策略

在动笔之前，先厘清 FluxTorrent 是什么、用户是谁、现有界面卡在哪里，再决定「美」往哪里走。

现状诊断：从「包子站复刻」到「自有品牌」

当前 globals.css 是开发过渡态——像素级复刻 BaoziPT 的暖橙纸质风（#fbf3e6 米黄底、#ed5a17 橙、楷体标题、🥟 emoji Logo）。它能跑，但与项目策划案规定的品牌内核存在三处偏差：

维度现状品牌目标
气质市井暖橙、餐饮感清新现代、可信专业
图标emoji 直接渲染lucide 线性图标，统一笔画
导航26 项平铺单行分组收敛 + 智能收纳
质感纯平纸质卡片极光渐变 + 磨砂玻璃高光

核心品牌资产（传承，不推翻）

  • 猫头鹰学士：知识与守护的化身，用于空态 / 加载 / 登录页情感锚点。
  • PT 十级段位：Peasant → User → Power → Elite → Crazy → Insane → Veteran → Extreme → Ultimate → Nexus Master，段位色阶递进，是用户在站内的身份徽章。
  • 贴纸徽章：白描边 + 微旋转 −2°，承载免费 / 2x / 官种 / 新手等运营标签。
  • 彩虹彩带：五色渐变条，用于进度、横幅、分隔——全站的「品牌心跳线」。
  • 蜡笔字标题：ZCOOL KuaiLe，仅用于 H1 / 等级名 / 品牌语，控制在极小面积以维持「童趣但不幼稚」。

设计概念：Seedlight · 流光种子

「种子在光里萌芽」是整套视觉的母题。Flux（流动的光）+ Torrent（奔涌的种流）合而为一：用极光般的流动渐变象征知识的流动，用水滴 / 种子形态的圆润语言象征生命的萌发。我们保留卡通贴纸的温度，但把材质从「印刷纸」升级为「晨雾中的磨砂玻璃」——更现代、更通透，也更耐看得久。

一句话设计主张：童趣的形，成人的效率。视觉上让新用户愿意停留；数据上让长期做种的老司机一眼看到分享率与收益，tabular-nums 对齐、对比度 ≥4.5:1、触控 ≥44px。
