## 总评

**未发现 P0 级可直接套利的洞。** 计费核心链路（announce 增量换算 + 物理速率上限 + 幂等键）与资金动账管线（事务 + FOR UPDATE 行锁 + spark_ledger 幂等唯一索引）的设计明显高于 NexusPHP 平均水准；管理端三个 http 层逐文件核查**零漏挂守卫**。真正的问题集中在：一个确定性可套利的农场市场价（P1）、若干部署/配置依赖型风险（XFF 首值、FLUX_DEMO、CORS 通配），和两个越权/爆破缺口（附件无属主校验、TOTP 无失败锁定）。

## P1 — 应尽快修（4 项）

### P1-1 农场市场价确定性套利（已回源码核实，且比子代理结论更重）
`apps/api/src/games/farm.rs:173-193`：买种因子与收获因子都是「窗口起点时间戳的纯哈希」（xorshift64*，无秘密盐），**任意未来窗口的价格可离线预计算**。代码注释声称「错开 salt 后无确定性正 EV 策略」，但 salt 只让两因子独立、不消除可预测性：作弊者筛「买种因子低 × 收获因子高」的窗口集中种植即锁定正收益。且标定闸 `base_yield ≤ 0.75×seed_price`（farm.rs:101）与种子表实际不符——博士参 1900/2000=0.95、状元稻 4800/5000=0.96，**高档作物收益比远超 75% 水位**，套利空间被进一步放大（两因子独立均匀于 50..150 时约 35-40% 的窗口组合 ROI>1，极端 2 倍+）。
**修法**：收获因子改为收获时刻服务端真随机（复用 `roll_double` 的 thread_rng），或混入服务器秘密（HMAC(secret, window)）；并补一个「枚举 10^4 窗口断言不存在 ROI>1 可达组合」的回归测试；种子表收益比与标定闸对齐。

### P1-2 附件读取无属主/可见性校验（IDOR）
`apps/api/src/attachment_video.rs:82-105`：`GET /attachments/{sha}` 只验登录 + sha 形状，SQL 无 user_id 过滤——**知道 sha 的任意成员可读任意附件**（私信截图、内部稿等）。sha 是 SHA3-256 不可枚举，但 URL 会被嵌进帖子/简介，帖子编辑删除后 URL 仍残留于历史/日志/转发。全站去重使同内容共享一行，也无法按人撤销。
**修法**：attachments 加 visibility 或「上传者 + 被引用帖子可见者」判定；管理端补按 sha 的属主查询与下架。

### P1-3 TOTP 失败不进账户锁定计数
`apps/api/src/auth_http/login.rs:144-181` + `twofa_http.rs:170-201`：acctlock 只在**密码错误**分支递增；密码正确后 TOTP 错码仅落 login_events。密码已泄露的攻击者可对 6 位 TOTP 持续尝试（仅受 5 次/分双维 throttle 约束，换 IP 即绕 IP 维度）。
**修法**：TOTP 失败同样递增 acctlock（或独立 `totp_fail:{uid}` 5 次/15min）；补 RFC 6238 同窗口防重放。

### P1-4 XFF 取首值的部署依赖（api + tracker 同款）
`apps/api/src/http/auth_infra.rs:62-85`、`apps/tracker/src/http_track/helpers.rs:102-125`：TRUST_PROXY=1 时取 X-Forwarded-For **首值**，前提是「反代追加而非覆盖」。若反代误配为透传客户端自带 XFF（nginx 常见 `proxy_set_header X-Forwarded-For $http_x_forwarded_for`），攻击者可任意伪造 IP → 绕过 ip_bans、轮换绕过 login-ip 限流、污染 cheat_events 取证。
**修法**：改为「可信代理网段」模型——仅当 socket 对端属于配置的代理网段才采信 XFF，并取最后一个非可信跳；启动时校验反代配置或在文档部署检查清单中强制项化。

## P2 — 计划修复（按域分组）

**传输作弊面（tracker/worker）**
- 首报盲区：`process_event.rs:137-140` 无基线时按 900s 计 allowance，换 peer_id/换种子可反复首报吃满额度 → 收紧为 min(300s, seed_cap/2) 或首报大增量进强告警。
- 幽灵做种：connectable 抽样 5min/50 peer 覆盖不足，CONN_UNTESTED 且虚报 1 字节 uploaded 即可绕过「不可达且零上传」过滤，持续攒 seeded_seconds（放大场景：复活任务 240h=5000 魔力+免费券）→ 抽样改「可疑优先」+ 未被回连的做种行进报表。
- 附件读取与 .torrent 下载无 per-user 限流（登录用户低成本打 IO）→ 复用 throttle() 加 60/min。

**经济面（资损向为主，非作弊向）**
- funding_contribute 扣款与出资记录跨事务，spawn 退款 best-effort，崩溃窗口「钱扣了无记录」→ 照 pool_donate 收口单事务。
- shop 效果 CAS 先置位后执行，apply 失败则「花钱买空气」永远补不回（shop.rs:255-266）→ CAS 移到 apply 成功后或并入同事务。
- farm 浇水/施肥占位回滚是独立语句，失败即免费加速 → 与收获同款单事务。
- bigsmall 倍率券（×1~×5）不受 EV 闸约束，若站长把 5x 券放进低 anchor 池档即成增发口（bigsmall_props.rs:243-248）→ mult 道具纳入经济闸校验。
- gacha 种子 = 时间纳秒 ^ uid 喂 mulberry32（弱 PRNG，roll.rs:87-93）：当前不外泄、不可利用（历史接口不含 seed 已核实 me.rs:69），但预防性换 thread_rng。

**鉴权/前端**
- CSRF 仅靠 SameSite=Lax + CORS 预检，而项目声明兼容不支持 SameSite 的旧内核浏览器 → 全局非 GET 中间件校验 Origin/Referer 同源。
- CORS 白名单条目无形状校验，误填 `*` 即通配（main.rs:68-97）→ 构建时校验 `^https?://[^/]+$` 并拒绝 `*`。
- 易支付匿名 GET 回调仅靠 MD5 验签（donate_notify.rs:17）→ 加回调 IP 白名单、强制密钥长度下限。
- 残留 `class_id>=90` 字面量与 perm 体系双轨（auth_infra.rs:286 等）；`flux.session`(12h) 与 jwt_ttl(可配 720h) 生命周期漂移；dedup 附件用户侧零配额占用；档案页无遍历限流。

**注入/SSRF 快扫结论**
- SQL：同义词白名单、LIKE 通配转义、排序枚举白名单，未发现可利用注入；`setting_i64`/`META_SELECT` 系列 format!-SQL 虽是常量键名仍建议参数化（代码卫生）。
- 命令注入：唯一入口 `backup_docker_exec`（admin_p3_http/ops.rs:76-104）需 SETTINGS_MANAGE 且值来自站长配置——建议 argv[0] 白名单化。
- SSRF：PTGen 有 host 后缀白名单（但 `ends_with("imdb.com")` 放行 evil-imdb.com，改精确匹配）；adapter 沙箱设计良好但 reqwest 跟随重定向可跳内网（关 redirect + 私网段黑名单）；**Web Push endpoint 仅校验 https:// 前缀，用户可注册内网地址让站点代发 POST**（内网探测 oracle）。

**部署/配置红线（站长自查）**
- FLUX_DEMO=1：跳过装机封锁 + 绕过支付网关直接入账（settle.rs:123）——**生产镜像严禁携带**。
- TRUST_PROXY=1 只有在 api/tracker 仅经可信反代可达时才可开。
- 仓库根 `_jwt.txt`（本地签发的管理员 token）已 git-ignore，注意勿拷入镜像/备份。
- 根目录管理员口令 password123 窗口：首启到完成向导之间存在（有 must_reset 闸门），文档应强调立即完成向导改密。
