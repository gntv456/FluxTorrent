# PT 游戏策划：钓鱼玩法

- **日期**：2026-09-29
- **作者**：纳纳
- **状态**：策划稿（未落地）
- **定位**：§9 二维评估排名第二——**好玩性中高 + 魔力回收高**。本质是 `jgg` 九宫格 + 稀有度图鉴 + 每日幸运连击 + 鱼竿升级 sink。

---

## 1. 目标与定位

- **核心价值**：把"每日签到 + 随机产出 + 收集图鉴 + 装备成长"揉成一个低门槛日常玩法，兼具留存钩子与回收能力。
- **经济定位**：抛竿本身 EV<1（同 `casino` 三件套回收口径）；**鱼竿升级是额外 sink**，把回收力度进一步拉高且不破数值。
- **参考**：`casino.rs`（`jgg`/`scratch` 的 `spend_spark`/`earn_spark`/`idem_key` 口径）、`helpers`、`JGG_TICKET` / `MAX_BET` 常量。

## 2. 核心循环

```
每日抛竿(固定票价,EV<1) → 随机渔获(按稀有度权重) → 入图鉴 → 累计幸运连击
        │                                                      │
        └──────── 鱼竿升级(花魔力,sink)→ 提升幸运倍率 ──────────┘
```

## 3. 数据模型（SQL 草图，迁移号需避让最大号）

```sql
-- 鱼种图鉴（种子数据）
CREATE TABLE fishing_catalog (
  id      BIGSERIAL PRIMARY KEY,
  name    TEXT NOT NULL,
  rarity  SMALLINT NOT NULL,   -- 1普通 2稀有 3史诗 4传说
  weight  INT NOT NULL,         -- 抽取权重
  payout  BIGINT NOT NULL       -- 基础产出(魔力)
);

-- 鱼竿等级（升级即 sink）
CREATE TABLE fishing_rods (
  level      SMALLINT PRIMARY KEY,
  cost       BIGINT NOT NULL,        -- 升到该级花费
  luck_bonus NUMERIC(4,3) NOT NULL   -- 幸运加成, 如 0.05
);

-- 用户钓鱼状态
CREATE TABLE fishing_luck (
  user_id        BIGINT PRIMARY KEY REFERENCES users(id),
  streak         INT NOT NULL DEFAULT 0,   -- 连续抛竿天数
  luck           NUMERIC(5,3) NOT NULL DEFAULT 0, -- 当前幸运倍率
  last_cast_date DATE,
  rod_level      SMALLINT NOT NULL DEFAULT 1
);

-- 渔获记录
CREATE TABLE fishing_records (
  id         BIGSERIAL PRIMARY KEY,
  user_id    BIGINT NOT NULL,
  fish_id    BIGINT NOT NULL REFERENCES fishing_catalog(id),
  payout     BIGINT NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_fr_uid ON fishing_records(user_id);

-- 图鉴收集(去重)
CREATE TABLE fishing_dex (
  user_id  BIGINT NOT NULL,
  fish_id  BIGINT NOT NULL,
  first_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (user_id, fish_id)
);
```

## 4. 经济设计

| 项 | 数值（建议，走设置键） | 说明 |
|---|---|---|
| 抛竿票价 | 50（同 `JGG_TICKET` 思路） | 受 `games_max_bet` 约束 |
| 稀有度权重 | 普通 60 / 稀有 28 / 史诗 10 / 传说 2 | `weight` 列 |
| 产出倍率 | 1 / 3 / 10 / 50（×票价） | `payout` 列 |
| **EV 约束** | 加权产出 < 票价（EV<1） | 同 `scratch_odds` 双源校验 |
| 幸运连击 | +2%/天，封顶 +30% | 作用于产出倍率 |
| 鱼竿升级 | 多级，累计花费递增（sink） | `luck_bonus` 提升 |

> 产出 = `票价 × 稀有度倍率 × (1 + luck)`，EV 由 `weight × 倍率` 加权保证 < 1。

## 5. 玩法机制

- **抛竿**：`spend_spark(票价)` → 按 `weight` RNG 出鱼 → `earn_spark(产出)`。幂等（重放不重开，同 `scratch`）。
- **稀有度图鉴**：首次钓到入 `fishing_dex`，集齐发限定称号（挂钩 `medals`）。
- **每日幸运连击**：连续日抛竿 `streak+1` → `luck` 累加，断签归零。
- **鱼竿升级**：花魔力升 `rod_level` → `luck_bonus` 提高（**sink**，不返魔力）。
- **排行榜**：最大单渔获 / 累计渔获（复用 P0 挑战赛排行思路）。

## 6. 接口设计（复用 `helpers`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET  | `/games/fishing/state` | 当前 luck / rod / streak |
| POST | `/games/fishing/cast` | 抛竿，复用 `check_bet`/`check_rate`/`idem_key` |
| GET  | `/games/fishing/dex` | 我的图鉴 |
| POST | `/games/fishing/rod` | 鱼竿升级，`spend_spark(cost)` sink |
| GET  | `/games/fishing/leaderboard` | 排行榜 |

抛竿 / 升级走 `spend_spark`；产出走 `earn_spark`；下注受 `games_max_bet` 约束。

## 8. 风控

- 抛竿 / 升级全部幂等（`idem_key("fish"|"rod", uid, client_key)`）。
- 每日限次 + 连击日期服务端校验（`last_cast_date`）。
- EV 常量走代码 + 设置键双源，站长可调但强制 < 1。
- 审计：`fishing_records` 落库。
