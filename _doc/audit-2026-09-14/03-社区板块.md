# 社区板块审计报告（agent_bb9133c0）

## 缺陷清单

### [P0] 黑名单不挡私信
- 位置：apps/api/src/community_http.rs:1128-1145（message_send）
- 证据：注释声称"须过 accept_pm + 非黑名单"，但只匹配 accept_pm，从未查 friendships.list='black'。实测 B 拉黑 A 且 accept_pm='yes' 后 A 仍发信成功（id=139 并正常 markread）。
- 修法：!staff 分支增加 EXISTS(friendships WHERE user_id=$to AND friend_id=$me AND list='black') 则拒绝。

### [P1] 成就体系无 worker，授予恒为 0
- 位置：migrations/0079_v4_gaps.sql:8-33 定义 9 条并注释"worker 周期扫描授予"，但全代码库无授予任务逻辑（与 worker 审计 P1 achievement_grant SQL 炸弹为同一断链：任务存在但 SQL 报错，user_achievements=0）。
- 证据：gaozhong 已有 3 个过审种子（up_1 阈值 1 应得 200 火花）、chuzhong 4 个——多个用户"该授予未授予"，/me/achievements 永远 earned=false。
- 修法：修好 worker 的 achievement_grant SQL（见 07 报告 RETURNING 修法）即可闭环。

### [P1] 工单状态机自洽性破裂
- 位置：community_http.rs:1959-2029（ticket_update）/ 1649-1705（staff_answer）
- 四态 0新/1处理中/2已答复待确认/3关闭之间无合法跳转约束：实测 3→0 关闭重开 200 OK；answered=1 的单也能随意改状态。
- staff_answer 只写 answered=1 从不更新 ticket_status（注释称"顺带置 3"但代码缺失）：实测答复后 answered=1, ticket_status=0——"已答复"永远停在"新"，列表 ORDER BY ticket_status ASC 把它当新单置顶。
- staff_mark(:1713) 可把未答复单置 answered=1 而 answer 为 NULL，用户端永远看不到答复内容。
- 修法：staff_answer 同步 ticket_status=2；ticket_update 加流转白名单；answered 单禁随意回 0。

### [P1] 好友无申请/接受/拒绝流程
- 位置：community_http.rs:1759-1786（friend_add）
- 直接单向写 list='friend'（schema 的 pending 值从未使用），对方不知情即成"好友"；且绕过 accept_pm='friends' 隐私屏障（加一行好友即可私信）。实测 add 后立即发信成功。
- 修法：写 pending+站内通知，新增 confirm/reject 端点，双方 friend 才算好友。

### [P1] 种子评论无删除/编辑端点
- 位置：apps/api/src/http.rs:1331 + torrents.rs:400
- 仅创建+列表；实测 DELETE /torrents/{id}/comments/{cid} 与 /comments/{cid} 均 404。用户和版主都无法删评论，只能 SQL 手工清。新闻评论端点整个不存在。
- 修法：补 DELETE（作者本人或 TORRENT_MANAGE）并挂 audit。

### [P2] 论坛列表无分页
- community_http.rs:649（topic_list LIMIT 50 硬编码）、:710（topic_detail LIMIT 200 无 offset）：超 200 楼帖子永远看不到后续楼层，已读标记只能记到第 200 楼。

### [P2] 未鉴权读取聊天盒
- community_http.rs:1053-1062（shoutbox_list）无 require_auth，匿名 200 拉最近 50 条含用户名发言；/shoutbox/bot(:2130) 匿名可访问（仅命令表低危）；medal_list(:83) .ok() 允许匿名浏览。其余社区端点匿名全 401。

### [P2] 勋章购买竞态+扣款不回退
- community_http.rs:105-189（medal_buy）：owned 检查→spend→INSERT 三步非事务；限量勋章并发超卖窗口；INSERT ON CONFLICT DO NOTHING（并发已拥有）时扣款不退。medal_gift 同构。

### [P2] 删主题收火花不对称
- community_http.rs:943-951：删主题回收楼主 +2，但删他人回帖（post_delete）不回收回帖者 +1。

### [P2] 误导性返回值/杂项
- message_delete(:1395) 返回 deleted=ids.len() 而非实际行数；post_edit 作者编辑自己帖也写 edited_by=自己（NP 口径仅编辑他人留痕）；topic_manage 移动版块只查目标存在，本版版主可把主题移入自己无权限的版块。

## 已验证闭环（实测）
1. 论坛：版块门槛过滤→发主题+2→回复+1→has_unread 翻转正确→置顶/锁帖生效锁后回帖 400→删主题 posts/topic_reads 级联零孤儿。
2. 论坛权限边界：非版主置顶/删 403；作者不能删自己帖（NP 口径）；非版主不能编辑他人帖；class≥90 postmanage 全版块管帖。
3. 私信：unread→markread 仅 receiver 生效→逻辑删→双删物理 DELETE→accept_pm=no/friends 拦截→staff 豁免→60s 防刷→Re:/转发。
4. 工单：contactstaff 60s 防刷→普通用户 403 于列表/流转→无效状态/越权指派 400→重复答复 400→priority 0-3 校验。
5. 评论/感谢：amount 白名单（7 被拒）。
6. 勋章：购买/佩戴事务化单佩戴位回滚正确。
7. 成就端点 9 条定义四族返回正常（授予缺失见 P1）。
