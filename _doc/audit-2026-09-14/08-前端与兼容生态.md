# 前端 web + 兼容生态审计报告（agent_77d65be1）

## 缺陷清单

### [P1] Torznab enclosure 的 passkey 是字面量占位符，Prowlarr 拿到必 401
- 位置：apps/api/src/economy_http.rs:1477-1530
- 证据：/api/v1/torznab/search 返回 enclosure url="...download.php?id=4&passkey=PASSKEY"（PASSKEY 原样输出）；实测无效 passkey → 401。Prowlarr 下载器直接用该 URL，全部下载失败。
- 修法：torznab_search 鉴权通过后由 token 反查所属用户 passkey，填入 enclosure/link 的 passkey= 参数。

### [P1] Torznab 不支持标准 apikey 查询参数鉴权，Prowlarr 无法注册
- 位置：apps/api/src/economy_http.rs:1477 + openapi_http.rs:37-46
- 证据：?apikey=<passkey> → 401（require_token 只读 Authorization: Token 头）；Prowlarr 通用 Torznab 以 apikey 查询参数（或 X-Api-Key）发送凭据。
- 修法：torznab_search 先尝试 q.get("apikey")，失败再回退头部。

### [P2] Torznab link/enclosure/guid 均为相对 URL
- 位置：economy_http.rs:1513/1519
- 证据：<link>/api/v1/compat/...</link>、<guid isPermaLink="true">torrent-4</guid>（非 URL）。
- 修法：从请求 Host 头拼绝对 URL；guid 改 isPermaLink="false" 或绝对详情页 URL。

### [P2] RSS link/guid 相对路径、channel link 为空
- 位置：apps/api/src/rss_http.rs（item 构造段）
- 证据：<link></link> 空链、item link=/torrent/24 相对路径，阅读器无法跳转。
- 修法：用外部基址拼绝对 URL。

### [P2] staffmessages answered 参数反序列化失败返回裸文本，击穿 JSON 信封契约
- 位置：apps/api/src/community_http.rs:1616
- 证据：?answered=false → HTTP 400 纯文本 "Query deserialize error"（非 {code,message,data} 信封）；前端降级为 ApiError(1000,"服务异常")。前端发 0/1 不受影响。
- 修法：StaffMsgQuery 的 answered 用 Option<String> 自行解析或错误映射到信封 1002。

### [P2-备查] 裸 /torznab、/rss 根路径不存在（仅 /api/v1/*）
- 属设计选择而非缺陷；如需兼容老工具可在网关/反代加 rewrite。
