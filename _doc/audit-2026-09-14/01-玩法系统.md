# 玩法系统审计报告（agent_18d23ecb）

## 缺陷清单

### [P0-1] 考核工资（jixiao）任意用户可自选任意岗位领取，min_requirements 全站为空 —— 无上限铸币
- 位置：apps/api/src/ops_http.rs:103-190（jixiao_claim）
- 问题：POST /jixiao/claim {type_id} 无岗位归属校验——不查 jixiao_claims 中的 admin 分配记录，任何登录用户可自选 type。且校验循环依赖 jixiao_types.min_requirements，全站 7 个类型该字段全为 {}，校验空转。
- 复现：root 连续领取 type_id:6（+500）和 type_id:5（主管 +50000）均 code:0；每用户每月可扫全部类型 ≈89,500 火花。
- 修法：claim 必须先验证当期存在 source='admin' 的分配行且 type 匹配；min_requirements 为空对象时应视为"未配置"拒绝发薪（或套用默认要求线）。

### [P0-2] 农场种植：幂等键含分钟窗口 + Replayed 扣款仍全额退款 —— 并发重放白拿火花
- 位置：apps/api/src/games_http.rs:275-303（farm_plant）
- 问题：idem = farm-plant:{uid}:{slot}:{now/60}；spend_spark 返回 Replayed 时调用方不检查直接继续。同槽同分钟第二个请求（换高价作物）：不扣款+槽占用失败+按本次高价 price 全额退款入账。窗口高价时状元稻退款额 = 5000×1.5 = 7500/次，理论 45,000/分钟无上限。
- 复现：并发两请求 slot=6 crop=1/crop=5，ledger 出现 farm-refund +2850 / farm-plant -57。
- 修法：退款金额以该 idem 在 ledger 中的实际扣款额为准；spend_spark 返回 Replayed 时直接返回错误（本请求未付费），不进退款分支。幂等键去掉 now/60，改客户端 idempotency_key。

### [P1-3] 农场收获恒正期望 + 市场窗口可预知 —— 无风险挂机产出
- 位置：apps/api/src/games.rs:98-113 + games_http.rs:377-384
- 问题：EV = base_yield×1.2 > 1（五档全部，crop5 5760/5000=1.152）；市场价窗口起点确定性推导，玩家可只在 ≥某因子窗口收割（单周期 +45%）。6 槽状元稻 ≈ 4 万/96h/账号。
- 修法：base_yield 下调使 EV(含双倍)<1（crop5 ≤4000）；或收割价按 planted 窗口锁定，削弱择窗套利。

### [P1-4] H&R 处罚链断裂：violated 之后无任何自动处置
- 位置：apps/worker/src/jobs.rs:976-992
- 问题：violated 只写 hr_violations 表 + 日志，无 PM/警告/禁下载/扣火花，唯一出口 staff pardon 或自费 20000 免罪。
- 修法：violated 落表同时发 PM + 置 hr_flag/警告计数，接入下载权限闸门。

### [P1-5] 众筹退款非事务且绕过统一管线 —— 半途崩溃导致用户永久损失退款
- 位置：apps/worker/src/jobs.rs:1560-1580（funding_settle ②）
- 问题：退款 = 裸 INSERT + 独立 UPDATE，无事务无行锁不走 earn_spark；fundings 先置 status=2 再退款，崩溃后该众筹永久退出结算集合，未完成的退款丢失；balance_after 未写。
- 修法：每笔退款包事务（或复用 earn_spark）；状态推进放到退款全部成功之后。

### [P1-6] hr_flag 硬编码与 hr_policy 可配口径脱节
- 位置：apps/worker/src/jobs.rs:995-1001
- 问题：快照/考核按 t.hr_policy 逐种可配，但 hr_flag 刷新硬编码 14 days/432000s。30d/96h 种子会被错误打标或漏打。
- 修法：hr_flag 改为 join torrents 取 hr_policy，或由 hr_snapshots.status 派生。

### [P2-7] 游戏限次在 Redis 故障时形同虚设
- 位置：games_http.rs:44-56：incr unwrap_or(0)，Redis 不可用时限流静默失效（fail-open）。建议 fail-close 或告警。

### [P2-8] 赌类端点无客户端幂等键
- 位置：games_http.rs:73/118/155：idem 用服务端 Uuid::new_v4()，超时重试双扣。建议接受并校验客户端键。

### [P2-9] 九宫格概率展示与实现严重不符
- 位置：games_http.rs:36 展示旧赔率表（38%/2%/0.5% 含 100x），实现为 73.1%/12%/6%/5%/2.5%/1%/0.3%/0.1% 无 100x 档，EV 0.725。同步展示文案。

### [P2-10] 排行榜：hourly 榜恒空 + seedtime 榜混入 0 值
- 位置：content_http.rs:543-600：hourly JOIN s.seeding 当前无做种行恒空；seedtime 未过滤 val>0，0.0 小时用户上榜。补 HAVING sum(...)>0 与空榜兜底。

### [P2-11] 补签后签到页 streak 显示错误
- 位置：economy_http.rs:1241：current_streak 取 rows.last() 含 makeup=true streak=0 行 → 补签当天显示连签 0。排除 makeup 行即可。

### [P2-12] 连签里程碑 >30 天后永久不再触发
- 位置：economy.rs:17-30：bonus 仅在 streak 恰为 10/20/30 时发，31 天起只剩 base 5。改为 streak % 30 == 0 循环发放。

### [P2-13] fun_vote 先占位后校验，回滚 DELETE 竞态
- 位置：games_http.rs:466-521：并发时非法分支 DELETE 可能把合法占位一并删掉；校验前置到 INSERT 之前。
