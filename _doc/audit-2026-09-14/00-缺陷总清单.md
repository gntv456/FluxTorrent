8 个板块并行深审完成，全部结论均有实测/SQL 证据。分报告见同目录 01~08。

## P2 — 汇总（30 项，明细见各分报告）

**安全类**：封禁不 bump tracker 缓存（≤60s 窗口）、API Token 不校验用户封禁状态、前端 token 双存 localStorage+非 HttpOnly Cookie、Redis 故障时限流/登出撤销 fail-open、2FA 关闭不验密码、serde 错误细节回传、聊天盒匿名可读。
**口径类**：pool_month UTC vs 视图 UTC+8、活期利息离账铸造、minted 含 refund、RSS 未拦 suspended、/detail 与主详情口径不一、thank 无状态校验、views 伪造、scrape 无用户级限流、排行榜 hourly 空/seedtime 0 值、补签 streak 显示、连签 >30 天断档、九宫格概率展示不符、hr_flag 双轨（同 P1-14）。
**健壮性**：勋章购买竞态+扣款不回退、fun_vote 回滚竞态、message_delete 返回值失真、staffmessages answered 裸文本 400、无审计 6 处、参数校验散缺（min_class 负值/3000 字符版名/空 FAQ/class_id 存在性）、Torznab/RSS 相对 URL、scrape downloaded 恒 0、限流键永生、死 swarm 无 Prometheus 不回收、任务无 last_run 落库、商店权益字段写了没人读（ad_free/vip_until）。

种子 API 层全链（上传/审核/可见性/下载闸门/评论感谢/删除/越界探测全 403）、tracker HTTP 协议层（BEP3/6/48/事件流转/passkey 校验/轮换联动）、认证核心（JWT/2FA/RBAC/IDOR/注入/CORS/限流 11 项）、银行结算幂等、签到/抽奖（EV 庄家优势）/成就端点/众筹资金链守恒（80=80）、规则版本化、POSTPONED 四态、对账端点、全量余额=流水对账 0 差异、前端 420 处 API 引用零死链、tsc 零错误、i18n 三语 key 一致。
