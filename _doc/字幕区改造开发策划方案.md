# 字幕区改造开发策划方案

> 版本：v1　日期：2026-09-21
> 依据：`字幕区横向对比与改造建议.md`、`PTP与KG字幕功能深度调研.md`、`专业字幕站调研与参考价值.md`
> 原则：**不重写，做增量**。字幕区的「形」与「存储」已比 NexusPHP 更干净，缺的是真实数据、治理闭环和流量入口。

---

## 1. 目标与边界

**目标**：把字幕区从「能看」做到「能用、能管、能激励」，同时压过 NexusPHP（治理）与 UNIT3D（工程化）的字幕区。

**四条硬约束**（本仓库既有约定，违反必返工）：

| 约束 | 说明 |
|---|---|
| 站型参数化 | 字幕区是影视/动漫站的模块，音乐/教育/软件站应可关。已存在 `modules.rs:36 SUBTITLES` + 页面 `requireModule("subtitles")`（`app/(main)/subtitles/page.tsx:10`）+ 导航 `layout.tsx:74` |
| 货币名不硬编码 | 用户可见文案一律 `{magic}` 占位符（`site_settings.currency_name`，默认「魔力」），三语字典同步 |
| 迁移号避让 | 当前最大迁移号 **0145**（`0145_tagline_override_only.sql`，共 143 个文件）。**创建前必须重新 `Glob apps/api/migrations/*.sql` 确认**，本仓库有并行会话撞号事故 |
| 改完要重建容器 | `docker compose -f docker/docker-compose.yml up -d --build api worker web`，sqlx 迁移在 api 启动时自动执行 |
| **新端点必须落在已登记前缀下** | 模块网关 `modules/gateway.rs:38` 只登记了 `/api/v1/subtitles` 前缀。新增端点命名成 `/api/v1/subtitles/xxx` 才会被自动拦截，否则模块关闭时仍可访问（维护纪律 D2，见文件头注释） |

### 1.1 字幕区开关机制（已确认可用，站长后台可控）

**结论：站长建站后在后台开关字幕区，这套机制已经存在且可用，本次改造不需要新建。**

三层结构（**运行时权威在中层，站长改了就永久生效，切站型不会覆盖**）：

```
site_type_packs.modules.subtitles   ← 站型初始快照（建站/切站型时打底）
        ↓ 覆盖
site_settings.module_subtitles      ← 运行时权威（后台开关写这里）  ★站长改的是这个
        ↓ 读取
modules.rs / gateway.rs             ← 导航、页面、API 三处一致拦截
```

| 事实 | 位置 |
|---|---|
| 注册表条目已存在：`('subtitles','字幕','Subtitles','字幕上传/下载/火花奖励','community',TRUE)` | `0107_module_registry.sql:48` |
| 后台分组 = **社区模块**（i18n `module_community`），站长在设置中心可见可切 | `i18n/zh-CN.ts:1936` |
| 读取逻辑：`site_settings.module_{key}`，值 `yes` 开、`no` 关；**键不存在时回落 `default_on`**（非 showcase/social/contests 均默认开） | `modules.rs:100 / 117-161` |
| 缓存 TTL 30s，后台保存时 `invalidate()` 主动失效 | `modules.rs:145-166` |
| **切站型不覆盖站长已改的开关**：pack 打底 + `module_*` 覆盖 | `staff_http/sitetype.rs:69-87` |
| API 网关按路径拦截（fail-close，4101） | `modules/gateway.rs:38` + `main.rs:186` |
| 页面门控 | `app/(main)/subtitles/page.tsx:10 requireModule("subtitles")` |
| 导航门控 | `components/layout.tsx:74` |
| **音乐站/无损站 `subtitles=true` 是有意为之**（音乐站传歌词字幕） | `0107:98-99`（用户确认，非笔误） |

| 级别 | 缺口 | 证据 |
|---|---|---|

| P1 | 无 release name / IMDB 匹配（只有 `ILIKE`） | 对比 addic7ed VERSION NAME |
| P1 | 无编辑/删除、无审核态/verified、无 anon | 对比 UNIT3D CRUD |
| P2 | 无求字幕悬赏（KG pots 形态） | 对比 Wikipedia pots + OS `AddRequest` |
| P2 | 无贡献者主页作品区、无公告联动 | 对比 SubtitleCenter / U3D Shoutbox |

## 3. 竞品取法（每家拿什么）

| 来源 | 取什么 | 不取什么 |
|---|---|---|
| **NexusPHP** | 治理规则：格式白名单、不合格 9 条、**举报成立 +50 / 违规 −100 魔力**、等级权限（Peasant 禁传 / PU 删自己的 / Moderator 删全部） | 文件系统直存（我们已有更好的内容寻址） |
| **UNIT3D** | 工程结构：强绑定种子、种子页 Subtitles 面板 + Add/Edit/Delete、`media_languages` 字典表、7 字段排序 + 分页、审核态 + verified、anon | 无（成就 13 档可简化） |
| **PTP** | **反面参照**：影视站不做字幕区也能活 → 用 `site_type` 决定开关，别一刀切 | 只有国旗元数据的做法 |
| **KG** | **pots 众筹悬赏**：多人凑魔力入池 → 译者交付 → 整池结算；**译者署名**"Subtitles: A and B for KG" | 无（UI 无公开证据，别照抄界面） |
| **专业字幕站** | 元数据规范（FPS / 机翻 / HI / 仅外语 / 三元署名）、md5 查重、体积上限 + 包白名单、修订版、评分与坏字幕、按上传者等级加权排序、release name 匹配 | moviehash（无文件本体）、下载配额 VIP、AI 翻译、整季包 |

## 4. 功能设计

### P0｜让字幕区「能用」（本批次必须完成）

| # | 功能 | 改法 | 落点 | 规模 |
|---|---|---|---|---|
| P0-1 | **真实 size / ext** | 列表 JOIN `attachments`（`file_ref='attach://'||sha256`）取 `size`/`mime`；同时给表补 `size`/`ext` 冗余列并回填 | `subtitles.rs:100-113` | 小 |
| P0-2 | **体积上限接线** | 上传时读 `site_settings.maxsubsize`（默认 1048576），超限 → 400；后台已有元信息可直接配置 | `subtitles.rs:11` | 极小 |
| P0-3 | **扩展名白名单** | `srt/ass/ssa/sup/idx/sub/cue/zip/rar/7z`；前端 `accept` 同步；zip/rar 不做解包校验（后置） | `subtitles.rs` + `subtitle-board.tsx` | 小 |
| P0-4 | **sha256 查重** | 同一 sha 已挂在未删除字幕下 → 拒绝（防重复刷 +5 火花），错误信息提示「该字幕已存在」 | `subtitles.rs:11` | 小 |
| P0-5 | **下载扩展名修正** | 按 `mime` + 原始文件名后缀决定 ext；字幕格式直通，兜底 `.srt` 而非 `.bin`；文件名带上语言代码 | `subtitles.rs:170-176` | 小 |
| P0-6 | **种子详情页字幕块** | 新增面板：列该种子字幕（语言 / 说明 / 大小 / 下载数 / 上传者 / 时间）+ 「上传字幕」按钮（带 torrent_id）；空态「暂无字幕」；**按模块开关 + 站型过滤** | 新组件 + `GET /subtitles?torrent_id=` | 中 |

### P1｜让字幕区「能管」

| # | 功能 | 改法 |
|---|---|---|
| P1-1 | **元数据字段** | 新增 `fps` / `machine_translated` / `hearing_impaired` / `foreign_parts_only` / `source` / `producer` / `proofreader` / `author_name` / `parent_id`（修订版）/ `release_name`（归一化，用于匹配） |
| P1-2 | **语言字典表** | 建 `subtitle_langs`（code / name / flag / position），后台可维护；去掉前端 31 项硬编码（`subtitle-board-table.tsx:12-53`）；`subtitles.lang_id` 外键，旧 `lang` 字符串回填后弃用 |
| P1-3 | **分页与排序** | `page` / `per_page`(25/50/100) / `sort`(created_at, downloads, size, rating) / `order`；**count 查询必须与列表同谓词** |
| P1-4 | **release name + IMDB 匹配** | 存归一化 release name；种子页/列表按 §5 优先级排序；有 `media_info->>'imdb_id'` 时做 IMDB+语言级匹配 |
| P1-5 | **评分与坏字幕** | `POST /subtitles/{id}/vote`（1-10，一人一次）、`POST /subtitles/{id}/report`（`bad_reports++`，达阈值自动隐藏并通知管理） |
| P1-6 | **编辑 / 删除** | `PATCH`（本人或 modo：语言/说明/匿名/署名）、`DELETE`（本人或 modo，软删 `deleted_at`，保留 attachments 引用） |
| P1-7 | **审核态** | `status`（0 pending / 1 approved / 2 rejected）+ `moderated_by/at` + `verified`；`site_settings.subtitle_moderation` 开关（默认关=NP 口径，开=U3D 口径） |
| P1-8 | **举报奖惩闭环** | 管理端处理 `ref_type=subtitle`：成立 → 举报者 **+50 {magic}**、上传者 **−100 {magic}**、删字幕；恶意举报反扣。复用 `earn_spark` + 幂等键 |
| P1-9 | **anon 匿名上传** | `anon` 字段，列表/公告隐藏用户名 |

### P2｜让字幕区「能激励」

| # | 功能 | 改法 |
|---|---|---|
| P2-1 | **求字幕悬赏（pots）** | `subtitle_requests`：发起（lang + 可选 torrent_id）→ 众人 `contribute` 凑魔力入池 → 译者上传并认领 → 发起人/管理确认 → **整池一次性结算**给译者（抄 `bounty.rs` 的 CAS + 幂等键 `subtitle-bounty-pay:{req_id}`） |
| P2-2 | **贡献者主页作品区** | 用户主页挂「字幕作品」卡片（数量 + 下载总数 + 署名），复用现有 medals 体系挂「字幕译者」勋章 |
| P2-3 | **公告联动** | 上传后往 shoutbox 发系统消息（匿名则「一位匿名用户」），照抄 U3D 文案结构 |
| P2-4 | **成就挂钩** | 复用现有 `medals` / `tasks` 体系（任务侧已有 `subtitles` 指标），挂 3-4 档里程碑即可，不必照抄 U3D 的 13 档 |

## 5. 匹配与排序规则（照抄 OpenSubtitles 加权思路，换成我们有的字段）

```
匹配优先级（高→低）：
1. torrent_id 精确命中（用户手动挂载）        +100
2. release_name 归一化后相等（去 ._-+、大小写） +80
3. media_info->>'imdb_id' 相同 + 语言相同     +50
4. 标题 ILIKE 模糊                            +10

叠加权重：
· 上传者等级：modo/trusted +12、platinum/gold +10、普通 +8、anon +6   （复用 users.class）
· FPS 匹配                 +2
· 下载数 / 评分 作为同分兜底排序
· bad_reports 达阈值（建议 3）自动降权至末位
```

## 6. 数据模型（迁移 0146，创建前重新确认最大号）

```sql
-- ============ 0146_subtitle_upgrade.sql ============

-- 1) 元数据与治理字段
ALTER TABLE subtitles
  ADD COLUMN IF NOT EXISTS size BIGINT NOT NULL DEFAULT 0,
  ADD COLUMN IF NOT EXISTS ext TEXT,
  ADD COLUMN IF NOT EXISTS fps NUMERIC(6,3),
  ADD COLUMN IF NOT EXISTS machine_translated BOOLEAN NOT NULL DEFAULT false,
  ADD COLUMN IF NOT EXISTS hearing_impaired BOOLEAN NOT NULL DEFAULT false,
  ADD COLUMN IF NOT EXISTS foreign_parts_only BOOLEAN NOT NULL DEFAULT false,
  ADD COLUMN IF NOT EXISTS source TEXT,          -- 原创翻译/校订翻译/市售DVD/官方译本/其他
  ADD COLUMN IF NOT EXISTS producer TEXT,
  ADD COLUMN IF NOT EXISTS proofreader TEXT,
  ADD COLUMN IF NOT EXISTS author_name TEXT,     -- 译者/字幕组署名（KG "for KG" 同款）
  ADD COLUMN IF NOT EXISTS parent_id BIGINT REFERENCES subtitles(id),   -- 修订版
  ADD COLUMN IF NOT EXISTS release_name TEXT,    -- 归一化 scene release name，用于匹配
  ADD COLUMN IF NOT EXISTS lang_id SMALLINT,
  ADD COLUMN IF NOT EXISTS anon BOOLEAN NOT NULL DEFAULT false,
  ADD COLUMN IF NOT EXISTS verified BOOLEAN NOT NULL DEFAULT false,
  ADD COLUMN IF NOT EXISTS status SMALLINT NOT NULL DEFAULT 1,          -- 0 pending /1 approved /2 rejected
  ADD COLUMN IF NOT EXISTS moderated_by BIGINT REFERENCES users(id),
  ADD COLUMN IF NOT EXISTS moderated_at TIMESTAMPTZ,
  ADD COLUMN IF NOT EXISTS rating_sum INT NOT NULL DEFAULT 0,
  ADD COLUMN IF NOT EXISTS rating_count INT NOT NULL DEFAULT 0,
  ADD COLUMN IF NOT EXISTS bad_reports INT NOT NULL DEFAULT 0,
  ADD COLUMN IF NOT EXISTS deleted_at TIMESTAMPTZ;

-- 2) 语言字典表（替代前端 31 项硬编码）
CREATE TABLE IF NOT EXISTS subtitle_langs (
  id SMALLSERIAL PRIMARY KEY,
  code TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  flag TEXT,
  position INT NOT NULL DEFAULT 0
);
INSERT INTO subtitle_langs (code, name, flag, position) VALUES
  ('chs','简体中文','🇨🇳',1), ('cht','繁體中文','🇹🇼',2), ('eng','English','🇬🇧',3),
  ('jpn','日本語','🇯🇵',4), ('kor','한국어','🇰🇷',5), ('fre','Français','🇫🇷',6),
  ('ger','Deutsch','🇩🇪',7), ('spa','Español','🇪🇸',8), ('rus','Русский','🇷🇺',9),
  ('other','其他','🌐',99)
ON CONFLICT (code) DO NOTHING;

-- 3) 回填
UPDATE subtitles s SET size = a.size
  FROM attachments a
 WHERE s.file_ref = 'attach://' || a.sha256 AND s.size = 0;

UPDATE subtitles s SET lang_id = l.id
  FROM subtitle_langs l WHERE s.lang = l.code AND s.lang_id IS NULL;

UPDATE subtitles s SET release_name = lower(regexp_replace(t.name, '[^a-zA-Z0-9]', '', 'g'))
  FROM torrents t WHERE t.id = s.torrent_id AND s.release_name IS NULL;

CREATE INDEX IF NOT EXISTS idx_subtitles_release ON subtitles (release_name);
CREATE INDEX IF NOT EXISTS idx_subtitles_torrent ON subtitles (torrent_id) WHERE deleted_at IS NULL;
CREATE INDEX IF NOT EXISTS idx_subtitles_lang ON subtitles (lang_id);

-- 4) 求字幕悬赏（KG pots + OpenSubtitles AddRequest）
CREATE TABLE IF NOT EXISTS subtitle_requests (
  id BIGSERIAL PRIMARY KEY,
  user_id BIGINT NOT NULL REFERENCES users(id),
  torrent_id BIGINT REFERENCES torrents(id),
  lang TEXT NOT NULL,
  descr TEXT,
  bounty BIGINT NOT NULL DEFAULT 0,
  contributors JSONB NOT NULL DEFAULT '[]',
  status SMALLINT NOT NULL DEFAULT 0,          -- 0 进行中 /1 已交付 /2 已撤销
  fulfilled_subtitle_id BIGINT REFERENCES subtitles(id),
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE TABLE IF NOT EXISTS subtitle_votes (
  subtitle_id BIGINT NOT NULL REFERENCES subtitles(id) ON DELETE CASCADE,
  user_id BIGINT NOT NULL REFERENCES users(id),
  score INT NOT NULL CHECK (score BETWEEN 1 AND 10),
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (subtitle_id, user_id)
);

-- 5) 设置项（后台已有 maxsubsize，这里补字幕区开关与新阈值）
INSERT INTO site_settings (name, value, descr) VALUES
  ('subtitle_moderation', '0', '字幕是否需要审核（0 发布即生效 / 1 需审核）'),
  ('subtitle_bad_threshold', '3', '字幕被标记坏字幕达此数自动隐藏'),
  ('subtitle_ext_whitelist', 'srt,ass,ssa,sup,idx,sub,cue,zip,rar,7z', '允许上传的字幕扩展名')
ON CONFLICT (name) DO NOTHING;

-- 6) settings_meta 后台元信息（照 0039 的写法补，保证后台能显示）
```

> ⚠️ **路径命名纪律**：上面所有新端点都刻意放在 `/api/v1/subtitles` 前缀下——因为网关 `gateway.rs:38`
> 只登记了这一个前缀（`path == "/api/v1/subtitles" || starts_with("/api/v1/subtitles/")`）。
> 若命名成 `/api/v1/subtitle-langs` 或 `/api/v1/subtitle-requests`，**不会被拦截**，
> 站长在后台关闭字幕区后这些接口仍然可访问——这是本方案最容易踩的坑。
> 若确实要用独立前缀，必须同步在 `gateway.rs` 的 `TABLE` 里登记，并更新文件末尾的契约测试断言（124-127 行）。

**挂载位置**：`apps/api/src/content_http/mod.rs`（现有三个 service 在 29-31 行），新增 service 在此注册。

## 9. 验收标准（可测）

| 编号 | 断言 |
|---|---|
| A1 | 上传一条 2KB 的 `.srt` → 列表「大小」列显示 ≈2.00 KB，页头总上传量随之变化（不再恒为 `—`） |
| A2 | 上传 2MB 字幕（`maxsubsize` 默认 1MB）→ 返回 400 且提示体积超限 |
| A3 | 上传 `.exe` → 返回 400；前端 `accept` 也过滤 |
| A4 | 同一文件连续上传两次 → 第二次返回「该字幕已存在」，火花流水只增加一条 |
| A5 | 点下载 → 保存的文件名后缀是 `.srt`（不是 `.bin`） |
| A6 | 打开任一种子详情页 → 有 Subtitles 面板；在该面板上传字幕后，面板立刻出现该条 |
| A7 | 列表翻页：第 2 页内容与第 1 页不重叠，总数与实际行数一致（count 同谓词） |
| A8 | 评分：同一用户第二次投票覆盖原分数，`rating_count` 不增加 |
| A9 | 举报 3 次（阈值）→ 该字幕在列表隐藏 |
| A10 | 非本人非 modo 调 `PATCH/DELETE` → 403 |
| A11 | 求字幕：两人共凑 200 {magic} → 译者交付 → 译者余额 +200，**幂等键保证重复结算只发一次** |
| A12 | 站型切到 music → 字幕区入口与页面均可见（音乐站传歌词字幕，`0107:98-99` 有意开启） |
| A13 | 后台把「社区模块 → 字幕」关掉 → 导航入口消失、`/subtitles` 页面 404/重定向、`GET /api/v1/subtitles` 返回 **4101 ModuleDisabled** |
| A14 | 音乐站（kind=lyric）上传 `.lrc` → 通过；影视站上传 `.lrc` → 400（NP 规则明令禁 lrc） |
| A15 | 站长手动关闭字幕区后切换站型（如 general → movie）→ 字幕区**仍保持关闭**（`sitetype.rs:69-87` 覆盖逻辑） |
| A16 | 后台改开关后 30s 内生效（缓存 TTL），或保存即刻生效（`invalidate()`） |

**端到端验证套路**（容器部署下）：铸 HS256 JWT（claims **必须含 `iat`**，否则 401）→ 带 Cookie `flux_token=<jwt>`（path=/api/v1）抓渲染 HTML 或直连 API（`Authorization: Bearer` 亦可）→ 比对断言。
注意：`flux.session=1` 只是 middleware 存在性标记，localStorage token 已废弃。

## 12. 站型差异化与后台可配置（增补）

> 背景：音乐站用字幕区**传歌词字幕**（`0107:98-99` 有意开启），所以字幕区不能只有一套「影视外挂字幕」口径。
> 需求：站长建站后可在管理后台决定是否启用，且不同站型应有不同默认值。

### 12.1 站型矩阵

| 站型 | 模块默认 | kind | 允许格式 | 显示名 | 说明 |
|---|---|---|---|---|---|
| movie / documentary | 开 | `subtitle` | srt,ass,ssa,sup,idx,sub,cue,zip,rar,7z | 字幕 | 影视外挂字幕，FPS 有意义 |
| anime | 开 | `subtitle` | 同上 + **ass**（特效字幕为主） | 字幕 | 特效字幕多，FPS 必需 |
| **music / lossless** | **开** | **`lyric`** | **lrc**,srt,ass,zip | **歌词** | 歌词字幕；无 FPS 概念；禁上传与曲目无关的文件 |
| general | 开 | `subtitle` | 影视默认集 | 字幕 | 综合站按影视口径 |
| education / ebook | 开（站长可关） | `subtitle` | 影视默认集 | 字幕 | 教育站字幕区常年无内容，建议站长关 |
| game / software / sports | 开（站长可关） | `subtitle` | 影视默认集 | 字幕 | 同上 |

**关键**：`lrc` 只在 `kind=lyric` 时允许。NexusPHP 规则明确禁止 lrc（"不允许 lrc 歌词或其它非字幕/cue 文件的上传"）——这条是**影视站**的规则，音乐站恰恰相反。所以**格式白名单必须按 kind 走，不能写死**。

### 12.2 后台可配置项（全部走 `site_settings` + `settings_meta`）

| 设置键 | 默认（影视） | 默认（音乐） | 说明 |
|---|---|---|---|
| `module_subtitles` | yes | yes | **总开关**（已存在，后台「社区模块」分组） |
| `subtitle_kind` | `subtitle` | `lyric` | 字幕 / 歌词，决定格式白名单、字段显隐、文案 |
| `subtitle_label` | 字幕 | 歌词 | 页面标题与导航显示名（站长可改） |
| `subtitle_ext_whitelist` | `srt,ass,ssa,sup,idx,sub,cue,zip,rar,7z` | `lrc,srt,ass,zip` | 扩展名白名单（覆盖 kind 默认，站长可微调） |
| `maxsubsize` | 1048576（已存在） | 建议 262144 | 歌词很小，可调低 |
| `subtitle_moderation` | 0 | 0 | 是否需要审核 |
| `subtitle_bad_threshold` | 3 | 3 | 坏字幕自动隐藏阈值 |
| `subtitle_show_fps` | 1 | **0** | 歌词无 FPS 概念，隐藏该字段 |

> `settings_meta` 行必须照 `0039_settings_meta.sql` 的字段顺序写（含 `label_en`），否则英文后台空标签；
> 分组建议挂 `grp='subtitle'`（新增分组）或并入既有社区分组。

### 12.3 音乐站歌词字幕的字段差异

| 字段 | 影视 subtitle | 音乐 lyric |
|---|---|---|
| `fps` | 显示（特效字幕关键） | **隐藏** |
| `hearing_impaired` / `foreign_parts_only` | 显示 | **隐藏**（歌词无此概念） |
| `machine_translated` | 显示 | 显示（同样禁机翻歌词） |
| `source` | 原创翻译/校订翻译/市售DVD/官方译本 | **原创听译/官方歌词本/转载** |
| `producer` / `proofreader` | 制作人 / 校订人 | **听译 / 校对**（复用同字段，改 label） |
| `author_name` | 译者或字幕组 | **听译者/歌词组** |
| 关联粒度 | 种子（一部片） | 种子（一张专辑）；**曲目号写在 title 里**（如 `01. 曲名`） |
| 下载后缀 | `.srt` / `.ass` | **`.lrc`** |

**不用新建表**：`subtitles` 表复用，`kind` 只影响**字段显隐与校验**，不动数据结构。

### 12.4 迁移补充（并入 0146）

```sql
-- 站型预设：按 pack 写默认值（建站/切站型时打底，站长后续改的 module_* 覆盖值优先）
UPDATE site_type_packs
   SET modules = modules::jsonb || '{"subtitles":true}'::jsonb
 WHERE code IN ('movie','documentary','anime','general');

-- 歌词口径预设（音乐/无损）
INSERT INTO site_settings (name, value, descr) VALUES
  ('subtitle_kind', 'lyric', '字幕区口径：subtitle 影视字幕 / lyric 歌词'),
  ('subtitle_label', '歌词', '字幕区显示名（导航与页面标题）'),
  ('subtitle_ext_whitelist', 'lrc,srt,ass,zip', '允许上传的扩展名（逗号分隔）'),
  ('subtitle_show_fps', '0', '是否显示 FPS 字段（歌词无需）')
ON CONFLICT (name) DO UPDATE
  SET value = EXCLUDED.value
 WHERE (SELECT value FROM site_settings WHERE name='site_type') IN ('music','lossless');

-- 影视口径预设（其余站型）
INSERT INTO site_settings (name, value, descr) VALUES
  ('subtitle_kind', 'subtitle', '字幕区口径：subtitle 影视字幕 / lyric 歌词'),
  ('subtitle_label', '字幕', '字幕区显示名（导航与页面标题）'),
  ('subtitle_ext_whitelist', 'srt,ass,ssa,sup,idx,sub,cue,zip,rar,7z', '允许上传的扩展名（逗号分隔）'),
  ('subtitle_show_fps', '1', '是否显示 FPS 字段（歌词无需）')
ON CONFLICT (name) DO NOTHING;
```

> 上面按 `site_type` 条件分支写默认值；若建站向导已有统一写入点，优先改向导代码而不是在迁移里分叉。

### 12.5 前端与文案

- 页面标题 / 导航名取 `subtitle_label`（默认"字幕"，音乐站"歌词"），**不要写死**
- `kind=lyric` 时：隐藏 FPS / 听障 / 仅外语部分三个字段，`source` 下拉换成歌词来源
- 规则卡文案按 kind 切换两套（影视 = NP 六条 + 禁 lrc；音乐 = 允许 lrc + 禁机翻 + 曲目号规范）
- 三语字典同步；涉及 {magic} 的地方保持占位符
