## 0. 背景与目标

FluxTorrent 当前已有一套完整的娱乐玩法底座（M24 娱乐玩法）。本文目的是在已有底座之上，梳理**还缺哪类玩法**、**怎么让现有玩法更成体系**，并借助外部参考站（思齐 / Siqi）的成熟模式，给出落地优先级与架构建议。

> 核心判断：PT 站的游戏价值不在"好玩到能当游戏平台"，而在两点——① 把核心行为（做种 / 上传 / 活跃）游戏化；② 提供休闲留存钩子。所有玩法必须服从经济红线。

---

## 1. 现有游戏底座盘点

核对 `apps/api/src/games_http/mod.rs` 及子模块后，现状如下：

| 玩法 | 实现位置 | 经济设计 |
|---|---|---|
| 刮刮乐 | `games_http/casino.rs` `scratch` | EV<1 回收，幂等防重放 |
| 猜大小 | `games_http/casino.rs` `guess_bigsmall` | 同上 |
| 九宫格抽奖 | `games_http/casino.rs` `jgg` | 固定票价，幂等 |
| 农场 | `games_http/farm.rs` / `farm_actions.rs` | plant / water / harvest |
| 趣味投票 | `games_http/fun.rs` `fun_polls` / `fun_vote` | 投票扣 1 火花 |
| 五子棋 | `http/frames_gomoku.rs` | 好友对战 |
| 总览 / 历史 / 回合 | `games_http/overview.rs` | — |

**设计成熟度**：所有产出玩法的 EV 均压在 1 以下（纯回收），下注走 `SpendOutcome::Spent` + 幂等键堵重放印钞口，限次走 Redis。这是成熟且正确的基线。

> 结论：问题不是"加基础小游戏"，而是"在已有底座上，还缺哪类玩法、怎么成体系"。

---

## 2. 三条设计红线（必须遵守）

1. **经济平衡**：任何"产出魔力"的玩法 EV 必须 < 1，且严格幂等（现有 casino 三件套已做对，新玩法照此标准）。
2. **防脚本**：下注 / 抽奖必须限次 + 幂等 + 行为风控（现有 `cheat_events` 可用）。
3. **合规**：纯虚拟货币、不涉及法币、界面不出现"赌"字眼。

## 3. 可加入玩法全景（分类 + 优先级）

### P0 — 跟核心行为强绑定，杠杆最大
- **做种 / 保种挑战赛 + 赛季排行榜**：复用 `seeding_reward` + `medals`，按周 / 月赛季排名发限定勋章。PT 站留存核心钩子。
- **签到 streak 日历 + 每日免费转盘**：用现有 `jgg` 九宫格加一张"免费票"，签到连续 N 天送一次。纯拉日活，零新经济风险。

### P1 — 休闲 / 社交
- **宠物 / 坐骑养成**：`farm` 已是养成雏形，升级成"宠物"（用做种天数 / 魔力喂养、展示在个人页）。社交货币属性强。
- **知识竞答**：`fun_polls` 升级版——计时、连对加倍、影视 / 技术题库。
- **好友对战扩展**：五子棋已有，可加象棋 / 斗地主简化版（胜负转移魔力，需单局封顶风控）。

### P2 — 彩蛋 / 长尾
- **站内寻宝**：在种子描述 / 帖子里埋 token，找到兑换魔力。强社区粘性、UGC 传播。
- **虚拟期货 / 预测市场**：押注"某资源未来做种热度涨跌"，纯虚拟。

### 补充候选（影视主题，最贴 PT 调性）
- 看截图 / 海报猜片名（素材现成，复用 `fun_polls` 思路）
- 资源图鉴 + 成就墙（长线留存，直接吃 `medals`，不碰经济红线）
- 车队保种战（P0 挑战赛的团队版）
- 三消 / 拼图 / 黑白棋（低开发休闲）
- 红包雨 / 做种 Bingo / 漂流瓶（节日与轻社交）

## 4. 参考站分析：思齐（Siqi）钓鱼游戏

> ⚠️ **安全提醒**：探讨过程中对方站点 `c_secure_pass` 凭证曾被明文粘贴进对话。该凭证为签名 session token（含 user_id 与长时效 expiry），按"已泄露"处理——应去原站重登、改密、踢掉其他会话。**本文不抓取、不依赖任何第三方私站实时数据**，以下分析基于 PT 圈公开成熟的"钓鱼"模式。

### 4.1 钓鱼游戏通用模式
"钓鱼 / 鱼塘"是私站最经典的休闲玩法：每天花固定魔力"抛竿" → 随机上钩 → 鱼分稀有度（普通 / 稀有 / 传说），稀有度越高魔力奖励越大；含每日限次、连续登录涨"幸运值"、装备（鱼竿）可花魔力升级提概率、"今日最大渔获"排行榜。

### 4.2 参考点映射
| 维度 | 是否抄 | 理由 |
|---|---|---|
| 稀有度图鉴 | ✅ 抄 | 补"收集 / 图鉴"钩子，比纯 RNG 更有黏性 |
| 每日幸运连击 | ✅ 抄 | = 签到 streak 的游戏化版 |
| 鱼竿升级（花魔力提概率） | ✅ 抄 | 魔力**下沉口**（sink），反而把 EV 压更稳 |
| 最大渔获排行榜 | ✅ 抄 | 复用 P0 挑战赛排行思路 |
| 核心随机产出 | ❌ 不抄 | `jgg` / `scratch` 的 EV<1 + 幂等 + 限次已成熟，直接套 |

> 一句话：**钓鱼 = `jgg` 九宫格 + 稀有度皮肤 + 每日幸运倍率 + 鱼竿升级 sink**。开发量小、留存杠杆大、不破经济红线。

### 4.3 落到 FluxTorrent 的改造草图（仅草图，非实现）
- **表**：`fishing_catalog`(鱼 id / 稀有度 / 基础产出)、`fishing_records`、`fishing_luck`(每用户连击 + 幸运值)、`fishing_rods`(竿等级 / 花费 / 幸运加成)
- **端点**：`POST /games/fishing`（抛竿）—— 复用 `helpers::check_bet` / `check_rate` / `idem_key`，下注受 `games_max_bet` 约束
- **EV 约束**：每竿固定票价（同 `JGG_TICKET`），产出 = 稀有度权重 × 幸运倍率，赔率走代码常量 + 设置键双源（同 `scratch_odds`）
- **鱼竿升级** = `spend_spark` 做 sink，提 `luck_bonus`
- **连击**：连续日抛竿 → 幸运值 +X%，封顶

## 6. 架构建议：通用赔率引擎

现有 `scratch_play_with` / `guess_play_with` / `jgg_draw` 三者本质相同：**下注 → 按赔率表 RNG → 产出（EV<1 + 幂等 + 限次）**。

**建议重构**：将 RNG + 赔率表抽成通用 odds 引擎（赔率表走代码常量 + 设置键双源，同 `scratch_odds`）。之后加**老虎机 / 轮盘 / 砸金蛋 / 石头剪刀布**基本等于"写张赔率表 + 换皮"，成本极低，且天然继承 EV<1 / 幂等 / 限次基线。

> 与其一个个加游戏重写一套，不如先沉淀引擎，把新玩法降级为配置。

## 7. 推荐落地路径

| 阶段 | 内容 | 理由 |
|---|---|---|
| 第一步 | **通用 odds 引擎重构** 或 **石头剪刀布** | 引擎一劳永逸；RPS 立竿见影，半天出原型 |
| 第二步 | **钓鱼**（§4 草图） | 图鉴 + 连击 + 排行榜，社交钩子强 |
| 第三步 | **老虎机**（= jgg 动画化） | 零新逻辑，纯前端表现 |
| 后续 P1 | 宠物系统 / 知识竞答 / 车队保种战 | 工程量大，分批推进 |

所有新玩法统一复用 `helpers.rs` 的限次 / 幂等 / `games_max_bet` 约束，迁移号按仓库惯例避让最大号。

## 9. 二维评估：好玩性 × 魔力回收力度

从「好玩性 / 趣味性」与「魔力回收力度」两个维度评估候选玩法。结论：**两者通常反向，仅"自愿下沉（sink）包裹进度"类玩法能同时占优。**

### 9.1 四象限分布
- **右上甜区（好玩且大力回收）**：宠物养成、钓鱼（含鱼竿升级）、扭蛋 / 外观 gacha、知识竞答
- **右下（高回收 · 低趣味，抽取感）**：纯赌场系（刮刮 / 猜大小 / 九宫格 / 老虎机 / 轮盘）、石头剪刀布
- **左上（高趣味 · 偏产出 / 通胀）**：站内寻宝、挑战赛排行
- **左下（低两者）**：签到 / 免费转盘

### 9.2 关键原理：大力回收的真正杠杆是 sink，不是压赔率
- **house edge 回收**：所有 EV<1 玩法通用，约回收 10% 流水，慢且体验枯燥。
- **自愿下沉 sink**：玩家主动花魔力换成长 / 外观（宠物喂养进化、鱼竿升级、扭蛋抽外观），可很大且不觉亏。**这才是"大力回收"的来源。**
- 纯赌场系只靠 house edge，宜作保底底池，不宜作主玩法。

### 9.3 综合排序（好玩 × 回收）
| 排名 | 玩法 | 好玩 | 回收 | 关键机制 |
|---|---|---|---|---|
| 1 | 宠物养成 | 高 | 极高 | 喂养 / 进化 = 永久 sink，情感投入深 |
| 2 | 钓鱼（鱼竿升级） | 中高 | 高 | 图鉴 + 连击 + 竿升级 sink |
| 3 | 扭蛋 / 外观 gacha | 中高 | 高 | 纯外观 sink，不破数值 |
| 4 | 知识竞答 | 中高 | 中 | 入门费 sink + 社区向 |
| 5 | 纯赌场系 | 低 | 高(稳) | 只靠 house edge，宜作底池 |

### 9.4 避坑与建议
- 左上角（站内寻宝 / 挑战赛 / 免费转盘）好玩但偏通胀，须"先回收后奖励"或限额控量。
- 若目标为**既要好玩又要大力回收**，优先做 **宠物养成（带喂养 / 进化 sink）** 与 **钓鱼（带鱼竿升级 sink）**；纯赌场系留作保底底池。
- 落地时 sink 类玩法新增表（如 pets / rods），消耗侧统一走 `spend_spark`，奖励侧沿用现有 earn 框架，EV<1 约束不变。
