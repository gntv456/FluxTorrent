# 同类 BUG 排查报告（2026-09-16）

> 排查目标：找出与「高级搜索/发布页维度不生效」「分类不同步」**同一族**的问题。
> 这一族的共同特征是 **前端/后端之间的参数与数据在传递链路上静默丢失或形态不一致**，
> 表现为「界面上选了但没用」或「显示的口径与实际数据不符」，且都不报错。

## 一、已确认并修复（本轮）

| # | 问题 | 表现 | 根因 | 修复 |
|---|------|------|------|------|
| 1 | **计数与列表口径不一致** | 高级搜索筛出 0 行，顶部却显示「共 29 个」 | `list_torrents` 的 count 查询只带 分类/媒介/学段/版本/官种/死种/标题搜索，**不带** sections、标签、搜索范围 | count 与列表共用同一套谓词生成（`search_pred` + `sec_sql` + 标签 + 发布者 JOIN），占位符重新编排 |
| 2 | **bool 查询参数只认 true/false** | `?include_dead=1`（旧站 1/0 口径、第三方客户端常用）直接 400 | `Option<bool>` 用 serde 默认解析 | 新增 `de_bool_lenient`：接受 `1/0/true/false/yes/no/on`，挂到 official / include_dead / include_unapproved |
| 3 | **搜索范围/匹配模式下拉不转发** | 选「简介」「准确」后再搜，结果等同全字段模糊 | 页面把参数留在 URL，但 SSR 调列表接口时未转发（同 search_area 历史上「传了但后端不解析」的老病） | paged 参数补 `search_area` / `search_mode` |
| 4 | **下拉框不回显** | 提交后「范围/匹配模式」跳回默认值 | select 无 `defaultValue` | 用 URL 参数回填 defaultValue |

**验证矩阵（api 直连，29 条种子）**

```
all (alive+dead)          code=0 total=29 rows=29 OK
include_dead=1 (宽松)      code=0 total=29 rows=29 OK
official=0 (宽松)          code=0 total=24 rows=24 OK
sec_media=60 (无匹配)      code=0 total=0  rows=0  OK   ← 修复前 total=29
tag_id=999999 (无匹配)     code=0 total=0  rows=0  OK   ← 修复前 total=29
search_area=1 无命中       code=0 total=0  rows=0  OK   ← 修复前 total=29
search_area=4 IMDb        code=0 total=0  rows=0  OK
category_id=1,2 多选       code=0 total=29 rows=29 OK
sort=size                 code=0 total=29 rows=29 OK
```

页面渲染验证（登录态抓 HTML）：范围→「简介」、匹配→「准确」均已回显；IMDb 选项随站点元数据源显隐。

## 二、已排查确认无同类问题

- **`api.get` 前缀**：全仓扫描字符串字面量调用，无遗漏 `/api/v1` 的场景（昨天的 loadPublic 是唯一一处，已修）。
- **裸 `fetch`**：全仓仅 3 处 —— `api-client.ts` 的 request/requestBlob（双地址规范实现）、发布表单上传（走同源 rewrites），均正确。
- **`paged()` 路径**：全部带 `/api/v1` 前缀。
- **其他列表端点的计数口径**：`/admin/torrents` 与 `/admin/seed-preserve` 等均与列表共用 `where_sql`，一致；`/admin/syslog`、`/admin/locations` 的 count 与列表谓词一致。
- **`/tags-dict` 响应形态**：返回 `[id, name, kind]` 元组数组，前端两种形态都兼容。

## 三、同类风险（未改，需知悉）

1. **静默回落掩盖故障**：种子页分类/维度在接口失败时回落到 i18n 字典（教育站默认值），
   故障时页面「看起来正常但内容陈旧」。当前保留（可用性优先），但建议后续加降级标记或日志。
2. **i18n 字典仍内嵌站点数据**（教育分类/年级/出版社等）：页面 RSC 数据里能看到这些字样（未渲染）。
   属 P1「i18n 剥离站点数据」范围。
