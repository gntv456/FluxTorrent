# FluxTorrent 阶段交付记录

> 本文档按「完成一个阶段 → 全功能复查 → 归纳总结 → 进入下一阶段」的节奏滚动维护。
> 每阶段记录：交付范围、关键实现决策、复查证据、遗留项。

## 阶段 S1：核心 PT MVP（M01–M10）

**交付**：Monorepo 骨架（Turborepo + pnpm workspace + Cargo workspace）、认证体系（Argon2id + JWT）、种子发布/下载/列表/详情、自研 Tracker（BEP3 二进制安全）、评论/感谢/收藏、管理后台基础（审核/举报/用户管理）、RSS。

**关键决策**：
- Tracker 字节层 percent-decode 解析 info_hash/peer_id，compact 响应返回 `Vec<u8>`（不经 String 避免 UTF-8 lossy 破坏哈希）。
- 不信任客户端自报 IP，仅 `TRUST_PROXY_IP=1` 时信任 X-Forwarded-For。

## 阶段 S2：经济与社区（M11–M23）

**交付**：火花经济（spark_ledger 流水为唯一事实源）、银行（定期/活期）、签到（连签奖励）、站免池、勋章（购买/赠送/佩戴）、论坛、短讯/好友、求种/候选/字幕、课本中心、保种区（做种>7 天自动移出）、排行榜、绩效考核工资、任务系统、邀请管理、Web 前端 14 页（好学品牌 Token + Tailwind v4）。

**关键决策**：
- 动账双函数 `spend_spark`/`earn_spark`：单事务 + FOR UPDATE 行锁 + 幂等键唯一约束。
- announce 计费链路：tracker → Redis Stream → worker XRANGE 游标消费 → BEP3 累计量转增量（`last_up/last_down` 列）→ 快照刷新。曾发现 P0 缺陷：worker 把累计量当增量，已修复并双场景实测。

## 阶段 S3：全方位审查修复（30+ 项）

**交付**：P0×7 / P1×15 / P2 主要项全部修复。代表性修复：
- Tailwind 从未安装（所有 className 死类）→ 安装 tailwindcss@4，CSS 1.9KB→18.6KB。
- 空作用域嵌套吞路由 → 改链式 `mount_xxx(scope) -> Scope`。
- require_auth 加 DB 权威校验（封禁/降级即时生效）。
- docker-compose 密码必填（`:?`）、端口绑 127.0.0.1、4 个 Dockerfile 重写。

## 阶段 S4：审查遗留项 + M26 PWA（提交 8e53986）

**交付**：
- `SpendOutcome{Spent,Replayed}`：shop_buy 幂等键必填，商品效果只在真实扣款时执行。
- 邀请配额原子占位（迁移 0010）：`UPDATE used=used+1 WHERE used<quota RETURNING`，消除 count+insert 竞态。
- `POST /auth/logout`：Redis not-before 撤销（iat<nbf 拒绝）+ 前端退出按钮。
- `verify_password` 对占位哈希返回 false（root 的 "stub" 哈希曾致 worker panic）。
- M26 PWA：manifest + Service Worker（静态缓存优先/导航网络优先/API 永不缓存）+ 图标 + /offline。

**环境备忘**：本地 flux-redis 容器实际未设密码；redis-rs ConnectionManager 对 AUTH 失败静默挂起，连接串须用 `redis://127.0.0.1:6379/0`（无密码）。

## 阶段 S6：M27 开放 API + M28 插件系统 + M29 管理后台（2026-09-09）

### M27 开放 API（迁移 0013）
- `api_tokens` 表：sha3-256 哈希落库（明文 `fxo_` 前缀仅签发时返回一次）、scopes、独立限流 `rate_per_min`、可撤销（`revoked_at`）。
- `POST /me/tokens` 签发（每人上限 5 枚有效）、`GET /me/tokens` 列表、`POST /me/tokens/revoke` 撤销。
- `GET /open/recent` 开放数据接口（最新 50 种子摘要）：`Authorization: Token <fxo_...>` 鉴权 + 按 token 分桶的 Redis 滑动限流。
- `GET /openapi.json`：OpenAPI 3.1 文档（信封 schema、apiKey 安全方案、错误码语义），与实现同源维护。
- E2E：签发→列表→开放接口访问→无/假 token 401→撤销后 401→rpm=2 连打 3 次第 3 次 1015。

### M28 插件系统
- `Plugin` Trait（on_user_login / on_torrent_upload / on_seeding_milestone），默认 no-op。
- `PluginManager`：编译期静态装配 + 运行期 `enabled()` 开关；Hook 分发经 `spawn_blocking + catch_unwind`，单插件 panic 只记日志不拖垮核心链路（验收：启停不影响核心）。
- 已接入触发点：登录成功（http.rs）、种子发布成功（http.rs）；worker 的 milestone 分发点预留。
- 示例插件 `auto_pin_official`：官种发布自动置顶（sticky），仅靠 Hook 实现、不侵入 torrents 领域层。
- `GET /admin/plugins` 插件清单（staff）。
- E2E：上传链路真实触发 Hook；`/admin/plugins` 返回清单；panic 抑制语义有单测。

### M29 管理后台（Dev 版）
- `admin_http.rs` 新增 9 个 staff 接口（class_id≥90）：运营概览（待审/举报/用户/种子/封禁计数）、种子审核队列（通过/拒绝，拒绝必须填理由）、举报处理（status/handled_by/handled_at 对齐既有 reports 表）、用户管理（搜索/封禁/解封）、等级调整（仅 99 站长可操作且不可动同级）、审计日志查询。
- 前端 `/admin`：5 Tab（概览/审核/举报/用户/审计）。
- E2E：root 全通过；uploader 访问 403；拒审无理由被拒；禁言后 token 仍有效（禁言≠封禁，与 require_auth 语义一致）；全部写操作落审计。

## 阶段 S7：上线准备（Phase 6，2026-09-09）

### 安全加固
- JWT 启动强度校验：`JWT_SECRET` <32 字节直接拒绝启动；非 `FLUX_DEV=1` 态含 "change_me" 的占位密钥拒绝启动。
- CORS 白名单：`CORS_ORIGINS` 环境变量（逗号分隔）→ 精确 allowed_origin；未配置退化为宽松 + WARN（仅开发态）。
- 注册 IP 限流：5 次/分/IP（防邀请码爆破）；此前仅登录有限流。
- compose 生产化：Redis 密码必填 + maxmemory 256mb LRU；api/web 端口默认绑 127.0.0.1（经反代对外）；`CORS_ORIGINS` 注入。
