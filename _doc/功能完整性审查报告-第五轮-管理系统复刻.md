## 5. 完整性评估

- 按 NP 158 页基线的前四轮结论（94%）不变；本轮聚焦**管理端**：好学站后台 70+ 菜单中，FT 已覆盖约 60%（staffpanel 32 工具 + settings 十二分组 + 审核/举报/申诉/审计/H&R/插件/客户端名单）。
- 本轮补齐 P1-1 ~ P1-7 后，管理端覆盖率预计 ≥ 85%；P2 完成后 ≥ 92%；剩余均为 P3/外部依赖/产品决策项。
- 业务逻辑合理性：NP 的"下载权限/挂起"是 tracker 侧执行点（announce 拒绝），FT 实现时必须落到 tracker，不能只改库。

## 6. 开发计划（转开发工程师执行）

1. 迁移 `0038_admin_user_fields.sql`：users 补列（download_enabled/suspended/seed_points 若缺）、`torrent_deny_reasons` 字典（种子 1-7 号对齐 hxpt）、promotions 补 `ends_at`。
2. API：
   - 重写 `GET /admin/users`（五维筛选+排序+分页）；
   - 新增 `GET /admin/users/{id}`（详情全景）、`POST /admin/users/{id}/adjust`（上传/下载/火花/做种积分/邀请配额，delta 语义+审计）、`PUT /admin/users/{id}/flags`（download_enabled/suspended）；
   - `GET/POST/PUT/DELETE /admin/deny-reasons` + 审核 decide 支持 deny_reason_id；
   - `GET /admin/torrent-ops`、`GET /admin/torrents`（后台种子管理）；
   - `GET /admin/promotions` + 到期编辑；
   - `GET /admin/login-events`、`GET /admin/spark-logs`、`GET /admin/torrent-buys`（三个记录查询）。
3. tracker：announce 检查 `download_enabled=false`（拒绝下载）与 `suspended`（拒绝全部）。
4. 前端：admin 页新增「用户管理」重构 Tab（筛选器+详情抽屉+调整对话框+开关）、「种子管理」Tab、「拒绝原因」「记录查询」并入 staff-tools；审核队列拒绝改下拉。
5. 验证：cargo check/test、tsc、regression.py、新 e2e（筛选/调整/开关 tracker 生效/拒绝原因/全站优惠到期）。
