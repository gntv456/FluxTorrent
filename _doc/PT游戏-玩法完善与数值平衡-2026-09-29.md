# PT 游戏玩法完善与数值平衡

- **日期**：2026-09-29
- **作者**：纳纳
- **状态**：完善稿（基于《宠物养成策划》《钓鱼玩法策划》补全）
- **目的**：让玩法"成立且好玩"——补齐四层：① 与核心 PT 行为（做种 / 上传 / 活跃）联动；② 可运营数值平衡；③ 进阶 / 社交 / 赛季深度；④ 边界与风控细化。

---

## 1. 与核心 PT 行为的联动（最关键）

纯娱乐游戏与 PT 站是两层皮；完善玩法的核心是让"玩"反哺"站"，把活跃行为变成游戏资源。

### 1.1 宠物养成
- **养成值**：宠物亲密度换算为个人页"养成值"，仅给展示性加成（特效 / 徽章进度），**不给做种数值加成**（避免 pay-to-win 破坏公平）。
- **口粮券联动**：每日做种满 6h 送 1 张口粮券，抵 1 次喂养消耗。让喂养不纯靠氪魔力，形成"做种 → 养宠"正循环。
- **图鉴称号**：集齐解锁的限定称号挂钩现有 `medals`，作为社区身份。

### 1.2 钓鱼
- **做种幸运**：鱼竿"幸运"除花魔力买，还可由连续做种天数提升（做种行为 ↔ 钓鱼收益联动）。
- **渔汛门槛**：周末"渔汛"活动鱼仅对"本周做种达标"用户开放钓取，把活跃行为变成限定产出门槛。
- **综合榜**：增设"做种 × 钓鱼"综合排行榜，鼓励双行为。

## 3. 进阶系统

### 宠物
- **宠物技能（展示向）**：进化随机解锁，如"拾荒"每日自动产 1 张口粮券（绑定轻度登录）、"招财"提升个人页动效。**不涉数值**。
- **宠物羁绊**：同账号多宠物达 N 只解锁"动物园"称号（挂钩 `medals`）。

### 钓鱼
- **咬钩时机小游戏**（把趣味从 0 拉起的关键完善）：抛竿后出"咬钩时机条"，窗口内点击命中 → 本次稀有度权重临时 +X%；未命中按基础。加入操作感，**不改变 EV**（命中只提升权重分布，整体仍 < 1）。
- **特殊鱼**：节日 / 活动限定，进图鉴且倍率更高，驱动回流。

## 4. 社交与交易

- **宠物赠礼**：好友间可"串门"看主宠；赠送已孵化宠物需双方亲密度门槛，防小号刷。
- **鱼市**：钓到的普通鱼可"晒制"成纯外观装饰（**不返魔力**）；传说鱼展示在个人渔获墙。
- **不开放自由交易魔力**，避免二级市场与通胀。

## 5. 赛季与活动

- 季度"养成大师赛" / "垂钓赛季"：按图鉴完成度 + 累计渔获排名，发赛季限定勋章（挂钩 `medals`）。
- 节日活动（春节 / 周年）：限定宠物皮肤 / 活动鱼，拉动回流。

## 6. 边界与风控细化

- **防脚本**：孵化 / 抛竿 / 喂养全部幂等（`idem_key`）+ Redis 限次；连击日期服务端校验；亲密 / 幸运增长服务端权威。
- **数值防作弊**：稀有度 / 倍率 / 权重服务端定值，前端只展示；EV 常量双源且强制 < 1。
- **经济熔断**：单用户单日渔获 / 孵化总额封顶；宠物 / 鱼竿产出**不返魔力**，结构上杜绝通胀源。
- **合规**：界面不出现"赌"字；纯虚拟货币。

## 7. 完善后落地优先级

| 序 | 内容 | 杠杆 | 成本 |
|---|---|---|---|

## 8. 优先级① 已落地代码（2026-09-29）

「核心行为联动轻量版」已完成可运行骨架，**未引入任何做种时长累计表、零改动资金管线**：

### 8.1 关键设计决策
- **「做种满 6h」直接复用 `seeding_reward` 流水**：其幂等键形如 `seeding:{user}:{yyyymmddhh}`，
  当日不同小时段条数 = 当日做种小时数。比新建累计表更省、更安全。
- **发放幂等**：`food_coupon_grants(user_id, day)` 主键，job 重跑 / 跨日补跑零副作用。
- **核销防双花**：`FOR UPDATE` 锁用户行 + `coupon_uses` 幂等键，既堵重放白嫖，也堵并发双花。
- **阈值双源**：6h 发券阈值 `games_coupon_seed_hours`、渔汛周阈值 `games_fishing_event_seed_hours`，均走 `site_settings`，运维可热调。
