## 4. 补测（2026-09-22 晚，磁力 + 详情缓存 + cargo-chef 批次）

- 详情聚合缓存（`cache:tdetail:v1:{id}:{reveal}`，30s + 写失效）：
  冷 34.7ms → 热 4.8–8.1ms（5 连发），约 **3–7x**；
  写路径（编辑/定价/删除/恢复/重提）即 DEL，实测改价后 price 立即可见。
- 磁力端点 announce 与 .torrent 内嵌 announce **逐字节一致**（bencode 解码比对 MATCH）。
- cargo-chef 分层构建（三 Rust Dockerfile）：冷构建 22m58s（含 cargo install chef +
  全量依赖），**改一行 Rust 增量构建 5m42s**（依赖层缓存命中，只编业务 crate）；
  纯 touch 重建 10s（全部缓存命中）。此前无分层时改一行 = 全量重编译（≈冷构建时长）。
- detail 可见性口径已对齐（本批修复）：待审/暂缓种 staff 与 owner 均可见
  （三视角实测 staff=200 / owner=200 / normal=404，新旧端点一致）。
