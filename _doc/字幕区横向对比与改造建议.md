# 字幕区横向对比与改造建议

> 调研日期：2026-09-21　范围：市面所有同类型 PT 建站系统（NexusPHP / UNIT3D / Gazelle 系 / Torrust / 老系 TBDev-XBTIT / FluxTorrent 自身）
> 证据口径：竞品取自上游仓库源码与在跑站点的规则页；FluxTorrent 取自本仓库代码（标注 file:line）

---

## 0. 结论速览

**一句话：市面上真正有「独立字幕区」的 PT 建站程序只有两家——NexusPHP 和 UNIT3D。Gazelle 系、Torrust、老系（XBTIT/TorrentTrader/TBDev）全都没有。**

FluxTorrent 当前字幕区 ≈ **NexusPHP 的形（UI 复刻到位）+ UNIT3D 的 0（工程化能力基本没有）+ NexusPHP 治理的 0（奖惩闭环没有）**：

| 层级 | 状态 | 说明 |
|---|---|---|
| 形（UI/交互） | ✅ 已到位 | 规则卡、上传表单（rowhead/rowfollow）、语言+首字母筛选、七列表格、举报按钮——与 NP `subs.php` 同款 |
| 存储（真实文件） | ✅ 已到位 | 走 `attachments` 内容寻址，`attach://<sha>`，下载回真实字节（审计修复 P1 空壳后） |
| 工程化（U3D 那套） | ❌ 基本缺失 | 无扩展名白名单、无真实 size、无分页排序、无编辑/删除、无审核态/verified、无种子页挂载、无语言字典表 |
| 治理（NP 那套） | ❌ 缺失 | 无「举报成立 +50 魔力 / 违规扣 100 魔力」闭环、无等级权限（Peasant 禁传 / PU 删自己的 / Moderator 删全部） |
| 激励 | ⚠️ 只有正反馈 | 上传 +5 火花（`subtitles.rs:70`），无成就族、无公告联动、无惩罚侧 |

**最该先堵的 5 个洞**（按性价比排序）：

1. **`size` 是假的** —— `subtitles.rs:101` 硬编码 `0::bigint AS size`，列表「大小」列和页头「总上传量」永远是 `—`。一条 SQL JOIN `attachments.size` 就能修。
2. **没有格式白名单** —— 现在 `.exe` 也能当字幕传上去，且 +5 火花。NP/U3D 都有白名单（NP：srt/ssa/ass/cue/zip/rar；U3D：srt/ass/sup/zip）。
3. **种子详情页没有字幕块** —— 用户找不到「这个种子有字幕」。U3D 在 torrent 详情页有 Subtitles 面板 + Add Subtitle 按钮，这是字幕区真正的流量入口；NP 靠字幕区列表里标题自己写种子名凑合。
4. **不能编辑/删除自己上传的字幕** —— 传错了只能找管理。U3D 有 update/destroy（本人或 modo），NP 等级体系也明确写了 PU 可删自己的。
5. **举报无闭环** —— 前端有举报按钮（`subtitle-board-table.tsx:187` 打 `ref_type=subtitle`），但后端没有「核实后奖励举报者、扣上传者」的处理链，也没人处理 `ref_type=subtitle` 的工单视图。

## 1. 竞品全景：谁有字幕区

| 系统 | 技术栈 | 独立字幕区 | 入口 | 字幕↔种子关系 | 备注 |
|---|---|---|---|---|---|
| **NexusPHP** | PHP（TBSource 派生） | ✅ 原生 | `subs.php` / `downloadsubs.php` | 绑定（文件落 `$SUBSPATH/$torrentid/$id.$ext`） | 华语 PT 事实标准，字幕区是标配板块 |
| **UNIT3D** | PHP / Laravel + Livewire | ✅ 原生（v8+ 完整） | `/subtitles` + 种子页内嵌 | **强绑定**（`findOrFail(torrent_id)`，标题自动取种子名） | 新一代里唯一把字幕做成完整 CRUD 的 |
| **Gazelle 系**（What.CD / OPS / RED / PTP / BTN / GazellePW） | PHP | ❌ 无 | — | 元数据字段（内置/外挂语言标签） | 音乐站天然不需要；PTP 导航（BROWSE/COLLECTIONS/REQUESTS/TOP10/FORUMS）无字幕入口 |
| **Torrust**（index + tracker） | Rust / Axum + Vue | ❌ 无 | — | — | 定位是「公开索引 + tracker」，无 UGC 社区模块（无字幕/求种/论坛） |
| **XBTIT / TorrentTrader / TBDev / TBSource** | PHP | ❌ 无 | — | — | 老系只解决 tracker+种子+简单论坛；TBSource 是 NP 的前身，字幕区是 NP 才引入的 |
| **U-232** | PHP | ❌ 无 | — | — | UNIT3D 前作，无字幕模块 |
| **FluxTorrent（本项目）** | Rust + Next.js | ✅ 有（NP 复刻） | `/subtitles` | **松绑定**（`torrent_id` 可为 0/NULL） | 见 §6 |

**结论**：字幕区是「华语 NP 血脉」和「UNIT3D 新一代」两条线上才有的模块，Gazelle 血脉和 Rust 新锐（Torrust）都没有。FluxTorrent 对标 NP，保留并做深字幕区是正确定位；但**深度应该取两家之长**：NP 的治理规则 + U3D 的工程结构。

## 2. NexusPHP 字幕区（华语标准）

### 2.1 结构

- 列表页 `subs.php`：规则卡 → 上传表单 → 语言下拉 + A–Z 首字母条 → 七列表格
- 下载页 `downloadsubs.php`：直接读文件流，落盘路径 `$SUBSPATH/$torrentid/$id.$ext`，`hits+1` 计数
  ```php
  $res = sql_query("SELECT * FROM subs WHERE id=$filename");
  sql_query("UPDATE subs SET hits=hits+1 WHERE id=$filename");
  $file = "$SUBSPATH/$dirname/$filename.$arr[ext]";
  ```
  → 表 `subs` 至少有 `id / torrentid / filename / ext / hits`，且**按 torrent 分目录存放**，说明字幕在生产关系上是「种子的附属物」。

### 2.2 规则（在跑站点规则页，浦园 / CarPT 同文）

**格式白名单**：`srt / ssa / ass / cue / zip / rar`
- Vobsub（idx+sub）、其它格式、合集（整季）→ 必须打包 zip/rar
- 开放音轨 CUE 表单；多个 cue 打包
- **禁止** lrc 歌词等非字幕文件（直接删除）

**不合格判定（9 条，命中即删）**：
与种子不匹配 / 与视频音频不同步 / 打包错误 / 含无关文件或垃圾信息 / 编码错误 / cue 错误 / 语种标识错误 / 标题命名不明确或含冗余信息 / 判定重复 / 被多用户举报且证实有问题。管理组保留最终裁定权。

**奖惩（治理核心）**：
- 举报一例不合格字幕，确认后 **举报者 +50 魔力**（3 天内发放）
- 字幕被判不合格 → 删除，**上传者 −100 魔力**
- 恶意上传刷分 / 恶意举报 → 额外扣魔力直至警告

**等级权限**（FAQ 表等级说明）：
- Peasant：**不能上传字幕**
- Power User：**可删除自己上传的字幕**
- Moderator：**可删除任何字幕**

**其他**：语言用 31 个固定 id（简体中文=25 / 繁體中文=28 / English=6 / 日本語=15 / 한국어=16 / Other=18…），列表以国旗图标呈现，标题里不需要写语言标记。

### 2.3 特点小结

> NP 的字幕区是「**发布即生效、事后删除制**」——没有审核队列，靠规则 + 举报 + 魔力奖惩来治理。成本低，但对管理人力依赖大。

## 3. UNIT3D 字幕区（新一代最完整）

### 3.1 路由与模型

```
GET    /subtitles            index    (Livewire SubtitleSearch)
GET    /subtitles/create     create   (带 torrent_id)
POST   /subtitles            store
PATCH  /subtitles/{id}       update
DELETE /subtitles/{id}       destroy
GET    /subtitles/{id}/download
```

`Subtitle` 模型字段（`app/Models/Subtitle.php`）：

| 字段 | 说明 |
|---|---|
| `title` | = 种子名（自动带出，不让用户瞎填） |
| `file_name` / `file_size` / `extension` | 真实文件三件套，**size 是真的** |
| `language_id` | → `media_languages` 字典表（staff 后台可维护） |
| `note` | **必填**，max 65535，列表以图标 title 展示 |
| `downloads` | 下载计数 |
| `verified` | 管理核实标记 |
| `user_id` / `torrent_id` | **torrent_id 必填 + exists 校验** |
| `anon` | 匿名上传（列表 `x-user-tag` 显示为 anonymous） |
| `status` / `moderated_at` / `moderated_by` | `ModerationStatus` 枚举 + 全局 `ApprovedScope` |

### 3.2 上传校验（`StoreSubtitleRequest`）

```php
'subtitle_file' => ['required','file', fn => in_array('.'.$ext, ['.srt','.ass','.sup','.zip'])],
'language_id'   => ['required', Rule::exists('media_languages','id')],
'note'          => ['required','max:65535'],
'anon'          => ['required','boolean'],
'torrent_id'    => ['required','integer', Rule::exists('torrents','id')],
```
存储走独立磁盘 `subtitle-files`，文件名 `uniqid()`。

### 3.3 种子详情页内嵌（关键差异）

`resources/views/torrent/show.blade.php`：

```blade
{{-- Subtitles block --}}
@if ($torrent->category->movie_meta || $torrent->category->tv_meta)
    @include('torrent.partials.subtitles')
@endif
```

- **只在影视/TV 分类显示**（教育/音乐/游戏分类不出现，符合站型参数化思路）
- 面板表头有 **Add Subtitle** 按钮（带 torrent_id）
- 每行 8 列：语言 / Note / 扩展名 / 大小 / 下载数 / 时间 / 上传者(支持 anon) / 操作
- 操作：**Download** + **Edit**（弹窗改语言/Note/匿名）+ **Delete**（本人或 modo），删除同时清磁盘文件
- 空态：`No external subtitles available`

### 3.4 列表页（`subtitle-search.blade.php`）

- 8 列 + 分类图标
- **7 个字段可排序**：title / language_id / extension / file_size / downloads / created_at / user_id
- **分页 25 / 50 / 100**
- 筛选：种子名搜索 + 语言下拉 + **分类多选** + 上传者用户名

### 3.5 激励与广播

- **成就族 13 档**：`UserUploadedFirstSubtitle` + 25/50/100/200/300/400/500/600/700/800/900/1000 Subtitles（每传一条给全族 `addProgress(1)`）
- **Shoutbox 系统公告**：`xxx has uploaded a new {语言} subtitle for {种子}`；匿名时播 `An anonymous user has uploaded...`
- **下载权限门禁**：`can_download == 0` 且非本人 → 拒绝下载并跳回种子页

### 3.6 特点小结

> U3D 的字幕区是「**种子详情页驱动 + 严格校验 + 完整 CRUD + 审核态 + 成就激励**」。工程化远超 NP，但治理侧（举报奖惩、等级权限）反而不如 NP 细。

## 4. 为什么其他系统不做字幕区

- **Gazelle 系**：音乐站是主战场（What.CD/RED/OPS），字幕无意义；电影分支（PTP/BTN/GazellePW）把字幕做成 release 的元数据字段（内置/外挂语言标签），而不是独立上传区——因为影视站的字幕通常由压制组随种子打包。
- **Torrust**：定位是「自建索引 + tracker」，roadmap 里根本没有 UGC 社区模块（无求种、无论坛、无字幕）。它跟 FluxTorrent 不是一个物种。
- **老系（XBTIT/TorrentTrader/TBDev）**：功能面停在 tracker + 种子 + 简单论坛，字幕区是 NP 在 TBSource 基础上新加的差异化能力，这恰恰是 NP 当年能成为华语事实标准的原因之一。

## 6. FluxTorrent 现状盘点（本仓库）

### 6.1 数据模型（`apps/api/migrations/0001_init.sql:344`）

```sql
CREATE TABLE subtitles (
  id BIGSERIAL PRIMARY KEY,
  torrent_id BIGINT REFERENCES torrents(id) ON DELETE CASCADE,
  user_id BIGINT NOT NULL REFERENCES users(id),
  title TEXT NOT NULL,
  lang TEXT,
  file_ref TEXT NOT NULL,
  downloads INT NOT NULL DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```
**缺**：`size` / `ext` / `note` / `anon` / `verified` / `status` / `moderated_at` / `moderated_by`。

### 6.2 接口（`apps/api/src/content_http/subtitles.rs`）

| 接口 | 行号 | 现状 |
|---|---|---|
| `POST /subtitles` | `:11` | 校验标题非空 + 附件归属（防冒用 sha）；`torrent_id>0` 才存，否则 NULL；**无格式白名单**；发 +5 火花（`:70`） |
| `GET /subtitles` | `:90` | `search` + `lang_id` + `letter` 筛选，`ORDER BY id DESC LIMIT 50`；**`0::bigint AS size`（`:101`）**；**无分页/排序** |
| `GET /subtitles/{id}/download` | `:121` | `downloads+1`；`attach://sha` 直接回字节（Content-Disposition 按 title 命名，ext 只分 pdf/txt/bin，**字幕格式被归成 .bin**）；外部直链回 JSON |

### 6.3 前端

- 页面：`apps/web/app/(main)/subtitles/`
- 组件：`components/subtitle-board.tsx`（规则卡 + 上传表单 + 搜索 + 首字母条）、`components/subtitle-board-table.tsx`（七列：语言/标题/时间/大小/点击/上传者/举报）
- 语言映射 31 种 **硬编码在前端**（`subtitle-board-table.tsx:12-53`），后端存的是 `chs/cht/eng/…` 字符串 code，两处靠一张 `LANG_CODE_TO_ID` 表对齐——**站长改不了语言清单**
- 举报：`subtitle-board-table.tsx:187` → `POST /api/v1/reports { ref_type: "subtitle", ref_id }`
- **种子详情页无字幕块**（`app/(main)/torrent/[id]/page.tsx` 里只有 `subtitleChain` 版本链变量，与字幕区无关）

### 6.4 已做对的地方（别动）

- 真实文件链路（attachments + sha256 内容寻址 + 归属校验），比 NP 的文件系统直存更安全
- 举报接了通用 reports 通道，有 `ref_type=subtitle` 预留
- 三语文案齐全（`i18n/zh-CN.ts:1505` 起，规则 6 条完整复刻 NP）
- 规则卡内容 = NP 规则页原文（同步/proper/resynced/合集打包/Vobsub）

## 7. 差距清单与建议

### P0（建议本轮做，成本低、体感强）

| # | 缺口 | 改法 | 落点 |
|---|---|---|---|
| 1 | size 恒为 0 | 列表 JOIN `attachments.size`（`file_ref` 形如 `attach://<sha>`）：`COALESCE(a.size,0)`；同时给 `subtitles` 补 `size BIGINT`/`ext TEXT` 冗余列更好 | `subtitles.rs:100-113` |
| 2 | 下载扩展名错（.bin） | 用 `attachments.mime` + 原始文件名后缀决定 ext；srt/ass/ssa/ssa/sub/idx/zip/rar 直通，其余回落 `.srt` 而不是 `.bin` | `subtitles.rs:170-176` |
| 3 | 无格式白名单 | 上传时校验原始文件名后缀 ∈ {srt,ssa,ass,sub,idx,sup,zip,rar,7z,cue}；不符直接 400 | `subtitles.rs:11` + 前端 `accept` |
| 4 | 种子详情页无字幕块 | 在 `torrent/[id]` 增加 Subtitles 面板：列该种子字幕（语言/大小/下载数/上传者/下载按钮）+「上传字幕」按钮带 `torrent_id`；**按站型/分类开关**（影视类开，音乐/教育关） | 新组件 + `GET /subtitles?torrent_id=` |
| 5 | 举报无闭环 | 加「字幕举报处理」：管理端能看到 `ref_type=subtitle` 的工单；处理成立 → 举报者 +50 魔力、上传者 −100 魔力、删字幕；恶意举报反扣 | 复用 `reports` + `earn_spark` |

### P1（结构补齐，对齐 U3D）

| # | 缺口 | 改法 |
|---|---|---|
| 6 | 不能编辑/删除 | `PATCH /subtitles/{id}`（本人或 modo，可改 lang/note/anon）、`DELETE /subtitles/{id}`（本人或 modo，软删 + 保留 attachments 引用） |
| 7 | 无审核态 | `status`（pending/approved/rejected）+ `moderated_by/at` + `verified`；列表默认只出 approved；`site_settings` 加 `subtitle_moderation` 开关（默认关=NP 口径，开=U3D 口径） |
| 8 | 无分页/排序 | 列表加 `page/per_page/sort/order`；count 查询与列表同谓词（历史教训：总数与行数不符） |
| 9 | 语言硬编码 | 建 `subtitle_langs`（或复用现有字典表）+ 后台可维护；`subtitles.lang` 存 id 外键，去掉前端 31 项硬编码 |
| 10 | 下载权限门禁 | 复用 `can_download` 判定：被禁下载者不能下他人字幕 |
| 11 | note 字段 | 上传表单加「字幕说明」（U3D 必填），列表以图标 title 展示 |

### P2（锦上添花）

| # | 缺口 | 改法 |
|---|---|---|
| 12 | 无匿名上传 | `anon BOOLEAN`，列表/公告里隐藏用户名 |
| 13 | 无成就联动 | 复用现有 `medals`/`tasks` 体系挂「字幕上传 1/25/100」里程碑（U3D 是 13 档，我们挂 3-4 档到 medals 即可） |
| 14 | 无公告联动 | 上传后往 shoutbox 发系统消息（可匿名） |
| 15 | 等级权限 | `subtitles` 上传门槛按用户等级（NP：Peasant 禁传）；删除权限 PU 自己 / Modo 全部 |

### 建议迁移字段草案（合并到一条新迁移）

```sql
ALTER TABLE subtitles
  ADD COLUMN IF NOT EXISTS size BIGINT NOT NULL DEFAULT 0,
  ADD COLUMN IF NOT EXISTS ext TEXT,
  ADD COLUMN IF NOT EXISTS note TEXT,
  ADD COLUMN IF NOT EXISTS anon BOOLEAN NOT NULL DEFAULT false,
  ADD COLUMN IF NOT EXISTS verified BOOLEAN NOT NULL DEFAULT false,
  ADD COLUMN IF NOT EXISTS status SMALLINT NOT NULL DEFAULT 1,      -- 1 approved / 0 pending / 2 rejected
  ADD COLUMN IF NOT EXISTS moderated_by BIGINT REFERENCES users(id),
  ADD COLUMN IF NOT EXISTS moderated_at TIMESTAMPTZ,
  ADD COLUMN IF NOT EXISTS deleted_at TIMESTAMPTZ;                   -- 软删，保留审计

CREATE TABLE IF NOT EXISTS subtitle_langs (
  id SMALLSERIAL PRIMARY KEY,
  code TEXT UNIQUE NOT NULL,      -- chs / cht / eng ...
  name TEXT NOT NULL,             -- 简体中文 / 繁體中文 / English
  flag TEXT,                      -- 🇨🇳 / 🇹🇼 / 🇬🇧
  position INT NOT NULL DEFAULT 0
);
-- 种子回填：从 attachments 反查 size/ext
UPDATE subtitles s SET size = a.size, ext = a.mime
FROM attachments a
WHERE s.file_ref = 'attach://' || a.sha256 AND s.size = 0;
```

> ⚠️ 迁移号：创建前先 `Glob apps/api/migrations/*.sql` 查当前最大号，从最大号 +1 起编（本仓库有过并行会话撞号事故）。

## 8. 一句话建议

**别重写，做增量。** FluxTorrent 的字幕区「形」和「存储」已经比 NP 更干净（内容寻址 vs 文件系统直存），真正缺的是三样：**真 size + 格式白名单 + 种子页挂载**。这三件做完，字幕区从「能看」变成「能用」；再把编辑删除 + 审核态 + 举报奖惩闭环补上，就同时压过 NP 和 U3D 的字幕区。
