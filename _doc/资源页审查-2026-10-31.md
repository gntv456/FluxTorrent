> 范围：/torrents 的作品聚合态（group=1 × 三视图）+ 与种子列表态的切换面。

## 结论：无 P0/P1，两处 P2 观察项

**功能完整性（全部验证过）**

| 功能 | 验证结果 |
|---|---|
| 三视图渲染（poster/card/table） | ✓ RSC 各 197/809/177 处 wk-* DOM；数据真实下发 |
| 分页 | ✓ p=1 只有下一页、p=6（末页）只有上一页；页码指示「第 N 页 / 6」 |
| 分页/切视图参数保持 | ✓ 所有链接保留 group=1 + view + limit + p + 筛选词（search/tag） |
| 视图切换三态链接 | ✓ card/table/poster 互切全部在位且带 group |
| 旧 URL 别名归一 | ✓ view=media→poster、group→group=1 服务端直出 200（不靠跳转） |
| 搜索透传 | ✓ q=4K total=4；空结果走 works.empty 空态文案 |
| 维度筛选 | ✓ sec_codec=466 → total=15（服务器实测，引用 H.265/x265 的作品） |
| 拒绝面（0436 批） | ✓ include_unapproved=1 / approval=2 / medium_id 均回 400 带中文说明 |
| 输入校验 | ✓ size_min=banana / date_from 坏格式 → 400 带格式提示；category_ids=abc → 400「分类参数非法」 |
| 边界值 | ✓ page=0/负数回落首页；limit 上限钳 100；超界页返回空 items 不炸 |
| 断种提示的态感知 | ✓ 列表态显示「另藏 N 条断种」入口；聚合态正确隐藏（聚合本就含断种） |
| 错误处理 | ✓ API 失败走 ErrorPanel（RSC 实测见 code:2001 分支），带重试链接且保留全部查询参数 |

**交互合理性（真机走查）**

- URL 即状态：一切筛选/视图/页码在 URL，可分享、可后退、SSR 直出（深链 ?group=1&view=poster&p=3 直接命中）；
- 首帧 Suspense 骨架（「正在获取列表…」）+ 流式补数据，不是白屏；
- 空态/错误态/加载态三态分明；
- 聚合态下不成立的入口（断种提示、approval 筛选）被主动隐藏/拒绝而不是静默失效。

## P2 观察项（不修，说明理由）

1. **seeders 全 0 时 sort=-seeders 看似无效**：本地/服务器库当前所有种子
   seeders=0（无真实做种客户端），排序本身正确（有数据时按降序）。属数据
   环境特征非缺陷；上线后有真实做种自然可验。
2. **limit=9999 静默钳到 100**：行为正确但无提示。设计取舍——上限钳制是
   防护，前端分页条数选择器只给 20/50/100 三档，正常路径到不了该分支。

  类精确定位后分页器行为完全正确。
