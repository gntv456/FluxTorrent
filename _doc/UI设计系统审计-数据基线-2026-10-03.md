## 附：口径与局限

1. **死变量口径**：`@theme inline` 桥接变量的 `var()` 引用天然为 0（它们供 Tailwind utility 消费），已单独按「对应 utility 在 TSX 中的命中数」二次判定，避免把有效桥接误判为死代码。A1-a 与 A1-b 分列。
2. **`@theme` 断点令牌**：`--breakpoint-sm/md/lg/xl` 的 `var()` 引用为 0，但 utility 前缀 `sm:`(50)/`md:`(79)/`lg:`(27)/`xl:`(5) 有效，故不计入死变量；`--breakpoint-2xl`（`2xl:` 0 次使用）计入。
3. **注释剥离**：所有色值/尺寸/类名统计前已剥离 `/* */` 与 `//` 注释，避免把设计稿说明文字计入。
4. **z-index 语义归属**：由「向上回溯 12 行内最近的非 `@` 块选择器」推断，为启发式；`pages.css:1745` 因选择器跨多行未能归属，已在表中标注 `?`。
5. **重复代码口径**：以「≥25 字符的归一化行被 ≥2 个文件共享」计。与 `difflib` 行级相似度、标签 Jaccard 三种口径交叉验证过——标签 Jaccard 曾报`admin-exams-table ⇄ admin-tasks-table` 为 1.00，经`difflib` 复核实为 17.9%，属标签集合相同但内容不同的**假阳性**，已剔除；报告中保留的均为 `difflib` 复核过的真实重复。
6. **触控目标**：`min-height:1px` 等极小值多为装饰性元素（进度条、角标、状态点），已在 C10 中与 TSX 侧实质违规分开列示。
