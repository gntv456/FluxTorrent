- 配套概念稿：`design-system/FluxTorrent-移动端UI概念稿.html`（已过无头 Edge 截图验证，0 控制台错误）

## 一、现状诊断（事实，含行号）

### 1. 全局基建
- Tailwind v4 CSS 配置制，`@theme inline` 只定义颜色/圆角/字体令牌，**无自定义断点**（`app/styles/base.css:229-260`），全走默认 sm/md/lg/xl。
- 全站宽度媒体查询仅约 20 条，全部集中在 `app/styles/*.css` 7 个文件，组件 tsx 内零媒体查询；**断点值多达 10 种**（440/560/640/700/720/768/860/900/1080/1120），无统一语义。
- `app/layout.tsx` **未导出 viewport**，没配 `viewport-fit=cover` → `components/layout.tsx:254` 的 `env(safe-area-inset-bottom)` 在 iOS 全面屏下**不生效**。
- `layout.css:1204` 有全仓唯一一条 `@media (folded)` 铰链避让规则（`.hinge-safe`），**没有任何消费方**，折叠屏等于未支持。
- PWA 反而是最完整的一环：manifest（standalone/maskable/shortcuts）+ sw.js + offline 页 + appleWebApp meta 都在。

### 2. 导航（最大短板）
- 顶栏小屏**不是汉堡/抽屉/横滚，而是 flex-wrap 直接换行堆叠**（`layout.css:34-44`，注释明言"空间不足改为换行"）——5 个一级菜单分组 + 更多 + 工具区全堆在首屏。
- 底 TabBar 仅 5 入口（`components/layout.tsx:214-292`，`md:hidden`），论坛/排行/字幕/任务/商店/考核等几十个入口在移动端**完全不可达**。
- 管理端 lg 以下侧栏隐藏，顶行「导航」按钮把 59 个条目**内联展开**在内容上方（`admin-shell.tsx:215-238`），展开后内容被顶出首屏。

### 3. 表格（第二短板）
- 策略只有「横向滚动」一种（`.baozi-wide-table-scroll`，`pages.css:107-109`，全仓约 35 处使用）。
- 种子列表 11 列全保留横滚（`torrents-table.tsx:34-39`），窄屏只压缩标题列（`pages.css:1070-1077`）。
- **管理端 39+ 张表格连滚动包裹都没有**（admin-torrents-table / admin-users-list / staff-tools-* / staff-box-desk 等），<lg 屏直接撑破容器、body 级横滚，管理端在移动端基本不可用。
- 全站唯一成熟范式在消息中心：「列降级 + 行内补偿」（`message-center-table.tsx:66-125`）——本方案把它推广为标准。

### 4. 已做点状适配（保留并推广）
首页 max-1080 塌单列、种子详情海报头 max-900/max-560、论坛 max-860、话题列表 sm 隐藏数字列、上传表单 max-720、控制面板 max-860/900、登录页 max-1120/440、hover 预览卡触屏禁用（`torrent-hover-preview.tsx:43`）。

### 5. 交互层（空白）
- **零手势**：全仓无 touchstart/touchmove/swipe；无 useMediaQuery hook，matchMedia 仅 4 类内联用法。
- 触控目标尺寸部分到位（底 Tab/翻页 44px）但不系统。
- SSR→CSR 搬迁需防 hydration 坑（日期 toLocale 时区、Date.now，已有 #418 先例）。

## 二、设计原则

1. **单手可达**：高频操作落在拇指热区（屏幕下 2/3），触控目标 ≥44×44。
2. **内容优先于导航**：导航默认收敛为一行，任意入口 ≤2 次点击。
3. **表格行卡片化**：移动端不做无限横滚，做「列降级 + 行内补偿」；审批可用，批量操作桌面保留。
4. **形态即布局**：手机=单栏流、折叠展开/平板=双栏（列表-详情），同一数据三种排布，不做三份页面。
5. **TIDE 零漂移**：全部复用现有 CSS 变量、字体令牌、动效令牌，移动端是同一主题的小屏表达，不是新皮肤。

## 三、断点体系（归一）

| 语义档 | 宽度 | 设备 | 布局策略 | 吸收存量野点 |
|---|---|---|---|---|
| 默认（<sm） | < 640 | 手机竖屏 | 单栏流 · 底 Tab · 抽屉 · 行卡片 | 440/560/640 |
| md | 640–1023 | 大手机横屏/折叠展开/平板竖 | 单栏加宽 或 双栏可配 | 700/720/768/860/900 |
| lg | 1024–1279 | 平板横屏 | 双栏+侧栏 · 表格完整列 | 1080/1120 |
| xl | ≥1280 | 桌面 | 现状不变 | — |
| `@media (folded)` | posture | 折叠合拢 | 铰链避让，双栏不跨折痕 | 复活 layout.css:1204 |

- 在 `@theme inline` 增补自定义断点令牌（Tailwind v4 支持 `--breakpoint-*`），存量媒体查询分批迁移，新增一律用语义档。
- 新增 `lib/hooks/use-media.ts`：`useMediaQuery(query)` / `useIsCompact()`（<md）/ `usePosture()`（folded 检测，取 `screen.orientation` + 媒体特性），作为组件层唯一断点判定入口；SSR 安全（默认桌面值 + useEffect 校正，防 hydration 闪跳——参照 #418 先例做横比验证）。
- `layout.tsx` 补 `export const viewport = { width:"device-width", initialScale:1, viewportFit:"cover" }`，safe-area 立即生效。

## 四、分形态设计方案

### 4.1 手机（<640）—— 概念稿 §2–§5

**导航架构重构（核心）**
- 顶栏收敛单行：汉堡（抽屉）· 品牌 · 搜索 + 头像；5 个一级菜单分组不再直接铺顶栏。
- 新增左侧导航抽屉：用户信息头（用户名/等级/上传/魔力）+ 分组九宫格（资源/社区/玩法/管理），与桌面 MainMenu 共用同一份菜单配置与 i18n 键；「管理面板」按 `profile.modules`/class 条件渲染。滑入 280ms `var(--ease-out)`，遮罩点击 + 右缘手势关闭。
- 底 TabBar 保留 5 项（首页/种子/凸起发布/消息/我的），未读徽标沿用。

**种子列表（行卡片化）**
- <640 且未显式指定 view 时，table 自动落到行卡片：封面 + 两行标题 + 促销徽标（FREE/2×/热/新，仍走 `torrents/promo.rs` 唯一口径）+ 单行 mono 数字（大小/做种↑绿/下载↓红/完成）。
- 复杂筛选收进 Bottom Sheet（FAB 唤出）：类型/促销/排序/状态四组，每选项 = 现有 URL 参数，确认后 `router.replace` 双向同步，刷新/分享可复现；分类高频项保留顶部横滑 chips。
- 手势：左滑行卡片露出 收藏/下载；下拉刷新（仅触屏态渲染）。
- 技术口径：行卡片与桌面表格共用 `TorrentTr` 数据源，按 `useIsCompact()` 切渲染分支；**不动**服务端分页、keyset 游标、count 采样、共享缓存键（cache:tlist:v2:*）。

**种子详情**
- 渐变沉浸头图（沿用现有 max-900 海报头信息重排）+ 四宫格核心数字 + 促销剩余时间徽标。
- 底部固定操作条：收藏 / 复制链接 / 下载种子（44px）；评论输入聚焦时操作条隐藏让位键盘。
- 简介/文件/评论/做种者改 Tab 分段；peers 数据（Redis 快照 flux:tracker:peers）点 Tab 才请求，省 SSR；mediainfo 折叠为「查看完整参数」；管理操作收 ⋯ 菜单。

**首页**：问候条 + 渐变数据条（上传/下载/分享率/魔力）+ 最新种子横滑海报 + 公告/论坛热帖卡片流；自定义排版 home-cell 窄屏塌单列沿用现状。

**管理端**
- 侧栏改抽屉（与前台同款组件）；管理首页改「待办墙」：待审种子/未结举报/候选申请/考核复核四张数字卡直达面板 + 快捷入口列表。
- 单条审批（通过/驳回，弹确认）移动端可用；批量勾选、宽表编辑、分区拖拽排序在 <lg 显示「请在桌面端操作」提示条，不做阉割版。
- 39+ 张裸表统一补 `.baozi-wide-table-scroll`（P0 机械修复），审批列固定首/末列。

### 4.2 折叠屏 —— 概念稿 §6
- 展开态（≈700–840px 逻辑宽，md 区间）：启用「列表-详情」双栏。种子列表左栏 + 详情右栏，选中态存 URL `?selected=`；合拢回手机宽度自动退化为「列表→详情页」标准导航并还原选中。
- 合拢态：`@media (folded)` + `.hinge-safe` 挂双栏容器，内容避让铰链半宽，双栏不跨折痕。
- 双栏是同一页面组件的条件排布，不是两个路由。

### 4.3 平板 —— 概念稿 §8
- 竖屏 768–1023：底 Tab 隐藏，左侧 172px 细侧栏（图标+短名）承载一级导航，内容区双列卡片。
- 横屏 ≥1024：直接复用桌面布局。
- 管理端 lg 以下侧栏从「隐藏」改「窄图标栏」，不整段消失。

### 4.4 三折叠（Mate XT 类）—— 概念稿 §7
**核心结论：三折叠不是第四种布局，是已有三档的连续映射，零新增布局。**

| 物理形态 | 逻辑宽度 | 断点档 | 布局（复用方案） | 工程要点 |
|---|---|---|---|---|
| 合拢 · 单外屏 | ≈360–430px | <sm | 手机方案：底 Tab + 抽屉 + 行卡片 | 无新增工作 |
| 展开一档 · 双屏 | ≈640–780px | md | 列表-详情双栏（§6 双折叠方案） | segments:2 · 单铰链避让 |
| 全展 · 三屏横持 | ≈1024–1120px | lg | 细侧栏 + 三列卡片 | segments:3 · 双铰链避让 |

工程关键只有两件：
1. **形态切换不丢上下文**：折展是连续 resize，筛选 query、`?selected=`、抽屉开关等状态全部 URL 化，断点切换只是重排。
2. **双铰链避让**：`usePosture()` 内部读 `horizontal-viewport-segments` 媒体特性返回 1/2/3；`.hinge-safe` 升级为支持双折痕，内容块分界对齐 1/3、2/3（列分界对齐折痕列为落地质检项）。

### 4.5 桌面端体检（2026-09-26 线上 1440px 实截）—— 概念稿 §9
TIDE 上线后桌面整体质量在线（管理端工作台、任务、上传页验证良好），**不重做，只修 6 处**：

| # | 级别 | 问题（实证） | 定位 | 修法 |
|---|---|---|---|---|
| 1 | P0 | 论坛头部「最新动态」入口 `text-sky` 压深蓝渐变，实截只见空框 | `app/(main)/forums/page.tsx:76-81` | pill 改白字描边/实底白字；横幅前景强制 on-accent 色板 |
| 2 | P0 | 商店卡片价格 CJK 断行「150,000 魔 力」「余额不 足」；半价徽章压圆角 | `components/shop-*.tsx` 价格行 | 价格行 nowrap + tabular-nums；价格与按钮分行；徽章内收 |
| 3 | P1 | 空态纵向不填充：种子列表/消息空时巨大留白，「获取 RSS」孤悬 | torrents 空态 · message-center | 空态 min-height:46vh + 引导行动组 |
| 4 | P1 | 首页 hero 左半大块纯色占位，信息密度低 | home-sections.tsx hero 卡 | 占位期用公告列表填充整卡 |
| 5 | P2 | 签到日历今日高亮格与其他格宽度/对齐不一致 | 首页签到组件 | 格子定宽 minmax(0,1fr)，高亮只改色 |
| 6 | P2 | 超宽屏 ≥1600 内容 max-w-1280 两侧空旷 | `app/(main)/layout.tsx:15` | 可选 2xl 档放宽至 1440；默认不动 |

#1 #2 随 M1 顺手修，#3 #4 随 M4 打磨，#5 #6 可选。

## 五、交互规范（全站统一）

| 项 | 规范 |
|---|---|
| 触控目标 | ≥44×44，icon 按钮视觉 32 时热区外扩；列表行整体可点 |
| 左滑快捷操作 | 列表行 ≤2 个操作，64px/个，过半吸合；全站仅此一个方向手势 |
| 下拉刷新 | 仅触屏态启用，64px 触发，TIDE 波浪指示器 |
| 长按多选 | 管理端列表长按进多选态，顶栏切「已选 n 项」；震动 10ms |
| Bottom Sheet | 圆角 18 · grabber · max-height 82% · 遮罩 rgba(8,19,31,.42) · 下滑/点遮罩关闭 |
| 动效 | 沿用 --ease/--ease-out；抽屉/sheet 280ms、按压 120ms、转场 200ms；尊重 prefers-reduced-motion |
| 返回 | 不自制全屏滑返，沿用浏览器手势 |

## 六、开发策划案（4 批，P0→P2）

### M1 · P0 基建与保底
1. `layout.tsx` 补 viewport 导出（viewportFit: "cover"）。
2. `@theme inline` 增断点令牌；写断点映射表注释，新增代码禁用野点（在 `line_limit_guard.mjs` 同类门禁思路下加一个 `breakpoint_guard.mjs` 或在 i18n_guard 基线中登记存量野点行）。
3. 新增 `lib/hooks/use-media.ts`（useMediaQuery/useIsCompact/usePosture，SSR 安全；usePosture 读 viewport-segments 覆盖双折/三折）。
4. 39+ 张裸表补 `.baozi-wide-table-scroll`（机械修复，逐个文件过）。
5. 顶栏小屏收敛单行（先隐藏 MainMenu，入口暂收「更多」，为 M2 抽屉铺路）。
6. 桌面快修：论坛头部 pill 对比度（#1）、商店价格断行（#2）。
- 验收：管理端任意页 375px 无 body 级横滚（无头 Edge 截图清单：admin 五个重灾区面板）；iOS safe-area 生效（模拟器验证底 Tab 不贴边）。
- 风险：裸表补容器是纯包裹，零契约风险；顶栏收敛在 M2 抽屉落地前会短暂降低入口可达性，M1/M2 应连续提交。

### M2 · P0 导航架构
1. 新增 `components/nav-drawer.tsx`：菜单配置抽 `lib/nav-menu.ts`（桌面 MainMenu、抽屉、底 Tab「更多」三处同源），i18n 键入字典（adminNav 已有先例；新增 navDrawer 命名空间）。
2. 管理端 admin-shell 移动导航从「内联展开」改抽屉复用。
3. `_admin_nav_align.py` 扩展：校验抽屉菜单与 MainMenu、staff_panel_entries 三处一致。
- 验收：任意入口 ≤2 次点击；三处命名一致校验过；vitest 补 nav-menu 配置快照测试。
- 红线：i18n 批次做完立刻 commit（zh-CN.ts 被并行会话覆盖过一次）。

### M3 · P1 核心链路移动化
1. 种子行卡片组件 `torrents/_parts/torrent-row-card.tsx`，`TorrentTr` 按 useIsCompact 分支；URL view 参数显式指定时尊重选择。
2. 筛选 Bottom Sheet `components/bottom-sheet.tsx`（通用件）+ `torrents/_parts/filter-sheet.tsx`；URL 双向同步。
3. 详情页：沉浸头 + 四宫格 + Tab 分段 + 底部操作条；peers 改按需请求。
4. 首页移动排版：问候条 + 数据条 + 横滑海报（复用 latest-posters）。
5. 左滑手势 `lib/hooks/use-swipe.ts` + 下拉刷新组件（仅触屏）。
- 验收：无头 Edge 375/768 截图比对概念稿；`check_type_drift.mjs` 不破（不动 API）；SSR→CSR 搬迁扫时区/Date.now；行宽门禁 wide 数不增（长 className 提常量）。
- 注意：种子页改造纪律——不内联促销谓词、不动游标/缓存；详情页 peers 非 staff mask_ip 不变。

### M4 · P2 折叠屏 / 三折叠 / 平板 / 手势收尾
1. 种子页双栏排布（usePosture + selected URL 参数），`.hinge-safe` 启用并升级双折痕。
2. 三折叠三态映射验证（零新增布局；上下文 URL 化 + segments 探测），列分界对齐折痕质检。
3. 平板细侧栏布局（md–lg）；管理端窄图标侧栏。
4. 管理端待办墙首页；长按多选。
5. 桌面打磨 #3 #4（空态填充、首页 hero）。
6. PWA 增强：底 Tab 与 standalone 模式适配复检。
- 验收：posture 模拟截图（folded/unfolded）；vitest 补双栏选中态 URL 同步、usePosture SSR 默认值用例；性能基线 `scripts/perf_baseline.py --rounds 5` 复测无回归。
- **✅ 验收记录（2026-09-27 补齐）**：`tests/use-media.test.ts` 9 用例
  （usePosture SSR 默认 {segments:1,folded:false}/双折/三折优先级/合拢态 +
  useMediaQuery 无 matchMedia 防御 + useIsCompact 两档）；性能基线 5 轮
  （_doc/性能基线-2026-09-27.md）：列表全场景 p50 6-8ms，全面快于
  2026-09-22 基线（25-37ms），详情 404 为空库预期（基线时代库内有 id=2），
  无回归；长按多选接入 admin-torrents-table 并实测（长按行→进入多选+
  勾选该行→退出恢复，触屏 pointerType 守卫 + contextmenu 抑制）。

### 全程红线
- 每批必过：`line_limit_guard.mjs`（存量只许变长不许变胖，用 `git show HEAD:<f>` 对比别信基线）、`check_type_drift.mjs`、`i18n_guard.mjs`（基线行号制，别 --update）、`_admin_i18n_audit.py`（保持 0）。
- 新文案走字典 + `{magic}` 占位符（i18n/DB 种子/worker 私信三层）。
- 纯函数别和 `"use client"` 同文件（RSC 坑先例）；CSR 搬迁先扫时区/随机数/Date.now。
- 每批做完立刻 commit + `docker compose up -d --build web`，用 `docker ps` + 镜像 CreatedSince 交叉确认。
- 概念稿先行：后续任何大页改版仍走「HTML 概念稿 → 无头截图 → 落地清单 → 确认后改代码」。
