[size=5][b]FluxTorrent：一套开源的 PT 建站系统[/b][/size]

[b]先说人话[/b]：PT 站就是那种要邀请码才能进、会记录你上传下载量的资源站。FluxTorrent 是拿来[b]开一个 PT 站[/b]的程序——不是某个站的源码，是可以反复用来搭站的那层东西。MIT 协议，随便用。

三件最要紧的：
[list]
[*][b]想建什么类型的站都行[/b]：影音、音乐、动漫、电子书、教育、纪录片、无损、游戏、软件、体育、综合，11 种起点，选一个开始，之后全部能改。
[*][b]不用改代码就能定制[/b]：加字段、开关功能、改页面菜单、改叫法改配色，都在后台点。
[*][b]一台机器一条命令起站[/b]：Docker，五分钟级别。
[/list]
仓库：[url]https://github.com/gntv456/FluxTorrent[/url]
文档：[url]https://wiki.ptang.top/ft/[/url]

[size=4][b]后台能改什么[/b][/size]
[img]IMG_URL_06[/img]
[list]
[*][b]加字段[/b]：六种类型（文字 / 数字 / 单选 / 多选 / 日期 / 是否）。要不要出现在注册页、给不给别人看、挂在哪个功能下，全是勾选。
[*][b]开关功能[/b]：30 多个模块，关掉一个，前台后台一起消失，不会留半截入口。
[*][b]改叫法[/b]：站里货币默认叫「魔力」，想叫「火花」「积分」「硬币」是改一条设定，不是全局替换文字。
[*][b]改外观[/b]：颜色、圆角、字体全走令牌，明暗两套主题。
[*][b]自己加页面和菜单[/b]：新站自带的 7 页新手帮助，就是这么加出来的。
[/list]

[size=4][b]装起来多简单[/b][/size]
[code]
cp docker/.env.example docker/.env    # 填三个密码
docker compose -f docker/docker-compose.yml up -d
# 浏览器打开 http://localhost:3000/setup，跟着向导四步走完
[/code]
[img]IMG_URL_19[/img]
宝塔、1Panel、离线包、域名 HTTPS 都有手册。升级就是拉最新代码再起一次，数据库的改动会自动跟上——前提是你没改它的代码。

[size=4][b]跑得快不快[/b][/size]
不吹参数，说人话：一个站几万人、几十万种子这个量级，它扛得住。
[list]
[*]Tracker（记录谁在做种、给你算流量的那个服务）实测每秒 [b]2138 次心跳、零失败[/b]，平均响应 [b]7.2 毫秒[/b]。
[*]心跳这条路上不碰数据库，所以人再多也不会把站拖死；流量是后台攒批算的，重启不丢账。
[*]免费、2X 这类促销，列表上的徽章和实际扣的流量读同一份数据，不会出现「显示免费照样扣」。
[/list]

[size=4][b]适合谁，不适合谁[/b][/size]
[b]适合[/b]：想自己开站的站长；觉得「加功能就得改代码」太累的运营；做第三方工具、想找个能随便起的测试站的人。

[b]不适合[/b]：
[list]
[*]想直接找个站加入的——这是建站工具，不是站。
[*]完全没碰过 Docker 命令行、也不想照手册抄的。
[*]介意「机会类小游戏」合规责任要自己担的（安装向导第四步就是确认这条，介意可以整块关掉）。
[*]介意项目还在 0.x 的：小版本之间仍有改动，生产站请盯更新日志。
[/list]
