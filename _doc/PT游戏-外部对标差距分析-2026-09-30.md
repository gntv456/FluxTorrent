## 1. 一句话总评

**底座层（防刷 / 事务 / EV 闸 / 公示 / 后台配置面）我们已是所有参考对象里最硬的；玩法品类本身已不缺大头；真正缺的是把玩法串成生态的四根线——排行榜、活动引擎、社交传播、以及三条已经开工但没闭环的链路。**

- 好学站玩法多（15 个）但架构散（60+ 个独立 PHP 散落 public/，CSRF/登录态各写各的，双银行并轨利率漂移）——我们用「注册表 + 统一奖池管线 + 设置键双源」，这条架构优势要保持。
- 财神站玩法少（6 个）但**闭环极紧**：刮刮乐 → 注资聚宝盆 → 满额开奖 → 72h 全站 FREE → 拉动做种赚元宝 → 再刮，一个回收器驱动全站。
- U-232/TBDev（开源）有 casino / blackjack / slots / lottery / bank 全套赌场件；NexusPHP 官方有幸运大转盘插件；UNIT3D 至今无内置游戏（blackjack 是社区呼声 [#3969](https://github.com/HDInnovations/UNIT3D/issues/3969)）——说明「赌场件」不是差异化项，「生态件」才是。

## 3. P0：三条已开工未闭环的断链（先修，都是小改）

1. **口粮券没有消费者**。worker 每小时按做种时长发券（`apps/worker/src/jobs/game_coupons.rs`），但 `pets.rs` 投喂只扣魔力不扣券，钓鱼没有鱼竿升级——`linkage.rs:6-8` 注释「供未来养成喂养/鱼竿升级消耗（当前宠物/钓鱼模块尚未落地）」已过期。**修法**：`pet_feed` 接受口粮券抵扣一次投喂（策划稿 §1.1 原设计）；或先把券接到钓鱼鱼饵。
2. **渔汛门槛只展示不拦截**。`linkage.rs:58-69` 算出 `fishing_event_unlocked`，但 `fishing.rs` 的 cast/reel 完全没读它，周末活动鱼未实装。**修法**：cast 时校验门槛 + 加 `fishing_event` 池，活动鱼只从该池出。
3. **gacha daily_free 是死键**。0231 账本 kind 注释里有 `daily_free`，全 Rust 代码零引用——日常白送抽卡次数没有发放路径。**修法**：要么删注释，要么接签到（连签 N 天送 1 券，见 §4.3）。
4. **票根册指标只覆盖 6 种局**（`arcade_stubs.rs:56-74`：game_plays 总数 + scratch/jgg/bigsmall/farm_water/farm_plant），扭蛋/大转盘/钓鱼/宠物没有专属票根成就——新玩法玩家在收集面上是隐身的。聚合源 `spark_ledger(kind='game')` 的 ref_type 里这些玩法都有数据，加 FILTER + 成就行。

## 4. P1：缺失的周边系统（各站都有、我们全无）

### 4.1 排行榜体系（最大缺口）
游戏域 grep `rank/排行` 零命中。参考：好学农场多维排行 + 学伴富豪榜，财神中奖名单，思齐钓鱼最大渔获榜，BTN 式 trivia 赛。**建议**：先做一张通用 `arcade_leaderboards(period, game, metric)` 周榜（钓最大渔获 / 农场收成 / 猜大小连胜 / 刮刮乐欧皇），复用 `arcade_budget_*` 确定侧预算发榜奖；MVP 可以只读不改账。五子棋顺带加天梯分。

### 4.2 稀有掉落全服播报
财神把 rarity≥3 的中奖做「最近 10 条播报」，是免费拉活入口。我们 `arcade_meta.rs` 的 feed 已有全服票根/领取事件流，**加一条 `rarity>=4 中奖` 事件口径即可**，前端大厅滚动条展示。

### 4.3 每日免费钩子
探讨稿 P0 提过未做：每日免费 1 次转盘/九宫格（零成本票，池 EV 照旧），签到 streak 联动（连签 N 天 → gacha daily_free 券）。这是最便宜的日活抓手，且正好把 §3-3 的死键救活。

### 4.4 红包层（传播 + 社交）
好学两件套：**首页红包雨**（18 秒/轮，服务端强制 250ms 最小点击间隔 + IP 限频 + 宽限窗，`redpacket_config.php` 连被刷史注释都有——防刷参数模板现成）和**猜大小开奖生成红包**（`bigsmall_redpacket` 表，赢家发红包大家抢，社交裂变）。M-Team/QQ 机器人红包同理：用户间转移不增发，不破红线。**建议**：先做「猜大小/刮刮乐大奖 → 可选发全服红包」这一小件，红包雨放节日活动引擎里做。

### 4.5 活动引擎（节日 / 赛季 / 期次开奖）
好学：节气/节日勋章定时上架、发种大赛、促销火花池达标→全站双倍 FREE；财神：聚宝盆按期开奖（period_id 赛季制）+ 开奖次日 72h 全站免流。我们的 `arcade_quests/milestones` + 渔汛 + 赛季星轨已有零件，缺的是「限定期次 + 达标触发全站权益」这一层编排。**聚宝盆式全站奖池**（消费按比例注资 → 满额开奖 → 全站 FREE）是最值得抄的单一机制：回收、稀缺、活跃一炉烩，且与我们确定侧预算闸同构。

### 4.6 补签卡接入奖品池（财神闭环小件）
我们的 attendance 已支持补签行（admin 口径），arcade_items 有 sku 道具管线——把「补签卡」加为刮刮乐/奖池物品档（use_kind=sku），就得到财神同款「游戏产出 → 签到救急」闭环，改动很小。

## 5. P2：现有玩法逐个对齐标杆深度（按杠杆排序）

| 玩法 | 标杆水平 | 我们的差距 | 建议 |
|---|---|---|---|
| **宠物** | 策划稿：抽蛋孵化→进化→技能→羁绊→串门 | 实装只有 feed/claim；species 固定 slime、name 恒空（`pets.rs:96-101`）；无改名/选种/个人页展示 | 先补「改名 + 选种 + 展示位」三个零风险件；孵化/进化按策划稿二期 |
| **钓鱼** | 思齐模式：图鉴+连击幸运+鱼竿 sink+渔获榜 | 只有计时竿；图鉴/连击/鱼竿/活动鱼全未做 | 鱼竿升级顺便就是口粮券消费者（§3-1） |
| **农场** | 好学：天气、偷菜（验证码+限次）、装饰、任务、多维排行、好友点赞 | 单机版；无社交无天气 | 装饰品 = 纯 sink 好方向；偷菜涉及陌生人互动，教育站风控先评估 |
| **刮刮乐** | 财神：11 种奖励类型、VIP 奖自动折算防重复、累计消费 10万/100万/1000万 三档勋章 | 奖励只有 magic/item 两类；无累计消费成就线 | 把「上传量/补签卡/VIP 时长/勋章碎片」等 sku 档位配起来即可（管线已支持）；累计消费成就 = 票根册加一条 metric |
| **抽卡** | 水浒卡牌宇宙（竞技场/副本/爬塔/打造/四题材复用） | 二期未做（UP 池/包载荷/后台编辑器/排行，见策划案 §6）；**券不可购买 = 不是火花 sink**，目前回收魔力为零 | 二期照案推进；更远期可学水浒「材料打造」给卡牌加多级 sink；竞技场类 PVP 对局最后考虑 |
| **扭蛋/大转盘/九宫格** | — | 三件同构（共用 `pool_round`），玩法差异只剩皮 | 不再加同质玩法；补稀有播报（§4.2）就够 |
| **猜大小** | 好学：开奖红包、走势、聊天 | 道具加权已落地（mult/shield）；luck 二期在案 | 开奖红包（§4.4）是小改大价值 |
| **五子棋** | — | 无天梯/段位 | 跟排行榜体系一起做 |
| **论坛抽奖** | 财神聚宝盆 | 单期、无奖池累积 | 可升级为期次制 + 全站注资口径 |

## 6. 新品类候选（性价比排序）

1. **答题扫雷 / 知识竞答**（好学）：教育站定位天然契合（与通用建站审查 R1 结论同向）；好学的题库批量导入 + 按难度抽取机制现成；复用 fun_polls 或独立小游戏均可。**性价比最高新品类。**
2. **每日拼图/猜片名**（探讨稿补充候选）：素材现成（海报库），Wordle 式每日一题，零经济风险。
3. **猜大小开奖红包**：见 §4.4。
4. **学伴市场式好友买卖**：好玩且社交裂变强，但拿真实用户（等级/保种）当「资产」定价，教育站身份敏感性需要站长拍板，**先搁置**。
5. **老虎机 / 砸金蛋**：= 现有池抽换皮，无新增机制，**不值得单独排期**。
6. **21 点等赌场件**：规则重、争议大、UNIT3D 十年没做——维持探讨稿判断不抄。
7. **银行/利息**：利息 = 增发，直接违反我们的 EV<1 红线；财神钱庄的价值在「沉淀+贷款」，不适合我们。**不抄。**

## 7. 明确不抄清单（红线与教训）

- **银行利息 / 定期**：增发。
- **PVP 魔力转移对局**（斗地主/押注棋）：转移即对赌，风控成本高，探讨稿已判。
- **无上限 luck 类道具**：改概率必破 EV，改版方案 §2.4 已定首期只上 mult+shield（已落地，写侧闸 ×5 上限）。
- **纯付费墙无免费次数**：财神缺陷，反例。
- **好学式散页架构**：60+ 独立 PHP、双银行利率漂移——我们注册表 + 统一管线 + 设置键双源就是防这个的，别为加玩法开快车道。
- **外链图片依赖**（财神 picture.agsvpt.com）：图标走 `arcade_items.icon` / 本地资源（改版方案 §3.3 同结论）。

## 8. 建议路线（接在改版方案附录「剩余收尾」之后）

| 阶段 | 内容 | 理由 |
|---|---|---|
| 0（1-2 天） | §3 四条断链：口粮券消费者 / 渔汛拦截 / daily_free 或删 / 票根 metric 补 4 玩法 | 已开工的半成品比缺新功能更伤 |

| 4（新品类） | 答题扫雷/竞答 → 每日猜片名 → 抽卡二期深化 → 卡牌 PVP 远期 | 按性价比与定位顺延 |

## 附：参考站速查

### 好学站亮点（可抄）
