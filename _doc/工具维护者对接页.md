# FluxTorrent 工具维护者对接页

> 你大概是收到了用户的 issue（"支持 FluxTorrent"）或看到了收录请求。
> 这一页给你三样东西：**能自己跑起来的测试环境**、**逐工具的对接要点**、**已备好的材料**。
> 全部对外契约有机器可读版本，不需要读我们的源码。

## 0. 这个站对外是什么形态

FluxTorrent 是自研 Rust 架构（非 NexusPHP/UNIT3D/Gazelle），对外四条通道：

| 通道 | 形状 | 谁在用 |
|---|---|---|
| 兼容层 | NexusPHP 字段口径 JSON | PT-Plugin-Plus / pt_mate / 老脚本 |
| Torznab | XML + `torznab:attr` | Prowlarr / Jackett / Sonarr / Radarr |
| RSS | RSS 2.0 + `<enclosure>` 直链 | qB RSS 下载器 / Flexget / cross-seed |
| 开放 API | JSON，`fxo_` Token | 自动发种 / 移动壳 / 自写脚本 |

机器可读契约：`GET /api/v1/openapi.json`（27 路径，含 schema）
架构自描述：`GET /api/v1/compat/meta`（能力开关 + 端点表 + 限流口径）

## 1. 三行命令起一个可测实例

```bash
git clone https://github.com/gntv456/fluxtorrent && cd fluxtorrent
cp docker/.env.example docker/.env          # 本地默认值可直接用
docker compose -f docker/docker-compose.yml up -d
```

然后打开 `http://localhost:3000` 走安装向导（建管理员），再灌演示数据：

```bash
python scripts/demo_seed.py --base http://127.0.0.1:8080 \
    --user admin --pass '你的管理员密码'
```

它会：登录 → 签一枚 `read+upload` Token → 生成并上传一枚**过审**的演示种子 →
最后打印一份可直接粘进工具的对接清单（Token / passkey / Torznab URL / RSS URL）。
六容器起不来或哪一步 4xx/5xx，脚本会指出是哪条，先查 `docker compose logs api`。

## 2. 快速自测清单（不改任何工具代码就能验）

```bash
BASE=http://127.0.0.1:8080/api/v1
TOK=<demo_seed 打印的 Token>

curl -s $BASE/compat/meta | head -c 400                  # 能力自描述
curl -s "$BASE/compat/nexusphp/torrents.json?page=1" \
     -H "Authorization: Token $TOK" | head -c 400        # NP 口径列表
curl -s "$BASE/torznab" | head -3                        # caps（根节点必须是 <caps>）
curl -s "$BASE/torznab/search?apikey=$TOK&t=search&q=demo" | head -5
curl -s "$BASE/open/torrents/1" -H "Authorization: Token $TOK" | head -c 400
```

## 3. 逐工具对接要点

### Prowlarr / Jackett —— 不需要 PR，用户自助
索引器类型选 **Generic Torznab**（或 Generic Newznab）：
- URL：`https://<站点>/api/v1/torznab`
- API Key：用户自己的 `fxo_` Token（网页端「我的 → API Token」签发）

caps 已按规范输出（`<caps>` 根节点 + `<searching>` 能力声明 + 站点实际分类映射），
`item` 带完整 `torznab:attr`（含 `seeders`/`peers`/`infohash`/免费倍率）。

### Sonarr / Radarr —— 经 Prowlarr/Jackett 即可
`tv-search` 支持 `q,season,ep`（按标题 `SxxExx` 收窄）；`movie-search` 支持 `q,imdbid`。
`cat` 传 Newznab 分类号，命不中时返回空 feed（不会静默忽略分类）。

### qBittorrent RSS 下载器 / Flexget
`GET /api/v1/rss/{passkey}`，item 带 `<enclosure>`（`download.php` 直链，含个人 passkey）。
常用参数：`categories` / `mediums` / `search` / `official` / `paid`(1=仅免费) / `showrows`(≤200)。

### cross-seed
优先 Torznab（item 的 `torznab:attr` 里有 `infohash`）；RSS 模式同样可用（有 enclosure）。
默认列表**含零做种新种**，`alive=1` 可只要活种。

### PT-Plugin-Plus / PT-depiler —— 有现成模板，改个域名就能提 PR
- 模板：`.research/ptpp-config-template/config.json` + `fluxtorrent.js`
- 用户信息卡：`GET /api/v1/plugins/ptppUserInfo`（含 `passkey` —— 插件拼下载链必须，
  **缺它 `$passkey$` 会拼成空串 → 下载 401**）
- 搜索：`GET /api/v1/compat/nexusphp/torrents.json?keyword=$key$`（JSON，免 DOM 解析）
- 下载：`GET /api/v1/compat/nexusphp/download.php?id=$id$&passkey=$passkey$`
- 提 PR 时把 `{{DOMAIN}}` 换成站点域名即可；字段口径见 `_doc/开放API接入指南.md` §2/§3

### IYUU / 辅种类
列表与详情都给双指纹：`info_hash` + `pieces_hash`（`pieces_hash` = info.pieces 的 SHA-1，
跨站同源再发布的精确判据）。

### MoviePilot / 自动发种
`POST /api/v1/open/torrents`（multipart：`file` 必填，元数据走查询参数；**需要 `upload` scope**）。
按 `info_hash`/`raw_info_hash` **幂等**：重试同一枚返回 200 + `duplicate=true`，不会报错。
权限/过审/被拒禁发/扣费与网页发种完全同源。

### 移动壳 / 全功能客户端
`GET /open/categories`（分类+媒介字典）、`/open/torrents/{id}`（深详情：文件清单/MediaInfo/
多维属性）、`/open/me/overview|seeding|history|hr|messages`（本人数据，只读）。

## 4. 常见坑（都是我们或对接方真踩过的）

| 坑 | 说明 |
|---|---|
| 鉴权头 | 开放 API/兼容层是 `Authorization: Token fxo_...`（**不是** Bearer）；会话 JWT 才是 Bearer；Torznab 客户端可用 `?apikey=` |
| 限流 | Token 默认 60/min，响应带 `X-RateLimit-Limit/Remaining/Reset`；超限 `429 + Retry-After: 60`，请据此退避 |
| 分页 | 兼容层 `pagesize ≤50`（`has_more` 判底）；批量导出/增量请用 `/open/announces?since_id=`，别翻页 |
| 存活口径 | 对外列表默认**含零做种新种**（新种必须立刻可被搜到）；只要活种 `alive=1` |
| passkey 在 URL | 下载/RSS/别名端点按 NP 习惯把 passkey 放 URL —— 工具侧请勿打日志 |
| 字段语义 | `size` 字节、`added`/`published_at` Unix 秒、`completed` = 完成数 |

## 5. 兼容承诺与变更公告

- 旧端点保留 **≥2 个版本周期**；破坏性变更提前一个版本在 `compat/meta` 与
  `_doc/开放API接入指南.md` 公告（YemaPT 硬删接口为反面教材）。
- 字段新增均为**增量**：`category` 始终是站内 id，`category_name/np/newznab`、
  `info_hash/pieces_hash` 都是后加的 —— 老适配器不会因为升级就挂。
- 契约漂移有门禁：`scripts/check_type_drift.mjs`（错误码/枚举/响应形状 Rust↔TS）。
