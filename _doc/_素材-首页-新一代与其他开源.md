# 素材：新一代/其他开源项目首页（子代理一手调研，2026-09-22）

## 1. Torrust Index (Rust + Nuxt)

前端独立仓库 **torrust/torrust-index-gui**。

- **a) 首页区块**：`pages/index.vue` 仅是重定向壳——`onBeforeMount` 里 `navigateTo("/torrents", { replace: true })`，**种子列表页就是首页** [实证]。`pages/torrents.vue`：顶部搜索框、Category/Tags 多选下拉、Sort by 下拉、Default/Table 布局切换、列表 + 分页（默认 50/页）[实证]。
- **b) 最新/热门**：列表按排序即"最新"（默认 UploadedDesc）；**无独立"最新种子首页区块"**。Default=可展开行卡片；Table=表格（Name/Size/Date/Uploader/Seeders/Leechers/Actions）[实证]。
- **c) 公告/投票/聊天/统计/排行榜**：**全无**。GUI 组件目录无任何 stats/news/poll 组件 [实证]。
- **d) 未登录**：可直接浏览列表（公共索引，无登录墙）。
- **e) 判定**：极简搜索式首页（类 nyaa.style），架构现代但**首页信息密度为零**，作 PT 首页参考价值低，列表页交互可参考。

## 2. Torrust Tracker frontend

- Tracker 是纯 headless Rust 服务，**无独立前端仓库** [实证：GitHub org 仓库列表]。

## 3. Arcadia (Rust actix + Vue3/PrimeVue)

仓库实际为 **Arcadia-Solutions/arcadia**（iguanes 路径 404）。

- **a) 首页区块**（`frontend/src/views/HomeView.vue`，主栏+侧栏双栏）[实证]：
  - 主栏：① `LatestTorrents` 最新上传（**海报组形式**，显示上传者，标题链到 /torrents）；② `KiwiIrcChat` 内嵌 IRC 聊天（登录且 irc_enabled 时）；③ Tabs 双页签：最新论坛帖子 / 最新资源组评论；④ 公告列表 `AnnouncementComponent`
  - 侧栏：⑤ 站点精选海报（siteHighlights，链到论坛帖）；⑥ 社区统计（启用用户、今日/周/月活跃人数+百分比、论坛主题/帖子、资源评论、求种评论）；⑦ 库统计（种子数、求种数+完成率、peers/seeders/leechers/snatches、titles/artists/series/collages），带权限的详情跳 /stats
  - 数据来源：单接口 `getHomeData()` 返回全部首页数据 [实证]
- **b) 最新种子**：有，海报墙形态（TitleGroup）[实证：`components/torrent/LatestTorrents.vue`]。热门无专门区块。
- **c) 公告✓、聊天✓（IRC）、统计✓（两块侧栏）、投票✗、排行榜✗（独立 StatsView 页）。
- **d) 未登录**：AuthView 登录墙，首页数据需 userStore.id [实证]。
- **e) 判定**：**最接近现代 PT 首页理想形态**（双栏：内容流+侧栏统计，单 API 聚合），强烈推荐作为设计参考。

## 4. meanTorrent (MEAN.js, AngularJS)

镜像 **taobataoma/meanTorrent**（原仓已删）。

- **a) 首页区块**：
  - `home.client.view.html` [实证]：① 促销公告条（sales_notice）；② 考核通知条 + 考核状态条；③ 全局搜索（站内种子/论坛切换）；④ 每日签到块（含 VIP/积分提示）
  - `home_torrents.client.view.html` [实证]：按资源类型分区的 **Top 榜**，类型含 movie/tvserial/variety/documentary/music/game/sports/ebook/picture/software（ng-if 逐类开关，14 个 backdrop 大区块）；每类：**第一名做全屏 backdrop 大图横幅（TMDB 海报+元数据+演职员表+下载按钮）+ 2~N 名海报缩略图网格**
  - 控制器 [实证]：`homeNewestTorrents`、`homeNewTopics`、`homeNoticeTopics`、`homeHelpTopics`、`albumsList`；home_torrents：movieTopList/TVTopList/musicTopList 等每类 TopList
- **b) 最新/热门**：**热门=海报墙+大图横幅**（TMDB 刮削）；最新种子 getNewestTorrents [实证]，主页偏 Top 榜展示。
- **c) 公告✓（置顶公告+促销/考核条）、投票✗、聊天✗、统计✗、排行榜✓（分类型 Top）。
- **d) 未登录**：403/deny 视图，未登录被拒 [实证]。
- **e) 判定**：**海报化首页鼻祖级实现**（TMDB 刮削+签到+考核 gamification），视觉参考价值高；AngularJS 1.x 严重过时，代码难复用。

## 6. sqtracker（实际仓库 tdjsnelling/sqtracker）

Next.js + Node API。

- **a) 首页区块**（`client/pages/index.js`）[实证]：登录后 = ① 邮箱未验证警告 Infobox；② 最新公告 Infobox（标题+时间+发布人，链接到 /announcements/slug）；③ 搜索表单；④ "Latest Torrents" + `TorrentList` 组件（每页 25，客户端分页，支持排序/免费标签）[实证]。SSR 数据：`/torrent/latest`、`/announcements/latest`、`/account/get-verified` [实证：getServerSideProps]。
- **b) 最新种子**：有，表格列表形态（含 seeders/leechers/comment/bookmark 图标列）。热门无。
- **c) 公告✓（仅最新一条）、投票✗、聊天✗、统计✗（独立 /stats 页）、排行榜✗。
- **d) 未登录**：`PublicLanding` 组件——居中站名大标题 + Login/Register 链接，**极简 landing** [实证]。
- **e) 判定**：现代极简私有站首页范本（登录墙+最新种子+最新公告三件套），适合小站起步；区块丰富度低。

## 7. NyaaPantsu (Go + Jet 模板)

- **a) 首页 = 搜索列表页**：路由 `/`、`/p/:page`、`/search` 全绑 `SearchHandler` [实证：`controllers/search/router.go`]。区块 [实证：模板]：① 系统公告条；② 搜索栏 + "refine" 高级搜索面板（分类/状态过滤 remake·trusted·A+/条数/指定用户/大小区间）；③ 种子表格（分类图标+语言旗标、名称+评论数、磁力/下载图标、大小、S/L/D、日期，表头可排序）；④ 版主批量管理工具。
- **b) 最新/热门**：默认日期序=最新；排序可按 S/L/D；**无独立热门区块**，纯表格。
- **c) 公告✓（单条）、投票✗、聊天✗、统计✗、排行榜✗（独立统计页）。
- **d) 未登录**：公开站直接看列表。
- **e) 判定**：公站搜索首页标杆（表格密度+高级筛选），但**无社区感区块**，PT 化参考有限。

## 8. TorrentPier (PHP)

- **a) 首页 = 论坛版面目录**（`resources/views/default/index.twig`）[实证]：① 顶部帮助主题区；② 顶导快捷链（查看新帖/我的帖子/Atom 最新发布/版面地图，LOGGED_IN 才显示）；③ 分类-版块表格（版块图标、名称/描述/子版块、主题数、帖子数、最后发表）；④ 底部 `#board_stats` 统计区：种子总数/peers/速度统计、今日生日、在线用户 [实证：数据构建于 `library/includes/datastore/build_stats.php`]。
- **b) 最新/热门**：首页无；种子排行在独立 tracker 页（tracker.twig，行内 AJAX 展开首帖）。形态=表格。
- **c) 公告：无独立区（置顶帖承载）[业内]；投票✗；聊天✗；统计✓。
- **d) 未登录**：可看版面目录 [实证]。
- **e) 判定**：论坛型首页，统计区实现（Datastore 缓存聚合）可借鉴；"首页无种子流"不适合 PT 直觉。

## 9. U-232 V4 (PHP/TBDev 系)

- **a) 首页 = 区块拼装（Portal）模式**：`index.php` 按用户位掩码 `curuser::$blocks['index_page']` + 全局 `$BLOCKS` 开关逐个 require 区块 [实证]，单列 portlet：IE 警告 → **公告 announcement** → 职员聊天框 → **聊天框 shoutbox** → **新闻 news** → 广告 → 论坛新帖 forum_posts → **本周电影 movieofweek** → **最新种子 latest_torrents**（另有滚动版 latest_torrents_scroll，默认注释）→ **统计 stats** → 活跃用户 → IRC 活跃用户 → 24h 活跃用户 → 生日用户 → 最新注册用户 → **投票 active_poll** → 圣诞礼包 gift → 电台 radio → TorrentFreak 新闻 → 免责声明 → **捐款进度条 donations**。区块实体在 `blocks/index/` 目录 [实证]。
- **b) 最新/热门**：`blocks/index/latest_torrents.php` 内含两个查询：Top5（ORDER BY seeders+leechers DESC）和 最新5（ORDER BY added DESC），行内文字链 + **鼠标悬停 Tip 弹出海报**（poster 字段 150×220）[实证]。
- **c) 公告✓ 新闻✓ 投票✓ 聊天✓ 统计✓ 排行榜✗（独立页）；gamification（签到/礼包/周电影）浓厚。
- **d) 未登录**：`loggedinorreturn()` 硬登录墙 [实证：index.php L26]。
- **e) 判定**：**老派 PT 首页区块全家桶活化石**（每个区块可开关/按权限），信息架构参考价值高；代码风格陈旧不可直接复用。

## 10. XBTIT (Btiteam, PHP)

- **a) 首页 = DB 驱动的区块系统**：区块从 `blocks` 表按位置（t=顶部/d=下拉/e=附加/c=中央/l=左栏/r=右栏/b=底部）+ minclassview/maxclassview 权限读取，由 `include/blocks.php` 的 get_menu($pos) 渲染 [实证]。可用区块文件（`blocks/` 目录）[实证]：**lasttorrents（最新种子）、toptorrents（热门种子）、news（新闻）、poller（投票）、shoutbox/ajax_shoutbox（聊天）、online（在线用户）、trackerinfo（服务器信息）、lastmember（最新会员）、forum（论坛）、seedwanted（缺种求助）、user、serverload、paypal（捐款）、clock、mainmenu** 等。
- **b) 最新/热门**：`lasttorrents_block.php` 与 `toptorrents_block.php` 结构相同——HTML 表格（下载图标、文件名、分类图片、添加时间、大小、S/L/C 列，含等待时间 WT 列与 EXT 外部种子标记）[实证]。
- **c) 公告新闻✓、投票✓、聊天✓、统计✓（trackerinfo+serverload）、排行榜✗（独立 extra-stats.php 页）。
- **d) 未登录**：首页可看，但区块按 minclassview 逐块控制 [实证]。
- **e) 判定**：**区块位置/权限完全数据库化，是"可配置首页"思路的祖师**；UI 表格化过时，借鉴其**区块配置模型**而非视觉。

## 横向小结

| 形态 | 项目 | 首页核心 |
|---|---|---|
| 双栏社区型（最推荐） | **Arcadia** | 最新海报流 + IRC + 论坛流 + 侧栏双统计卡 |
| 区块全家桶型 | **U-232 V4** | 20+ 可开关 portlet（公告/聊天/投票/新闻/周电影/捐款） |
| DB 区块配置型 | **XBTIT** | 位置+权限驱动的左中右栏区块 |
| 海报榜+运营型 | **meanTorrent** | TMDB 大图 backdrop + 分类 Top 榜 + 签到/考核 |
| 极简三件套型 | **sqtracker** | 登录墙 landing + 最新种子表 + 最新公告 |
| 搜索列表即首页 | **Torrust / NyaaPantsu** | 纯列表/表格，零社区区块 |
| 论坛型 | **TorrentPier** | 版面目录 + 底部统计条，种子在 tracker 子页 |
| 失联 | rartracker | [未获取] |

通用结论：新一代项目（Torrust/sqtracker/NyaaPantsu）首页趋于"搜索+列表"极简；传统 PHP 系（U-232/XBTIT/meanTorrent）区块最丰富；**Arcadia 是唯一兼具现代技术栈与完整 PT 首页区块（最新+聊天+公告+统计）的开源实现**。
