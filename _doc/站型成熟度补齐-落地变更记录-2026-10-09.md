## 2. 批次 B · 质量门禁与能力声明（迁移 0336）

### 2.1 trumping（G1，PTP/GGn 口径）
- 表 `torrent_trumps`：举报（含指名替代）→ 版主裁决 → accept 淘汰被举报种
  （`approval_status=2` + `deny_note`）。
- 端点：
  - `POST /torrents/{id}/trump`（登录；不能举报自己的种）
  - `GET /torrents/{id}/trumps`（普通用户见计数，staff 见明细）
  - `GET /admin/trumps`（版主待处理列表）
  - `POST /admin/trumps/{id}/resolve`（accept/reject，重复裁决 400）
- 文件：`apps/api/src/torrent_http/trump.rs`（新增）

### 2.2 多版本语义分槽（G2，PTP 范式）
- **不建列**：`group_info` 由该种子的 `standard` 维度值**派生** tier
  （UHD / HD / SD / Other），`tier_of()` 在 `publish_http/group.rs`。
- 前端：`torrent-detail-blocks.tsx::tierBadge` 组版本行显示分槽徽标。

### 2.3 features 能力声明（统一机制）
- `site_type_packs.features JSONB`（11 包默认值：movie 开 trumping+quality_tiers；
  game/music/lossless 开 trumping；documentary 开 quality_tiers）。
- 消费点 `feature_on()` 读 `features->>'trumping'`，**不 match site_type**。
- 闸门实测：general 站（features 空）举报被 400 拒绝 ⇒ 能力门真的在起作用。

### 踩坑记录（写进记忆，避免重犯）
1. `torrent_sections` 的**枚举值写独立的 `dict_id` 列**，不是
   `value->'dict_ids'`（见 `upload_sections.rs:163`）。首版分槽 SQL 用后者，
   tier 全落 Other。
2. `dict.torrent` 与 `dict.tdetail` 是两个 i18n 区块；键加在哪个区块就必须读哪个。
3. `docker compose build` 曾产出**不含新迁移**的镜像（tag 被覆盖/缓存命中）。
   判据：`docker run --rm --entrypoint sh <image> -c "ls /app/migrations | tail -3"`。
4. `media_info` 可能为 NULL，`query_as` 直接解 `serde_json::Value` 会 500，
   必须 `COALESCE(media_info,'{}'::jsonb)`。
5. 改事件处理器签名（`genDescr(urlArg?)`）后 `onClick={genDescr}` 类型报错，
   必须包一层 `onClick={() => genDescr()}`。
6. root 是 staff（class_id ≥ 90）⇒ 用 root 测「非 owner 应 403」永远测不出，
   要断言「staff 可代为触发」。

## 8. G3 后半 · CUE 表合规判定

- **解析器** `apps/api/src/logcheck/cue.rs`：纯函数 `parse()` + 6 条单测。
  判据只认**逐行可复现的结构事实**：有 `FILE` 声明、TRACK 数 > 0、
  轨号从 1 连续递增、每轨至少一个 `INDEX 01`。
- **端点** `POST /torrents/{id}/cue-check`：body 传 `cue` 正文则直接判；
  缺省回落读该种 `kind='cue'` 的工件正文（发种时经 artifact 通道上传的 .cue）。
  返回 `{valid, tracks, has_file, missing_index, issues}`。
- **意义**：补上 RED/What.CD「Perfect FLAC = HasLog + LogScore 100 + HasCue」
  里的 **HasCue 合规性**——判的不是「有没有 .cue 文件」，而是
  「这张表能不能被正确还原成音轨布局」（缺 FILE / 缺 INDEX 01 / 轨号断裂
  都是不可用的表，且每条 issue 都能指回 CUE 里的一行）。
- **闸门**：`scripts/pt_audit_y_cue.py`（合法 / 缺 FILE / 缺 INDEX 01 /
  轨号不连续 / 空文本 / 回落读 artifact / 404 共 7 组断言）。

## 10. G13 · 文件树冲突检测

- **端点** `GET /torrents/{id}/file-conflicts`（登录可读、纯读、零侵入发种流程）：
  比较**同一聚合组内**过审种之间的文件路径，列出重合路径与对应的另一颗种。
- **口径**：Gazelle 把「劣质即重复」作为 trumping 的判据之一，重复路径 = 重复打包。
  **不阻断发种**——「重复」要人裁决（谁更优），自动拒绝会误杀「同片不同版」的正当并列。
- **比较域** = 聚合组（未入组直接返回 `group_id=null`，不报错）；
  对方种必须 `approval_status=1` 才计入。
- **闸门** `scripts/pt_audit_z_conflict.py`：同组同路径命中 / 反向对称 /
  不同组不算 / 路径不重合 / 未过审不计入 / 未入组 / 404，共 7 组断言
  → **ALL PASS**。
