以下是重构方案中可参考的开源项目清单，按技术组件分类整理：

---

## 一、Tracker 服务

### 1. Torrust Tracker（首选）

- **简介**：功能最全面、最活跃的 Rust Tracker，使用 Axum 框架构建
- **关键特性**：
  - 支持 UDP、HTTP(S)、WebTorrent 多协议
  - 全 IPv4/IPv6 支持
  - 支持 SQLite、MySQL、PostgreSQL 持久化
  - 内置管理 API 和 Prometheus 监控
  - 实现 BEP 3, 7, 15, 23, 27, 48 等多个标准
- **GitHub**：https://github.com/torrust/torrust-tracker
- **许可证**：AGPL-3.0
- **相关项目**：`torrust-actix`（改用 Actix-web 框架的分支）

### 2. Aquatic（备选/性能极致）

- **简介**：以极致性能为目标的 Rust Tracker，星标数约 591
- **关键特性**：
  - 模块化设计：`aquatic_udp`、`aquatic_http`、`aquatic_ws` 独立实现
  - 多线程设计 + 纯内存数据存储
  - 支持 IPv4/IPv6
  - HTTP/WebSocket 实现利用 Linux `io_uring` 追求极致吞吐量
- **GitHub**：https://github.com/greatest-ape/aquatic
- **生产验证**：被 `explodie.org` 公共 Tracker 用于生产环境

### 3. UNIT3D-Announce

- **简介**：高性能私有 BitTorrent Tracker，与 UNIT3D 种子站兼容
- **适用场景**：需要与现有 UNIT3D 站点集成时参考

### 4. enxame-tracker

- **简介**：轻量级 Rust Tracker，支持 HTTP announce + scrape，内存 Swarm 注册表
- **适用场景**：学习参考或轻量级部署

### 5. Arcadia

- **简介**：内容无关的种子站和 Tracker 框架，模块化设计
- **适用场景**：参考其模块化架构设计


## 二、Web 后端框架

### 1. Actix-web

- **简介**：Rust 生态 Web 框架性能王者，实测 144k+ req/s
- **关键特性**：
  - 异步非阻塞，基于 Tokio 运行时
  - 类型安全的路由和提取器
  - 成熟的中间件生态
- **GitHub**：https://github.com/actix/actix-web
- **参考项目**：
  - `Actix_CRUD`：CRUD 示例 + JWT 认证
  - `rust-actix-examples`：社区示例集合

### 2. Axum

- **简介**：Tokio 团队官方维护的 Web 框架，设计优雅，与 Tower 生态无缝集成
- **关键特性**：
  - 类型安全的路由
  - 提取器模式（Extractors）
  - 与 Tower 中间件生态完美集成
- **GitHub**：https://github.com/tokio-rs/axum
- **参考项目**：
  - `axum-quickstart`：WebAuthn/Passkeys 认证 + PostgreSQL + Redis + Prometheus
  - `axum-best`：分层架构模板，MySQL + Redis + 结构化日志
  - `create-ruxum-app`：Rust Axum + Next.js 全栈脚手架


## 三、前端框架与工具

### 1. Next.js

- **简介**：React 全栈框架，Vercel 维护
- **关键特性**：
  - App Router 服务端组件
  - **PPR（部分预渲染）**：静态壳 + 动态内容流式加载
  - **Turbopack**：Rust 编写的打包器，构建速度提升 5 倍
  - ISR（增量静态再生）
- **官网**：https://nextjs.org

### 2. shadcn/ui

- **简介**：基于 Radix UI + Tailwind CSS 的高质量 React 组件集合
- **关键特性**：
  - 组件源码直接复制到项目，完全可控
  - 支持 AI 辅助开发
  - GitHub Star 超 50k
- **GitHub**：https://github.com/shadcn-ui/ui

### 3. Tailwind CSS

- **简介**：实用优先的 CSS 框架，移动优先设计
- **关键特性**：响应式断点系统、深色模式支持、高度可定制
- **官网**：https://tailwindcss.com

### 4. Framer Motion

- **简介**：React 动画库，声明式 API
- **适用场景**：页面过渡、列表入场、微交互动效
- **GitHub**：https://github.com/framer/motion

### 5. TanStack Virtual

- **简介**：虚拟滚动库，支持 React/Vue/Solid
- **适用场景**：百万级种子列表渲染，DOM 节点恒定
- **GitHub**：https://github.com/TanStack/virtual


## 四、项目管理与 Monorepo

### 1. Turborepo

- **简介**：Vercel 维护的高性能 Monorepo 构建系统
- **关键特性**：
  - 内容感知缓存（构建时间从 15 分钟降至 2 分钟）
  - 任务并行执行
  - 远程缓存共享
- **官网**：https://turborepo.dev
- **快速开始**：`create-turbo`

### 2. pnpm

- **简介**：高效的 Node.js 包管理器，节省磁盘空间
- **适用场景**：Monorepo 工作区管理
- **官网**：https://pnpm.io


## 五、边缘网关

### Pingora

- **简介**：Cloudflare 开源的 Rust 网络服务框架
- **关键特性**：
  - 支持每秒处理超 4000 万个互联网请求（Cloudflare 生产验证）
  - 异步多线程框架
  - 可编程、可扩展
- **GitHub**：https://github.com/cloudflare/pingora
- **许可证**：Apache-2.0


## 六、数据与缓存

### 1. PostgreSQL

- **简介**：最先进的开源关系型数据库
- **关键特性**：分区表、覆盖索引、JSONB、全文搜索
- **官网**：https://postgresql.org

### 2. Redis / Valkey

- **简介**：内存数据结构存储，分布式缓存
- **Valkey**：Redis 开源替代，Linux 基金会托管
- **官网**：https://redis.io / https://valkey.io

### 3. Moka

- **简介**：高性能并发缓存库，受 Java Caffeine 启发
- **关键特性**：
  - 线程安全、高并发
  - W-TinyLFU 淘汰算法
  - 纳秒级响应
- **GitHub**：https://github.com/moka-rs/moka
- **Star**：~3k


## 七、数据库访问

### SQLx

- **简介**：异步纯 Rust SQL 工具包
- **关键特性**：
  - 编译时检查查询（可选）
  - 支持 PostgreSQL、MySQL、SQLite
  - 完全异步，与 Tokio/Actix 兼容
- **GitHub**：https://github.com/launchbadge/sqlx


## 八、异步运行时

### Tokio

- **简介**：Rust 异步运行时的事实标准
- **关键特性**：
  - 事件驱动、非阻塞 I/O
  - 零成本抽象，极致性能
- **GitHub**：https://github.com/tokio-rs/tokio


## 九、日志与可观测性

- **简介**：结构化、应用级诊断框架
- **关键特性**：
  - 结构化事件日志

## 十、安全相关

- **适用场景**：用户密码安全存储

- **适用场景**：替代 OpenSSL，更安全的内存管理
