## 3. 过程事故与修复（运维经验记录）

应用 `0036` 迁移时引发 **api 容器 crashloop（`migration 36 was previously applied but has been modified`）**，根因链：

1. 先手动 psql 执行 0036，再手动登记 checksum；
2. 期间 docker compose `up -d` 未 `--force-recreate`，**旧镜像容器（内含早期版 0036 文件）反复重启竞争登记**，写入的 checksum 与新镜像文件不一致；
3. 修复：checksum 以**新镜像文件 sha384** 为准 UPDATE + `docker compose up -d --force-recreate api` → health 200。

教训（已体现在操作顺序上）：迁移文件一旦提交**禁止再改动**；compose 重建必须 `--force-recreate` 确认 Image ID 更新。
